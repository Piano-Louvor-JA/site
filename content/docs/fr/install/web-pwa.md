# Utiliser PIANO LouvorJA dans le navigateur et comme application

Ouvrez PIANO directement sur [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br). Sur Chrome, Edge ou Android, vous pouvez l'ajouter comme application à l'écran d'accueil ; après le premier chargement, il peut rester disponible hors ligne selon le contenu déjà chargé sur l'appareil.

## Comment ouvrir PIANO sans rien installer ?

Le navigateur est la manière la plus rapide de commencer, utile pour tester PIANO, utiliser un autre ordinateur ou soutenir un programme en dehors de l'église.

1. Ouvrez un navigateur à jour.
2. Tapez `app.pianolouvorja.com.br`.
3. Attendez que l'application se charge.
4. Ouvrez **Central de Mídia** pour trouver les hymnes et recueils.
5. Utilisez **Liturgia** pour organiser le programme.
6. Testez la projection avant de commencer le culte.

Pour une meilleure expérience de projection multi-écrans, l'ordinateur est généralement le choix le plus pratique. Le navigateur reste utile sur les tablettes, téléphones et appareils partagés.

## Comment installer comme application sur Chrome ou Edge sur ordinateur ?

L'installation PWA crée un raccourci qui ouvre PIANO dans sa propre fenêtre, sans avoir à chercher l'onglet dans le navigateur.

1. Ouvrez [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br) dans Chrome ou Edge.
2. Cherchez l'icône d'installation à côté de l'adresse du site, lorsqu'elle apparaît.
3. Cliquez sur **Installer** ou sur **Installer PIANO LouvorJA**.
4. Confirmez l'installation.
5. Ouvrez PIANO via le raccourci créé dans le menu des applications ou sur le Bureau.
6. Faites un test d'hymne, de Bible et de projection.

Si l'icône n'apparaît pas, ouvrez le menu à trois points du navigateur et cherchez **Installer l'application**, **Installer cette page comme application** ou une option similaire.

## Comment ajouter à l'écran d'accueil sur Android ?

Sur Android, PIANO peut être disponible sous forme d'icône sur l'écran d'accueil.

1. Ouvrez [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br) dans Chrome.
2. Touchez le menu à trois points.
3. Choisissez **Ajouter à l'écran d'accueil** ou **Installer l'application**.
4. Confirmez le nom et touchez **Ajouter** ou **Installer**.
5. Localisez l'icône de PIANO sur l'écran d'accueil ou dans la liste des applications.
6. Ouvrez via l'icône et testez avant le culte.

Sur d'autres navigateurs, le texte peut varier. Cherchez l'option qui ajoute le site comme application ou à l'écran d'accueil.

## PIANO fonctionne-t-il hors ligne dans le navigateur ?

Après le premier chargement, la PWA peut rester disponible hors ligne selon les données et contenus déjà chargés sur l'appareil. Préparez tout avec Internet avant le culte.

1. Avec Internet, ouvrez PIANO au moins une fois.
2. Recherchez et téléchargez à l'avance les hymnes qui seront utilisés.
3. Ouvrez la liturgie et confirmez que les éléments nécessaires sont prêts.
4. Testez la projection tant qu'Internet est encore disponible.
5. Ensuite, si la connexion tombe, utilisez ce qui a été préparé et enregistré sur l'appareil.

N'attendez pas le début du programme pour dépendre d'un contenu pas encore chargé. L'accès initial et les nouvelles mises à jour nécessitent une connexion.

## Quand utiliser le navigateur, la PWA ou l'application installée ?

Choisissez selon le type d'utilisation de l'église.

| Situation                                                                    | Meilleur choix                                        |
| ---------------------------------------------------------------------------- | ----------------------------------------------------- |
| Tester rapidement ou utiliser un ordinateur prêté                            | Navigateur sur `app.pianolouvorja.com.br`             |
| Utiliser toujours le même ordinateur sans installer un logiciel traditionnel | PWA installée via Chrome ou Edge                      |
| Projection avec deux écrans et routine fixe de l'église                      | Application pour Windows, macOS ou Linux              |
| Contrôle sur téléphone ou tablette                                           | PWA dans le navigateur ou ajoutée à l'écran d'accueil |
| TV connectée au réseau pour recevoir la projection                           | Scène sur un appareil compatible                      |

La version installée est préférable lorsque l'équipe a besoin d'une opération stable, avec l'écran de l'opérateur séparé de l'écran de l'église.

## Comment préparer un programme dans la PWA ?

L'organisation du culte est identique : préparez avant et avancez pendant le programme.

1. Dans **Central de Mídia**, recherchez les hymnes par nom ou extrait des paroles.
2. Téléchargez les hymnes pour rendre le contenu disponible sur l'appareil.
3. Dans **Liturgia**, créez des catégories comme **Accueil**, **École du Sabbat**, **Louange**, **Message** et **Clôture**.
4. Ajoutez des musiques, vidéos, images, PDF, présentations, liens et notes de l'équipe.
5. Glissez les éléments pour ajuster l'ordre.
6. Enregistrez et rouvrez pour vérifier.
7. Pendant le culte, avancez élément par élément et suivez les éléments déjà terminés.

## Comment rendre l'écran de l'église lisible ?

1. Ouvrez **Paramètres**.
2. Entrez dans **Projection**.
3. Choisissez des couleurs avec un contraste fort.
4. Ajustez la police entre 50% et 200% selon la distance de l'assemblée.
5. Activez la zone de texte si l'arrière-plan a une image claire.
6. Ajustez l'alignement et l'arrière-plan.
7. Testez sur le projecteur ou la TV avant de commencer.

## Comment utiliser la Bible et les utilitaires dans la PWA ?

1. Ouvrez **Bible**.
2. Choisissez la version, le livre, le chapitre et le ou les versets.
3. Cliquez sur **Projeter** pour envoyer le texte à l'écran de l'église.
4. Pour l'heure, ouvrez **Utilitaires** et choisissez **Horloge**.
5. Ajustez la couleur, le format 12 ou 24 heures et les secondes.
6. Pour contrôler le temps, utilisez **Minuteur** ou **Compte à rebours**.
7. Testez tout avant le début du programme.

## Comment contrôler PIANO à distance ?

1. Ouvrez la zone **Télécommande et Scène** sur l'appareil principal.
2. Choisissez l'appairage sur le même réseau ou via un serveur.
3. Terminez la confirmation présentée sur les appareils.
4. Testez la recherche d'hymne et l'ouverture d'une musique.
5. Testez l'avancement des versets et l'effacement de la sélection.
6. Testez le démarrage, la pause et la remise à zéro des minuteurs.
7. Confirmez que le second écran n'affiche pas les commandes de l'équipe.

## Que faire si la PWA ne s'ouvre pas hors ligne ?

1. Connectez l'appareil à Internet.
2. Ouvrez `app.pianolouvorja.com.br` dans le navigateur.
3. Attendez que la page finisse de se charger.
4. Refaites la préparation et les téléchargements.
5. Gardez les hymnes et la liturgie enregistrés avant de vous déconnecter.
6. Actualisez la page lorsqu'il y a Internet pour recevoir la version à jour.
7. Pour une routine fixe de projection, envisagez l'application de bureau.

## Comment garder le navigateur prêt pour le programme ?

1. Fermez les onglets qui ne seront pas utilisés.
2. Désactivez les notifications du navigateur, si possible.
3. Utilisez le plein écran seulement si cela ne masque pas les commandes nécessaires.
4. Vérifiez que l'ordinateur ne passera pas en veille.
5. Gardez le chargeur et la connexion réseau disponibles.
6. Ouvrez la liturgie et laissez le premier élément prêt.
7. Faites un test final de projection.

## Checklist finale avant le culte

1. Confirmez que PIANO s'ouvre sur l'appareil choisi.
2. Confirmez que les hymnes et les supports sont disponibles.
3. Confirmez que la liturgie est dans le bon ordre.
4. Confirmez que l'écran de l'église reçoit une projection de test.
5. Confirmez la taille des lettres et le contraste au fond de la salle.
6. Confirmez le réseau, l'alimentation et les câbles nécessaires.
7. Désignez une personne responsable de l'opération.
