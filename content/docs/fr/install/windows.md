# Installer PIANO LouvorJA sur Windows

La méthode la plus simple consiste à installer l'application via le Microsoft Store. Si vous préférez, téléchargez le fichier EXE portable sur la page officielle de téléchargement ; ouvrez ensuite PIANO, terminez la préparation initiale et réservez un écran pour l'opérateur et un autre pour l'église.

## Comment installer via le Microsoft Store ?

Le Microsoft Store s'occupe de l'installation et des mises à jour de l'application.

1. Ouvrez la page officielle de [téléchargement](/download).
2. Choisissez **Windows** et ouvrez l'option du Microsoft Store.
3. Dans le Store, recherchez **LouvorJA**. Si vous recevez un lien direct, il utilise le produit `9N1WPDQKFLR9`.
4. Cliquez sur **Obtenir** ou **Installer**.
5. Attendez la fin du téléchargement.
6. Cliquez sur **Ouvrir** ou localisez **LouvorJA PIANO** dans le menu Démarrer.

N'installez pas de copies reçues par messages ou provenant de sites inconnus. Utilisez la page officielle pour accéder au Store.

## Comment utiliser l'EXE portable ?

L'EXE est l'alternative officielle pour ceux qui ne souhaitent pas utiliser le Store. Il est fourni via les versions publiées sur GitHub et peut être téléchargé depuis la page de téléchargement.

1. Ouvrez [téléchargement](/download).
2. Dans la section **Windows**, choisissez le téléchargement en EXE.
3. Attendez que le fichier soit complètement téléchargé.
4. Ouvrez le dossier **Téléchargements**.
5. Double-cliquez sur le fichier EXE de PIANO.
6. Confirmez l'ouverture si Windows demande une autorisation.
7. Conservez le fichier dans un dossier facile à trouver, comme **Documents/PIANO LouvorJA**.

La version portable s'ouvre sans installation traditionnelle. Créez un raccourci sur le Bureau uniquement après avoir vérifié qu'elle s'ouvre normalement.

## Que faire lors de la première ouverture ?

Lors de la première utilisation, PIANO prépare le catalogue et affiche la configuration initiale. Laissez Internet connecté à ce moment-là, mais vous pouvez commencer à découvrir l'application pendant que le contenu est préparé.

1. Ouvrez PIANO LouvorJA.
2. Attendez que l'écran de démarrage termine la préparation.
3. Ajustez la taille de l'interface avec les boutons **−** et **＋** de l'en-tête.
4. Ouvrez la **Centrale Média** et recherchez un cantique de l'Hymnaire Adventiste ou un recueil.
5. Téléchargez à l'avance les cantiques qui seront utilisés pendant le culte ; la progression est sauvegardée même si l'application se ferme.
6. Ouvrez **Liturgie** pour préparer l'ordre de l'École du Sabbat, les louanges, le message et les autres moments.
7. Dans **Paramètres**, ajustez le fond, la couleur et la taille des lettres pour l'écran de l'église.

Ce que vous téléchargez et configurez est sauvegardé sur l'ordinateur. Cela inclut les cantiques, la progression des téléchargements, les liturgies et les préférences.

## Comment préparer deux écrans ?

Utilisez un écran pour contrôler PIANO et un autre pour la congrégation. L'opérateur voit les recherches, les boutons et les éléments suivants ; l'église ne voit que la projection.

1. Connectez le vidéoprojecteur, la TV ou le second écran à l'ordinateur.
2. Sous Windows, ouvrez **Paramètres**.
3. Allez dans **Système**, puis dans **Écran**.
4. Dans **Plusieurs écrans**, choisissez **Étendre ces affichages**.
5. Faites glisser les icônes des écrans pour correspondre à leur position physique.
6. Ouvrez PIANO et lancez une projection de test.
7. Placez la fenêtre de l'église sur le second écran ou la TV.
8. Testez un texte de cantique, un verset et l'horloge avant le culte.

Évitez le mode qui duplique les écrans : il affiche l'écran de contrôle à l'église. Le mode **Étendre** sépare l'opérateur de la projection.

## Comment projeter un cantique ou un verset ?

Faites un test complet avant l'arrivée de la congrégation.

1. Dans la **Centrale Média**, recherchez le cantique.
2. Ouvrez le résultat et cliquez sur **Projeter**.
3. Faites défiler la strophe ou le refrain ; l'écran de l'église suit.
4. Dans **Bible**, choisissez la version, le livre, le chapitre et les versets.
5. Cliquez sur **Projeter** pour envoyer le passage au second écran.
6. Pour terminer une projection, utilisez **ESC** et confirmez.

Lorsqu'aucun passage n'est sélectionné dans un chant, PIANO peut afficher la pochette de l'album avec le titre. Cela est utile lors de l'accueil ou avant les louanges.

## Comment ajuster la lisibilité de la projection ?

Avant le culte, adaptez l'écran à l'espace et à la distance de la congrégation.

1. Ouvrez **Paramètres**.
2. Allez dans les options de **Projection**.
3. Ajustez la couleur de fond, la couleur du texte et la taille de la police.
4. Choisissez l'alignement horizontal et vertical.
5. Activez la zone de texte lorsque vous utilisez un fond clair ou une image claire.
6. Testez depuis le dernier banc de l'église, si possible.
7. Enregistrez la configuration ; elle reste sur l'ordinateur.

Pour les textes des cantiques sacrés, privilégiez le contraste et la taille. Une belle image ne sert à rien si l'église ne peut pas suivre le texte.

## Et si une vidéo ou un audio s'ouvre dans le mauvais programme ?

Sous Windows, PIANO permet de choisir comment les vidéos et les fichiers multimédias seront ouverts.

1. Ouvrez **Paramètres**.
2. Localisez **Lecteur externe**.
3. Choisissez **Associé au système** pour utiliser le programme par défaut de Windows.
4. Si un autre lecteur est détecté, sélectionnez-le.
5. Faites un test avec la vidéo ou l'audio de la liturgie.

## Comment tout garder prêt pour le prochain culte ?

Une préparation sereine pendant la semaine réduit le travail de l'équipe le samedi.

1. Ouvrez la liturgie précédente et utilisez-la comme référence, si cela est pertinent.
2. Mettez à jour les titres complémentaires, les horaires et les catégories du programme.
3. Téléchargez à l'avance les chants, vidéos et fichiers qui ne sont pas encore sur l'ordinateur.
4. Ouvrez chaque élément multimédia pour vérifier qu'il fonctionne.
5. Effectuez une sauvegarde dans **Paramètres** avant de changer d'ordinateur.
6. Laissez le portable branché sur le secteur avec le chargeur accessible.
7. Faites une projection rapide quinze minutes avant le début.

## Comment agir si la projection ne se met pas à jour ?

1. Vérifiez que le second écran est toujours connecté à Windows.
2. Vérifiez que la fenêtre de projection est ouverte dans le bon module, comme **Média** ou **Bible**.
3. Rouvrez la projection de l'élément utilisé.
4. Vérifiez que Windows est toujours en mode **Étendre ces affichages**.
5. Si nécessaire, fermez et rouvrez PIANO ; le contenu sauvegardé reste disponible.
6. Utilisez un câble vidéo de secours lorsque l'église en a un à disposition.

## Comment travailler en équipe ?

Désignez une personne pour opérer et une autre pour vérifier l'écran de l'église.

1. L'opérateur ouvre la liturgie et fait avancer les éléments.
2. La seconde personne confirme le texte, le passage et le contraste sur la projection.
3. Avant de commencer, les deux personnes révisent l'ordre des louanges et du message.
4. En cas de changement, utilisez une annotation dans la liturgie pour orienter l'équipe.
5. Évitez que plusieurs personnes manipulent le même ordinateur pendant le programme.

## Liste de contrôle finale avant le culte

1. Vérifiez que PIANO s'ouvre sur l'appareil choisi.
2. Vérifiez que les cantiques et les matériaux sont disponibles.
3. Vérifiez que la liturgie est dans le bon ordre.
4. Vérifiez que l'écran de l'église reçoit une projection de test.
5. Vérifiez la taille des lettres et le contraste sur le fond de la salle.
6. Vérifiez le réseau, l'alimentation et les câbles nécessaires.
7. Désignez une personne responsable de l'opération.
