# Skróty klawiaturowe

Skróty pomagają prowadzić nabożeństwo bez szukania przycisków. Przetestuj je wszystkie na komputerze w kościele przed programem i używaj ich tylko wtedy, gdy fokus nie jest używany do wpisywania wyszukiwania lub notatki.

## Jak bezpiecznie używać skrótów?

Używaj klawiatury podłączonej do komputera operatora. Najpierw przygotuj hymn, liturgię lub Biblię; następnie używaj skrótów, aby szybko reagować podczas projekcji.

1. Otwórz PIANO na komputerze sterującym nabożeństwem.
2. Przygotuj hymn i ekran projekcyjny przed rozpoczęciem.
3. Kliknij poza polami tekstowymi przed użyciem strzałek, spacji lub liter skrótów.
4. Przeprowadź krótką próbę z zespołem.
5. Pozostaw widoczne przyciski jako alternatywę, jeśli skrót nie zadziała.

## Które skróty sterują odtwarzaczem?

Używaj tych skrótów podczas śledzenia hymnu lub nagrania. Pozwalają one uniknąć zmiany ekranów tylko po to, aby wstrzymać, przejść dalej lub dostosować głośność.

| Działanie          | Skrót   | Kiedy używać                                                                             |
| ------------------ | ------- | ---------------------------------------------------------------------------------------- |
| Odtwórz/Wstrzymaj  | `Space` | Aby rozpocząć lub wstrzymać dźwięk hymnu podczas próby, powitania lub uwielbienia.       |
| Następny utwór     | `→`     | Aby przejść do następnego utworu, gdy wymaga tego program lub próba.                     |
| Poprzedni utwór    | `←`     | Aby wrócić do poprzedniego utworu, gdy zespół musi powtórzyć lub poprawić wybór.         |
| Zwiększ głośność   | `↑`     | Aby zwiększyć głośność odtwarzacza po potwierdzeniu prawidłowego wyjścia dźwięku.        |
| Zmniejsz głośność  | `↓`     | Aby zmniejszyć głośność odtwarzacza bez przerywania muzyki.                              |
| Tryb pełnoekranowy | `F`     | Aby używać odtwarzacza w trybie pełnoekranowym podczas konferencji lub wspólnego śpiewu. |

Unikaj używania strzałek podczas pisania w polu wyszukiwania lub edytowania notatki. W takim przypadku mogą przesuwać kursor zamiast sterować odtwarzaczem.

## Które skróty sterują projekcją?

Używaj tych poleceń, aby wyświetlać, kończyć lub szybko przełączać sterowanie i projekcję podczas nabożeństwa.

| Działanie                                              | Skrót        | Kiedy używać                                                                                                |
| ------------------------------------------------------ | ------------ | ----------------------------------------------------------------------------------------------------------- |
| Przełącz projekcję                                     | `P`          | Aby włączyć lub wyłączyć projekcję bieżącej treści bez szukania przycisku na ekranie.                       |
| Zakończ projekcję                                      | `ESC`        | Aby zamknąć projekcję po zakończeniu hymnu, wersetu lub elementu; aplikacja poprosi o potwierdzenie.        |
| Przełącz operatora ↔ projekcję w aplikacji desktopowej | `Ctrl+Alt+P` | Aby przełączać między oknem operatora a projekcją w aplikacji desktopowej, gdy trzeba sprawdzić oba ekrany. |

Przed użyciem `ESC` uprzedź osobę przy mównicy lub śpiewającą. Polecenie kończy projekcję i wymaga potwierdzenia właśnie po to, aby ograniczyć przypadkowe zakończenia.

## Jak wyszukać hymn bez przerywania toku programu?

Szybkie wyszukiwanie jest przydatne do znalezienia hymnu z Adventist Hymnal, świętego śpiewnika lub innej treści, gdy liturgia zmienia się krótko przed nabożeństwem.

| Działanie            | Skrót    | Kiedy używać                                                                                  |
| -------------------- | -------- | --------------------------------------------------------------------------------------------- |
| Szybkie wyszukiwanie | `Ctrl+K` | Aby otworzyć wyszukiwanie i wpisać numer, tytuł lub fragment słów bez poruszania się po menu. |

1. Naciśnij `Ctrl+K`.
2. Wpisz numer hymnu, tytuł lub fragment słów.
3. Wybierz właściwy wynik.
4. Potwierdź, że hymn jest pobrany, zanim będziesz polegać na nim bez internetu.
5. Otwórz go i wyświetl w odpowiednim momencie programu.

## Jak ćwiczyć skróty z zespołem?

Nie polegaj na pierwszym użyciu na żywo. Przeprowadź krótką sekwencję identyczną z tą, która będzie używana podczas nabożeństwa.

1. Otwórz już pobrany hymn.
2. Użyj `Space`, aby rozpocząć i wstrzymać.
3. Dostosuj głośność za pomocą `↑` i `↓`.
4. Kliknij **Project** i przetestuj `P`.
5. Użyj `ESC`, potwierdź zakończenie i ponownie otwórz projekcję.
6. Naciśnij `Ctrl+K` i wyszukaj następny hymn.
