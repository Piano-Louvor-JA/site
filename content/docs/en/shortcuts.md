# Keyboard shortcuts

Shortcuts help you lead the service without looking for buttons. Test all of them on the church computer before the program and use them only when focus is not being used to type a search or note.

## How do I use shortcuts safely?

Use a keyboard connected to the operator computer. First have the hymn, liturgy or Bible ready; then use shortcuts to respond quickly during the projection.

1. Open PIANO on the computer that controls the service.
2. Prepare the hymn and the projection screen before starting.
3. Click outside text fields before using arrows, space or shortcut letters.
4. Run a short rehearsal with the team.
5. Keep the buttons visible as an alternative if a shortcut does not respond.

## Which shortcuts control the player?

Use these shortcuts while following a hymn or audio. They avoid changing screens just to pause, advance or adjust volume.

| Action          | Shortcut | When to use                                                                             |
| --------------- | -------- | --------------------------------------------------------------------------------------- |
| Play/Pause      | `Space`  | To start or pause a hymn's audio during rehearsal, welcome or praise.                   |
| Next track      | `→`      | To go to the next track when the program or test requires it.                           |
| Previous track  | `←`      | To return to the previous track when the team needs to repeat or correct the selection. |
| Increase volume | `↑`      | To raise player volume after confirming the sound output is correct.                    |
| Decrease volume | `↓`      | To lower player volume without interrupting the music.                                  |
| Fullscreen mode | `F`      | To use the player in fullscreen during a conference or follow-along.                    |

Avoid using the arrows while typing in the search field or editing a note. In that case, they may move the cursor instead of controlling the player.

## Which shortcuts control the projection?

Use these commands to show, end or quickly switch between control and projection during the service.

| Action                                          | Shortcut     | When to use                                                                                                          |
| ----------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------- |
| Toggle projection                               | `P`          | To turn the current content projection on or off without looking for the on-screen button.                           |
| End projection                                  | `ESC`        | To close the projection after a hymn, verse or feature ends; the application asks for confirmation.                  |
| Toggle operator ↔ projection in the desktop app | `Ctrl+Alt+P` | To switch between the operator window and projection in the desktop application when you need to check both screens. |

Before using `ESC`, warn the person at the pulpit or singing. The command ends the projection and requires confirmation precisely to reduce accidental endings.

## How do I search for a hymn without leaving the flow?

Quick search is useful for finding a hymn from the Adventist Hymnal, a sacred songbook or other content when the liturgy changes shortly before the service.

| Action       | Shortcut | When to use                                                                                 |
| ------------ | -------- | ------------------------------------------------------------------------------------------- |
| Quick search | `Ctrl+K` | To open search and type a number, title or part of the lyrics without navigating the menus. |

1. Press `Ctrl+K`.
2. Type the hymn number, title or part of the lyrics.
3. Choose the correct result.
4. Confirm that the hymn is downloaded before relying on it without internet.
5. Open and project it when the moment in the program comes.

## How do I practice shortcuts with the team?

Do not rely on the first live use. Run a short sequence identical to the one that will be used in the service.

1. Open an already-downloaded hymn.
2. Use `Space` to start and pause.
3. Adjust the volume with `↑` and `↓`.
4. Click **Project** and test `P`.
5. Use `ESC`, confirm the ending and open the projection again.
6. Press `Ctrl+K` and search for the next hymn.
