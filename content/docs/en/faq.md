# PIANO LouvorJA frequently asked questions

PIANO LouvorJA helps you prepare and project hymns, Bible, liturgy and worship resources. For extra safety, test your computer, projector or TV before the program and download the media you will use in advance.

## Installation and access

## Is PIANO LouvorJA really free?

Yes. PIANO LouvorJA is free and open source. There is no subscription and no ads to use the features described in the application.

You can use the application to organize worship services, hymnals, songbooks, liturgy, Bible and projection. Content such as hymns and lyrics remains the property of their respective authors and rights holders; use the material appropriately for your church.

## Do I need to create an account to use it?

Not to get started. The application can be opened and used without registration, including for organizing the service and working with local data.

The account area offers sign in, sign up and password recovery. If you choose to use it, password recovery sends a reset token and does not reveal whether an e-mail exists or not, for security reasons.

## On which devices can I use it?

PIANO can be accessed on a computer, tablet or phone with a modern browser. To prepare and project a complete service, the desktop is the most recommended option, as it offers multiple screens, independent projection and keyboard shortcuts.

1. Use desktop for separate operator and projector/TV.
2. Use the phone as a remote control when pairing is available and tested.
3. Use the browser as a quick alternative when no application is installed.

## Does an old non-smart TV work?

Yes, if it can receive the image from a computer or another compatible device by cable. In that case, the TV works as a second screen for the projection.

1. Connect the computer to the TV using the input type available on it.
2. Select the correct input on the TV.
3. Open a hymn in PIANO and click **Project**.
4. Confirm that the lyrics appear before the service.

Stage mode depends on a receiver or device connected to the TV and to the network. See [Stage and multiple devices](/docs/palco-multi-device) for pairing precautions.

## Use during the service

## Does it work without internet during the service?

The desktop application works offline once the necessary media has been downloaded. Downloaded hymns, liturgies, settings and local progress remain on the device.

The web version needs a connection to work. Before a service without a reliable connection, do the following:

1. Download all the hymns, songbooks and media that will be used.
2. Open each item once to confirm availability.
3. Save the liturgy with the complete order.
4. Test the projection on the projector or TV.
5. Take a backup of the data if you will use another computer.

## How many devices can I use in the same service?

Basic use separates two roles: one device to control and one screen to display. The manual also describes a remote control and a Stage connected over the network.

The maximum number of Stage receivers and simultaneous controls is not detailed in the available source. Run a test with the number of screens you want before relying on it in the program.

Each Stage receiver occupies a separate connection to the operator computer, so additional screens require more network capacity and more attention from the operator. In practice, one main TV and one secondary TV (for example, hallway or lobby) is the most common setup.

## Can I prepare the whole program in advance?

Yes. Use the **Liturgy** to build the order of the service before starting. You can insert categories, songs, videos, audios, images, PDF, PowerPoint presentations, websites, online videos and notes for the team.

1. Create categories such as `Sabbath School`, `Praise`, `Offering` and `Word`.
2. Add the items in the actual order of the program.
3. Drag to fix the sequence.
4. Save.
5. During the service, mark what has already passed and open the next item.

## Does the audio keep playing if I open the Bible?

Yes. The audio player keeps playing while you navigate to other sections. You can leave a hymn playing and prepare the next verse or liturgy item.

When you switch hymns during playback, the application makes a smooth transition between the current audio and the new one. Test the volume and audio output before the service to avoid surprises with the church sound.

## How do I back up before switching computers?

Export the data using the backup feature in the settings. Keep the copy in a safe place before formatting, replacing or lending the computer.

1. Open **Settings**.
2. Locate **Backup**.
3. Export the settings and data.
4. Copy the file to a trusted medium or storage.
5. On the other computer, use the corresponding import option.

## Privacy and data

## Where is my data stored?

In the desktop application, downloaded hymns, liturgies and settings are stored locally on the device. This allows you to keep using what was prepared even without internet.

On the website, the contact form sends name, e-mail and message to enable a reply. See the website's Privacy Policy for details about this processing.

## How is my privacy protected?

The website states that it does not use tracking, analytics or advertising cookies; there is only a technical cookie to remember the preferred language. Contact data is used to answer the request, not for third-party marketing.

To exercise rights over personal data or learn the details, see the Privacy Policy available on the PIANO LouvorJA website.

## Problems and updates

## How is the application updated?

In the web application, updates are applied by reloading the page. There is no need to download an update manually for that version.

Before an important program, open the application in advance. This way, you can confirm that the version loaded and test the projection, audio and the hymns of the liturgy.

## What do I do if the application does not load or gives an error?

Start by reloading and checking the connection, especially on first access or in the web version.

1. Reload the page; if needed, use `Ctrl+F5` to refresh the cache.
2. Check the internet on first access.
3. Clear the site data in the browser settings.
4. Test in an incognito window to rule out a conflicting extension.
5. If it persists, use **Try again** when the app offers that option.
6. Note the browser, device, version and what you were doing before the error.

See solutions by symptom in [Common problems](/docs/troubleshooting).

## How do I get support or report a problem?

Use the contact form on the website or open an issue in the project repository. The more details you provide, the easier it is to reproduce the problem.

Include:

1. Device model and system used.
2. Browser or application version.
3. Affected module: hymn, Liturgy, Bible, Stage, projection or audio.
4. Steps that caused the problem.
5. Expected result and actual result.
6. Photo or screenshot, without exposing personal data.

## Can I contribute to the project?

Yes. As an open-source project, you can report bugs, suggest improvements, submit contributions, help with translations or share PIANO with other churches and worship teams.
