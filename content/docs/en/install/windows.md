# Install PIANO LouvorJA on Windows

The simplest way is to install from the Microsoft Store. If you prefer, download the portable EXE file from the official download page; then open PIANO, complete the initial setup and leave one monitor for the operator and another for the congregation.

## How do I install from the Microsoft Store?

The Microsoft Store handles the installation and updates of the application.

1. Open the official [download](/download) page.
2. Choose **Windows** and open the Microsoft Store option.
3. In the Store, search for **LouvorJA**. If you receive a direct link, it uses the product `9N1WPDQKFLR9`.
4. Click **Get** or **Install**.
5. Wait for the download to finish.
6. Click **Open** or find **LouvorJA PIANO** in the Start menu.

Do not install copies received through messages or unknown websites. Use the official page to reach the Store.

## How do I use the portable EXE?

The EXE is the official alternative for those who do not want to use the Store. It comes from the versions published on GitHub and can be downloaded from the download page.

1. Open [download](/download).
2. In the **Windows** section, choose the EXE download.
3. Wait for the file to finish downloading.
4. Open the **Downloads** folder.
5. Double-click the PIANO EXE file.
6. Confirm the launch if Windows asks for authorization.
7. Keep the file in an easy-to-find folder, such as **Documents/PIANO LouvorJA**.

The portable version runs without a traditional installation. Create a Desktop shortcut only after confirming that it opens normally.

## What should I do on first launch?

The first time, PIANO prepares the catalog and shows the initial setup. Keep the internet connected at this moment, but you can start exploring the application while the content is being prepared.

1. Open PIANO LouvorJA.
2. Wait for the splash screen to finish the preparation.
3. Check the interface size with the **−** and **＋** buttons in the header.
4. Open **Media Center** and search for a hymn from the Adventist Hymnal or a songbook.
5. Download beforehand the hymns that will be used in the service; progress is saved even if the app closes.
6. Open **Liturgy** to build the order of Sabbath School, praise, message and other moments.
7. In **Settings**, adjust the background, color and size of the lyrics for the church screen.

What you download and configure is saved on the computer. This includes hymns, download progress, liturgies and preferences.

## How do I set up two monitors?

Use one monitor to control PIANO and another for the congregation. The operator sees searches, buttons and upcoming items; the congregation sees only the projection.

1. Connect the projector, TV or second monitor to the computer.
2. In Windows, open **Settings**.
3. Go to **System** and then **Display**.
4. Under **Multiple displays**, choose **Extend these displays**.
5. Drag the monitor diagrams to match their physical positions.
6. Open PIANO and start a test projection.
7. Keep the congregation window on the second monitor or TV.
8. Test a lyric, a Bible verse and the clock before the service.

Avoid the mode that duplicates the screens: it shows the control screen to the congregation. The **Extend** mode separates the operator from the projection.

## How do I project a hymn or Bible verse?

Run a complete test before the congregation arrives.

1. In **Media Center**, search for the hymn.
2. Open the result and click **Project**.
3. Advance the verse or chorus; the church screen follows along.
4. In **Bible**, choose the version, book, chapter and verses.
5. Click **Project** to send the passage to the second screen.
6. To end a projection, use **ESC** and confirm.

When no section of a song is selected, PIANO can display the album cover with the title. This helps during the welcome time or before the praise.

## How do I adjust the readability of the projection?

Before the service, adapt the screen to the room and the distance of the congregation.

1. Open **Settings**.
2. Go to the **Projection** options.
3. Adjust the background color, text color and font size.
4. Choose the horizontal and vertical alignment.
5. Enable the text box when using a light background or light image.
6. Test from the last pew of the church, if possible.
7. Save the configuration; it stays on the computer.

For sacred hymn lyrics, prioritize contrast and size. A beautiful image does not help if the congregation cannot follow the lyrics.

## What if video or audio opens in the wrong program?

On Windows, PIANO lets you choose how videos and media files are opened.

1. Open **Settings**.
2. Locate **External player**.
3. Choose **System-associated** to use the Windows default program.
4. If another player is detected, select it.
5. Run a test with the liturgy's video or audio.

## How do I keep everything ready for the next service?

Preparing calmly during the week reduces the team's work on Sabbath.

1. Open the previous liturgy and use it as a reference, if it makes sense.
2. Update complementary titles, times and categories of the program.
3. Download beforehand the songs, videos and files that are not yet on the computer.
4. Open each media item to confirm it works.
5. Make a backup in **Settings** before switching computers.
6. Keep the laptop plugged in with the charger accessible.
7. Run a quick projection fifteen minutes before the start.

## What should I do if the projection does not update?

1. Confirm that the second monitor is still connected to Windows.
2. Check that the projection window is open in the right module, such as **Media** or **Bible**.
3. Reopen the projection of the item you are using.
4. Confirm that Windows is still in **Extend these displays**.
5. If needed, close and reopen PIANO; the saved content remains available.
6. Use a spare video cable when the church has one available.

## How do we work as a team?

Assign one person to operate and another to check the church screen.

1. The operator opens the liturgy and advances the items.
2. The second person confirms lyrics, passage and contrast on the projection.
3. Before starting, both review the order of the praise and the message.
4. In case of changes, use a note in the liturgy to guide the team.
5. Avoid having several people handle the same computer during the program.

## Final checklist before the service

1. Confirm that PIANO opens on the chosen device.
2. Confirm that hymns and materials are available.
3. Confirm that the liturgy is in the correct order.
4. Confirm that the church screen receives a test projection.
5. Confirm text size and contrast against the hall's background.
6. Confirm network, power and the necessary cables.
7. Leave one person in charge of the operation.
