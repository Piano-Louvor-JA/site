# Atalhos de teclado

Atalhos ajudam a conduzir o culto sem procurar botões. Teste todos no computador da igreja antes da programação e use-os apenas quando o foco não estiver sendo usado para digitar uma busca ou anotação.

## Como usar os atalhos com segurança?

Use um teclado conectado ao computador operador. Primeiro deixe o hino, a liturgia ou a Bíblia preparados; depois use os atalhos para responder rapidamente durante a projeção.

1. Abra o PIANO no computador que controla o culto.
2. Prepare o hino e a tela de projeção antes do início.
3. Clique fora de campos de texto antes de usar setas, espaço ou letras de atalho.
4. Faça um ensaio curto com a equipe.
5. Mantenha os botões visíveis como alternativa caso um atalho não responda.

## Quais atalhos controlam o player?

Use estes atalhos enquanto acompanha um hino ou áudio. Eles evitam mudar de tela apenas para pausar, avançar ou ajustar o volume.

| Ação            | Atalho   | Quando usar                                                                            |
| --------------- | -------- | -------------------------------------------------------------------------------------- |
| Play/Pause      | `Espaço` | Para iniciar ou pausar o áudio de um hino durante ensaio, entrada ou louvor.           |
| Próxima faixa   | `→`      | Para seguir para a próxima faixa quando a programação ou teste exigir.                 |
| Faixa anterior  | `←`      | Para retornar à faixa anterior quando a equipe precisar repetir ou corrigir a seleção. |
| Aumentar volume | `↑`      | Para elevar o volume do player após confirmar que a saída de som está correta.         |
| Diminuir volume | `↓`      | Para reduzir o volume do player sem interromper a música.                              |
| Modo tela cheia | `F`      | Para usar o player em tela cheia durante uma conferência ou acompanhamento.            |

Evite usar as setas enquanto estiver digitando no campo de busca ou editando uma anotação. Nesse caso, elas podem mover o cursor em vez de controlar o player.

## Quais atalhos controlam a projeção?

Use estes comandos para mostrar, encerrar ou alternar rapidamente entre controle e projeção durante o culto.

| Ação                                        | Atalho       | Quando usar                                                                                                      |
| ------------------------------------------- | ------------ | ---------------------------------------------------------------------------------------------------------------- |
| Alternar projeção                           | `P`          | Para ligar ou desligar a projeção do conteúdo atual sem procurar o botão na tela.                                |
| Encerrar projeção                           | `ESC`        | Para fechar a projeção ao terminar um hino, versículo ou recurso; o aplicativo pede confirmação.                 |
| Alternar operador ↔ projeção no app desktop | `Ctrl+Alt+P` | Para mudar entre a janela do operador e a projeção no aplicativo desktop quando precisar conferir as duas telas. |

Antes de usar `ESC`, avise quem está no púlpito ou cantando. O comando encerra a projeção e exige confirmação justamente para reduzir encerramentos acidentais.

## Como busco um hino sem sair do fluxo?

A busca rápida é útil para localizar um hino do Hinário Adventista, uma coletânea sacra ou outro conteúdo quando a liturgia muda pouco antes do culto.

| Ação         | Atalho   | Quando usar                                                                             |
| ------------ | -------- | --------------------------------------------------------------------------------------- |
| Busca rápida | `Ctrl+K` | Para abrir a busca e digitar número, título ou trecho da letra sem navegar pelos menus. |

1. Pressione `Ctrl+K`.
2. Digite o número do hino, o título ou parte da letra.
3. Escolha o resultado correto.
4. Confirme que o hino está baixado antes de depender dele sem internet.
5. Abra e projete quando chegar o momento da programação.

## Como treinar os atalhos com a equipe?

Não dependa do primeiro uso ao vivo. Faça uma sequência curta, igual à que será usada no culto.

1. Abra um hino já baixado.
2. Use `Espaço` para iniciar e pausar.
3. Ajuste o volume com `↑` e `↓`.
4. Clique em **Projetar** e teste `P`.
5. Use `ESC`, confirme o encerramento e abra a projeção novamente.
6. Pressione `Ctrl+K` e busque o próximo hino.
