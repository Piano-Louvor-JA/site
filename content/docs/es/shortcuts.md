# Atajos de teclado

Los atajos ayudan a conducir el culto sin tener que buscar botones. Pruébalos todos en la computadora de la iglesia antes del programa y úsalos solo cuando el foco no esté en un campo para escribir una búsqueda o una nota.

## ¿Cómo usar los atajos con seguridad?

Usa un teclado conectado a la computadora del operador. Primero deja preparado el himno, la liturgia o la Biblia; después usa los atajos para responder rápidamente durante la proyección.

1. Abre el PIANO en la computadora que controla el culto.
2. Prepara el himno y la pantalla de proyección antes del inicio.
3. Haz clic fuera de los campos de texto antes de usar las flechas, el espacio o las letras de atajo.
4. Haz un ensayo corto con el equipo.
5. Mantén los botones visibles como alternativa en caso de que un atajo no responda.

## ¿Qué atajos controlan el reproductor?

Usa estos atajos mientras acompañas un himno o un audio. Evitan tener que cambiar de pantalla solo para pausar, avanzar o ajustar el volumen.

| Acción                 | Atajo     | Cuándo usar                                                                                    |
| ---------------------- | --------- | ---------------------------------------------------------------------------------------------- |
| Play/Pausa             | `Espacio` | Para iniciar o pausar el audio de un himno durante el ensayo, la entrada o el louvor.          |
| Pista siguiente        | `→`       | Para pasar a la pista siguiente cuando el programa o la prueba lo requiera.                    |
| Pista anterior         | `←`       | Para volver a la pista anterior cuando el equipo necesite repetir o corregir la selección.     |
| Aumentar volumen       | `↑`       | Para subir el volumen del reproductor después de confirmar que la salida de audio es correcta. |
| Disminuir volumen      | `↓`       | Para bajar el volumen del reproductor sin interrumpir la música.                               |
| Modo pantalla completa | `F`       | Para usar el reproductor en pantalla completa durante una conferencia o un acompañamiento.     |

Evita usar las flechas mientras escribes en el campo de búsqueda o editas una nota. En ese caso, pueden mover el cursor en lugar de controlar el reproductor.

## ¿Qué atajos controlan la proyección?

Usa estos comandos para mostrar, finalizar o alternar rápidamente entre control y proyección durante el culto.

| Acción                                                 | Atajo        | Cuándo usar                                                                                                                           |
| ------------------------------------------------------ | ------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Alternar proyección                                    | `P`          | Para encender o apagar la proyección del contenido actual sin buscar el botón en la pantalla.                                         |
| Finalizar proyección                                   | `ESC`        | Para cerrar la proyección al terminar un himno, un versículo o un recurso; la aplicación pide confirmación.                           |
| Alternar operador ↔ proyección en la app de escritorio | `Ctrl+Alt+P` | Para cambiar entre la ventana del operador y la proyección en la aplicación de escritorio cuando necesites revisar las dos pantallas. |

Antes de usar `ESC`, avisa a quien está en el púlpito o cantando. El comando finaliza la proyección y pide confirmación justamente para reducir los cierres accidentales.

## ¿Cómo busco un himno sin salir del flujo?

La búsqueda rápida es útil para localizar un himno del Himnario Adventista, una colectánea sacra u otro contenido cuando la liturgia cambia poco antes del culto.

| Acción          | Atajo    | Cuándo usar                                                                                                  |
| --------------- | -------- | ------------------------------------------------------------------------------------------------------------ |
| Búsqueda rápida | `Ctrl+K` | Para abrir la búsqueda y escribir el número, el título o un fragmento de la letra sin navegar por los menús. |

1. Presiona `Ctrl+K`.
2. Escribe el número del himno, el título o parte de la letra.
3. Elige el resultado correcto.
4. Confirma que el himno está descargado antes de depender de él sin internet.
5. Ábrelo y proyéctalo cuando llegue el momento del programa.

## ¿Cómo entrenar los atajos con el equipo?

No dependas del primer uso en vivo. Haz una secuencia corta, igual a la que se usará en el culto.

1. Abre un himno ya descargado.
2. Usa `Espacio` para iniciar y pausar.
3. Ajusta el volumen con `↑` y `↓`.
4. Haz clic en **Proyectar** y prueba `P`.
5. Usa `ESC`, confirma el cierre y abre la proyección de nuevo.
6. Presiona `Ctrl+K` y busca el siguiente himno.
