# 자주 발생하는 문제와 해결 방법

증상부터 확인하고, 예배 전에 해결 방법을 테스트한 후, 프로젝션을 위한 대안을 항상 준비해 두세요. 이미 다운로드한 콘텐츠, 예배 순서(liturgia) 및 기기의 로컬 설정은 그대로 저장되어 있습니다.

## 도움을 요청하기 전에 무엇을 확인해야 하나요?

메시지를 보내기 전에 이 점검 목록을 확인하세요. 가장 흔한 오류를 해결할 수 있고, 문제가 계속될 경우 팀에 필요한 정보를 제공할 수 있습니다.

1. 앱을 닫았다가 다시 열거나 페이지를 새로 고침하세요.
2. 컴퓨터, 프로젝터, TV 및 오디오 출력이 켜져 있는지 확인하세요.
3. 비디오 케이블이 연결되어 있고 TV가 올바른 입력으로 설정되어 있는지 확인하세요.
4. 콘텐츠를 다운로드하거나 웹 버전을 사용 중이라면 인터넷 연결을 확인하세요.
5. 이미 다운로드한 찬송가를 열어 인터넷 문제인지 앱 문제인지 구분하세요.
6. 찬송가와 성구 하나로 프로젝션을 테스트하세요.
7. 운영체제, 브라우저 또는 앱 버전, 문제가 발생한 모듈, 표시된 오류 메시지를 기록하세요.
8. 비밀번호, 개인 정보, 교회 정보가 노출되지 않도록 주의하며 화면 캡처를 하세요.

## 앱이 열리지 않거나 로드되지 않아요. 어떻게 하나요?

먼저 새로 고침을 하세요. 웹 버전은 첫 접속 시 인터넷이 필요하며, 앱에서는 **다시 시도** 옵션으로 일시적인 오류를 복구할 수 있습니다.

1. 페이지를 새로 고침하세요.
2. 브라우저를 사용 중이라면 `Ctrl+F5`로 캐시를 갱신하세요.
3. 다른 웹사이트에서 인터넷이 작동하는지 확인하세요.
4. 시크릿(익명) 창에서 테스트하여 확장 프로그램이 간섭하는지 확인하세요.
5. 브라우저 설정에서 해당 사이트의 데이터를 삭제하고 다시 여세요.
6. 오류 화면이 나타나면 **다시 시도**를 클릭하세요.
7. 브라우저 모드에서 bridge가 없다는 안내가 표시되면 사용 가능한 로컬 데이터로 계속하거나, 해당 기기에 맞는 버전을 사용하세요.

문제가 지속되면 점검 목록의 내용과 오류가 나타난 시점을 함께 전달하세요.

## 찬송가 카탈로그가 로드되지 않아요. 어떻게 하나요?

연결 상태를 확인하세요. 앱은 여러 카탈로그 소스를 순차적으로 시도하며, 이미 다운로드한 항목은 오프라인에서도 계속 사용할 수 있습니다.

1. 인터넷 연결을 확인하세요.
2. 앱을 새로 고침하세요.
3. 필요한 경우 이미 다운로드한 찬송가를 열어 연습이나 예배를 계속하세요.
4. 예배 준비 중에는 로컬 데이터를 삭제하지 마세요.
5. 연결이 복구되면 다시 검색해 보세요.

## 찬송가가 다운로드되지 않아요. 어떻게 하나요?

진행률 표시줄을 확인하고 연결을 유지하세요. 앱을 닫아도 진행 상황이 사라지지 않고 저장되어 나중에 이어서 다운로드할 수 있습니다.

1. 인터넷이 안정적인지 확인하세요.
2. 다운로드를 시작하고 잠시 기다리세요.
3. 진행이 멈추면 새로 고침하거나 앱을 다시 여세요.
4. 같은 찬송가를 다시 찾아 다운로드가 재개되었는지 확인하세요.
5. 예배 때는 미리 다운로드가 완료된 것을 확인한 찬송가만 사용하세요.

## 오디오가 재생되지 않아요. 어떻게 하나요?

먼저 컴퓨터의 볼륨과 사운드 출력을 확인하세요. PIANO는 다른 섹션을 탐색하는 동안에도 오디오를 계속 재생하므로, 문제는 선택된 출력 장치나 해당 항목 자체에 있을 수 있습니다.

1. 플레이어가 일시정지가 아닌 재생 상태인지 확인하세요.
2. PIANO와 컴퓨터의 볼륨을 높이세요.
3. 올바른 음향 믹서, 스피커 또는 헤드폰이 선택되어 있고 켜져 있는지 확인하세요.
4. 오디오가 있는 다른 찬송가를 테스트하세요.
5. 데스크톱에서 외부 비디오나 오디오에 문제가 있다면 **설정**을 열고 **외부 플레이어**를 확인하세요.
6. 기본 플레이어를 사용하려면 **시스템 연결**을 선택하거나, 감지된 다른 플레이어를 선택하세요.
7. 예배 시작 전에 다시 테스트하세요.

## 비디오, PDF 또는 프레젠테이션이 잘못된 프로그램으로 열려요. 어떻게 하나요?

데스크톱에서 PIANO는 시스템에 연결된 플레이어 또는 감지/설정된 다른 플레이어를 사용할 수 있습니다.

1. **설정**을 여세요.
2. **외부 플레이어**로 이동하세요.
3. 컴퓨터의 기본 프로그램을 사용하려면 **시스템 연결**을 선택하세요.
4. 필요하면 VLC처럼 감지된 플레이어를 선택하거나, 파일 선택기를 통해 다른 실행 파일을 추가하세요.
5. 해당 항목을 다시 열어 테스트하세요.
6. 되돌리려면 사용자 지정 플레이어를 제거하고 시스템 연결 플레이어를 사용하세요.

## 프로젝션이 표시되지 않아요. 어떻게 하나요?

케이블, TV/프로젝터의 입력, 올바른 모듈의 프로젝션이 활성화되어 있는지 확인하세요. 교회 스크린은 운영자 화면과 분리되어 있습니다.

1. 프로젝터나 TV를 켜세요.
2. TV나 프로젝터에서 올바른 입력을 선택하세요.
3. 컴퓨터와 스크린에 연결된 비디오 케이블을 확인하세요.
4. **미디어 센터**에서 찬송가를 여세요.
5. **프로젝션**을 클릭하세요.
6. 슬라이드를 넘겨 업데이트가 되는지 테스트하세요.
7. 표시되지 않으면 **미디어**나 **성경**처럼 올바른 모듈에서 프로젝션 창을 다시 여세요.
8. 성구나 시계 같은 다른 콘텐츠로 테스트하세요.

## 두 번째 화면이 감지되지 않아요. 어떻게 하나요?

추가 화면의 인식은 컴퓨터, 케이블, 운영체제에 따라 달라집니다. 먼저 물리적 연결과 컴퓨터 자체의 화면 설정을 확인하세요.

1. TV나 프로젝터를 껐다가 다시 켜세요.
2. 케이블을 뽑았다가 다시 연결하세요.
3. 가능하면 다른 케이블이나 다른 입력으로 테스트하세요.
4. 컴퓨터의 화면 설정을 열어 두 번째 화면이 나타나는지 확인하세요.
5. 컴퓨터에 맞는 듀얼 모니터 모드를 선택하세요.
6. 시스템이 화면을 인식하면 PIANO로 돌아가 **프로젝션**을 테스트하세요.

Windows에서는 `Win+P` 단축키로 "복제"와 "확장" 모드를 전환할 수 있습니다. macOS에서는 시스템 설정 → 디스플레이를 열고 화면을 실제 위치에 맞게 드래그하세요. Linux에서는 모니터 설정이 설정 → 디스플레이에 있습니다(배포판에 따라 이름이 다를 수 있음).

## 가사가 어긋나거나 읽기 어려워요. 어떻게 하나요?

프로젝션 설정을 조정하세요. 가사와 성경에는 앱에서 각각의 시각적 옵션이 있습니다.

1. **설정**을 여세요.
2. **프로젝션**에서 배경색, 글자색, 글자 크기와 굵기를 조정하세요.
3. 가로 및 세로 정렬을 조정하세요.
4. 텍스트 상자를 켜고, 배경이 가독성을 해친다면 불투명도/테두리를 변경하세요.
5. 필요하면 배경 이미지를 변경하거나 조정하세요.
6. 성경의 경우 성경 스타일 관련 설정도 확인하세요.
7. 회중이 화면을 보게 될 위치에서 멀리 떨어져 테스트하세요.

## TV나 Palco가 연결되지 않아요. 어떻게 하나요?

네트워크와 페어링을 확인하세요. 매뉴얼에 따르면 같은 네트워크에서의 P2P 연결 또는 서버를 통한 연결이 별도의 탭에서 제공됩니다.

1. TV/Palco 수신기와 제어 기기가 켜져 있는지 확인하세요.
2. P2P의 경우 두 기기를 모두 같은 로컬 네트워크에 연결하세요.
3. 기기들을 분리해 버리는 방문자용 Wi‑Fi는 피하세요.
4. 제어기와 수신기에서 페어링 화면을 다시 여세요.
5. 다시 연결한 후 찬송가와 성구 하나로 테스트하세요.
6. 예배 중 연결에 실패하면 가능할 경우 케이블로 연결된 두 번째 화면을 대안으로 사용하세요.

재연결 후 TV에 이전 콘텐츠나 멈춘 화면이 표시되면, PIANO 쪽에서 재연결을 시도하기 전에 TV에서 Palco 수신기를 닫았다가 다시 여세요(브라우저라면 페이지를 새로 고침). TV는 이미 종료된 이전 연결의 화면을 메모리에 유지하고 있을 수 있습니다.

## 업데이트가 적용되지 않은 것 같아요. 어떻게 하나요?

웹 버전에서는 페이지를 새로 고침할 때 업데이트가 적용됩니다. 예배 시작 몇 분 전이 아니라 예배 전에 업데이트하세요.

1. 페이지를 새로 고침하세요.
2. 캐시를 갱신해야 한다면 `Ctrl+F5`를 사용하세요.
3. 설치 버전을 사용 중이라면 앱을 닫았다가 다시 여세요.
4. 필수 기능이 계속 작동하는지 확인하세요: 검색, 다운로드한 찬송가, 오디오, 예배 순서(liturgia), 프로젝션.
5. 변경 사항으로 인해 사용이 불가능하다면 버전, 브라우저, 증상을 지원팀에 전달하세요.

## 예배 순서, 다운로드, 설정이 사라질 수 있나요?

앱을 닫거나 컴퓨터를 재시작하거나 인터넷이 끊겨도 이미 저장된 로컬 데이터는 사라지지 않아야 합니다. 그래도 기기를 교체하거나 시스템 유지보수를 하기 전에는 백업하세요.

1. **설정**을 여세요.
2. **백업**을 사용하여 데이터와 설정을 내보내세요.
3. 백업본은 변경할 컴퓨터 외부에 보관하세요.
4. 예배에서 의존하기 전에 다른 컴퓨터에서 가져오기를 테스트하세요.
5. 백업본 없이는 앱의 파일이나 데이터를 삭제하지 마세요.
