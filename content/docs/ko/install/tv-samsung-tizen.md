# 삼성 TV에서 PIANO LouvorJA 사용하기

삼성 TV는 **Palco**를 통해 투사 화면을 수신해야 합니다: 다른 기기로 예배를 운영하고 TV에는 교회 화면만 표시됩니다. 다운로드 페이지에서는 게시된 파일이 있을 때 삼성 TV 채널이 나타나며, 사용 가능한 파일이 없으면 TV의 브라우저로 웹 앱에 접속하거나 TV에 호환되는 리시버를 연결하여 사용하세요.

## Palco란 무엇인가요?

Palco는 TV에서 실행되어 PIANO가 전송하는 투사 화면을 표시하는 리시버입니다. 팀은 계속 컴퓨터, 휴대폰 또는 다른 기기로 운영하며, TV는 검색, 예배 순서(liturgia), 제어 버튼을 표시할 필요가 없습니다.

Palco가 연결되면 회중이 다음 내용을 함께 볼 수 있습니다:

- 찬송가 및 콜렉타나(coletâneas)의 가사;
- 성경 구절;
- 시계, 타이머, 카운트다운;
- 운영자가 시작한 기타 투사 화면.

## 사전에 무엇을 준비해야 하나요?

안식일이나 프로그램 전에 네트워크와 기기를 준비하세요.

1. 삼성 TV를 교회 네트워크에 연결합니다.
2. 로컬 페어링을 사용할 경우, 운영용 컴퓨터나 휴대폰을 같은 네트워크에 연결합니다.
3. 다른 기기에서 [다운로드](/download) 페이지를 열어 **Samsung/Tizen**용 다운로드가 활성화되어 있는지 확인합니다.
4. 공식 파일이 존재하면 해당 파일과 다운로드 페이지의 안내만 사용합니다.
5. 파일이 없으면 TV의 브라우저를 열거나 호환되는 리시버를 HDMI 입력에 연결합니다.
6. TV를 켜고 소리를 조절한 상태에서 테스트합니다.

다운로드 페이지에는 Samsung/Tizen 카드가 표시되지만, 실제 파일은 리시버에 게시된 버전이 있어야 사용할 수 있습니다. 이 문서에서는 특정 삼성 스토어를 안내하지 않습니다.

## TV 브라우저를 대안으로 사용하는 방법은?

리시버가 설치되어 있지 않을 때만 브라우저를 대안으로 사용하세요. 탐색 및 호환성은 TV 모델에 따라 다릅니다.

1. 리모컨에서 **Home**을 누릅니다.
2. TV에서 **Apps**, **Internet** 또는 사용 가능한 브라우저를 엽니다.
3. `app.pianolouvorja.com.br`을 입력합니다.
4. 앱이 로드될 때까지 기다립니다.
5. 표시 및 탐색 테스트를 합니다.
6. TV 브라우저가 원활하게 작동하지 않으면 Palco가 실행 중인 컴퓨터나 TV Box를 HDMI에 연결하세요.

삼성 TV에 Android APK를 설치하려고 하지 마세요. Tizen은 Android가 아닙니다.

## TV를 PIANO와 페어링하는 방법은?

페어링은 TV의 리시버를 프로그램을 제어하는 기기와 연결합니다.

1. TV에 연결될 기기에서 Palco 또는 웹 앱을 엽니다.
2. 운영용 컴퓨터나 휴대폰에서 PIANO를 엽니다.
3. **리모컨 및 Palco** 영역에 들어갑니다.
4. 표시된 페어링 방법(같은 네트워크 또는 서버 경유)을 선택합니다.
5. 두 기기에 표시된 데이터 또는 코드를 확인합니다.
6. 연결 확인을 기다립니다.
7. 테스트용 찬송가를 투사합니다.
8. 한 절을 넘겨 TV가 함께 이동하는지 확인합니다.

로컬 페어링을 위해서는 모든 기기가 같은 네트워크에 있어야 합니다. 교회에서 방문자용과 장비용 네트워크를 분리해 사용하는 경우, 운영자와 리시버를 장비용 네트워크에 연결하세요.

## 전체 투사 테스트는 어떻게 하나요?

성도가 도착하기 전에 테스트하세요.

1. **미디어 센터**에서 찬송가를 열고 **투사하기**를 클릭합니다.
2. 절과 후렴을 넘겨 봅니다.
3. **성경**에서 짧은 본문을 투사합니다.
4. **유틸리티**에서 시계와 카운트다운을 테스트합니다.
5. **설정**에서 글자 크기를 키우고 필요하면 대비를 조절합니다.
6. TV에 제어 메뉴가 표시되지 않는지 확인합니다.
7. 운영 기기에서 **ESC**를 눌러 투사를 종료하고 TV 화면이 깨끗이 지워지는지 확인합니다.

## TV에서 가독성을 높이는 방법은?

조정은 운영 기기에서 이루어지며 성도가 보는 화면에 적용됩니다.

1. PIANO에서 **설정**을 엽니다.
2. **투사**에 들어갑니다.
3. 대비가 좋은 배경과 글자색을 선택합니다.
4. 멀리서 읽을 수 있도록 글자 크기를 키웁니다.
5. 밝은 이미지 위에서는 글자 상자를 활성화합니다.
6. 가로·세로 정렬을 조절합니다.
7. 강당에서 가장 먼 지점에서 다시 테스트합니다.

## 페어링 목록에 TV가 나타나지 않으면?

1. TV/리시버와 운영자가 같은 네트워크에 있는지 확인합니다.
2. Palco 또는 TV 브라우저를 닫았다가 다시 엽니다.
3. TV가 격리된 게스트 네트워크에 있지 않은지 확인합니다.
4. 리시버 또는 TV만 재시작한 뒤 다시 페어링을 시도합니다.
5. 해결되지 않으면 일시적으로 HDMI 케이블을 사용해 투사하고 예배를 중단하지 마세요.

## 운영 기기에서 프로그램을 준비하는 방법은?

TV는 투사 화면을 수신할 뿐이며, 준비는 팀이 사용하는 컴퓨터, 휴대폰 또는 태블릿에서 이루어져야 합니다.

1. 운영 기기에서 **예배 순서(Liturgia)**를 엽니다.
2. 예배의 각 순서별로 카테고리를 만듭니다.
3. 찬송가, 구절, 파일, 메모를 추가합니다.
4. 실제 프로그램에 맞게 항목 순서를 재배열합니다.
5. 필요한 찬송가와 콘텐츠를 미리 다운로드합니다.
6. 저장하고 프로그램을 인도할 사람과 함께 검토합니다.
7. TV를 페어링하기 전에 첫 번째 항목을 준비해 둡니다.

## 삼성 TV에서 중단을 피하는 방법은?

1. TV를 대기 모드가 아닌 콘센트에 연결된 상태로 켜 둡니다.
2. 자동 꺼짐 타이머가 활성화되어 있으면 일시적으로 해제합니다.
3. 프로그램 전에 Wi-Fi 네트워크를 확인합니다.
4. 리모컨에 좋은 배터리를 준비해 둡니다.
5. 예배 중에는 네트워크 설정을 변경하지 마세요.
6. TV에서 다른 앱을 열지 마세요.
7. 비상 대책으로 HDMI 케이블을 항상 준비해 둡니다.

## Palco에서 시계와 타이머를 사용하는 방법은?

1. 운영 기기에서 **유틸리티**를 엽니다.
2. **시계**, **타이머** 또는 **카운트다운**을 선택합니다.
3. 필요하면 시계의 색과 형식을 조절합니다.
4. 정해진 시점에 타이머나 카운트다운을 시작합니다.
5. TV에서 잘 보이는지 확인합니다.
6. 팀이 특정 시점을 기록해야 할 때는 타이머에 마크를 저장합니다.
7. 예배 순서의 다음 항목으로 넘어갈 때 투사를 종료합니다.

## 마지막 순간에 순서가 바뀌면 어떻게 하나요?

1. 운영자를 주 기기에 머물게 합니다.
2. **미디어 센터**의 검색으로 필요한 찬송가를 찾습니다.
3. 평소처럼 투사하고 절을 넘기면 TV가 업데이트를 수신합니다.
4. 중요한 변경 사항은 예배 순서 메모에 기록합니다.
5. 투사가 정상 작동 중이라면 TV를 재시작하지 마세요.
6. 리시버에 문제가 생기면 일시적으로 HDMI로 전환합니다.
7. 페어링은 예배 후 여유를 갖고 다시 설정하세요.

## 예배 전 최종 체크리스트

1. 선택한 기기에서 PIANO가 열리는지 확인합니다.
2. 찬송가와 자료가 사용 가능한지 확인합니다.
3. 예배 순서가 올바른 순서로 되어 있는지 확인합니다.
4. 교회 화면이 테스트 투사를 수신하는지 확인합니다.
5. 강당 뒤쪽에서 글자 크기와 대비를 확인합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 운영을 담당할 사람을 지정해 둡니다.
