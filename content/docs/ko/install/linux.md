# Linux에 PIANO LouvorJA 설치하기

Linux에서는 공식 AppImage를 다운로드하는 것이 가장 간단한 방법입니다. Snapcraft를 사용할 수도 있으며, Flathub는 현재 심사 중이므로 스토어에 나타나기 전까지는 다른 공식 채널을 사용해야 합니다.

## 어떤 설치 방법을 선택해야 하나요?

교회 컴퓨터에서 이미 잘 작동하는 채널을 선택하세요.

- **AppImage:** 공식 페이지에서 다운로드하는 단일 파일입니다. 다운로드 폴더에 접근할 수 있다면 가장 간단한 방법입니다.
- **Snapcraft:** Snap 스토어를 이미 사용하는 배포판에 적합한 옵션입니다.
- **Flathub:** 현재 심사 중입니다. 스토어에서 PIANO를 사용할 수 있게 된 후에만 사용하세요. 그때까지는 AppImage나 Snapcraft를 선택하세요.

모든 방법은 공식 [다운로드](/download) 페이지에서 접근할 수 있으며, 해당 페이지는 공개된 버전으로 연결됩니다.

## ARM64와 X64 중 어떻게 선택하나요?

다운로드 페이지에 두 가지 버전의 AppImage가 표시될 수 있습니다.

1. 컴퓨터가 일반적인 Intel 또는 AMD 프로세서를 사용한다면 **X64**를 선택하세요.
2. ARM 프로세서를 사용한다면 **ARM64**를 선택하세요.
3. 잘 모르겠다면, 다운로드하기 전에 이전에 컴퓨터를 설정한 사람에게 도움을 요청하세요.
4. 무작정 파일을 테스트하는 것은 피하세요. 잘못된 아키텍처를 사용하면 실행되지 않습니다.

Intel 또는 AMD를 사용하는 교회 컴퓨터는 보통 X64를 사용합니다.

## AppImage로 설치하는 방법은?

AppImage는 다운로드한 후 실행 권한을 부여하고 열면 되는 파일입니다.

1. [다운로드](/download) 페이지를 엽니다.
2. **Linux**를 선택하고 컴퓨터에 맞는 AppImage를 다운로드합니다.
3. 파일 관리자를 열고 **Downloads** 폴더로 이동합니다.
4. AppImage 파일을 마우스 오른쪽 버튼으로 클릭합니다.
5. **속성**을 선택합니다.
6. **권한** 탭을 엽니다.
7. **파일을 프로그램으로 실행 허용**과 비슷한 옵션에 체크합니다.
8. 속성 창을 닫습니다.
9. AppImage를 두 번 클릭하여 PIANO를 엽니다.

옵션 이름은 Linux 배포판에 따라 조금씩 다를 수 있습니다. **권한**과 파일 실행 허용 관련 설정을 찾아보세요.

## 터미널만 사용할 수 있다면?

가능하면 파일 관리자를 사용하는 것을 권장합니다. 교회의 기술 담당자가 터미널을 사용한다면, 파일이 저장된 폴더에서 다음 명령으로 실행 권한을 부여할 수 있습니다:

```bash
chmod +x 파일명.AppImage
```

이후에는 파일 관리자로 파일을 열면 됩니다. PIANO를 일상적으로 사용할 때 터미널은 필요하지 않습니다.

## Snapcraft로 설치하는 방법은?

공식 다운로드 페이지를 통해 PIANO에 공개된 Snapcraft 채널로 이동하세요.

1. [다운로드](/download) 페이지를 엽니다.
2. **Linux** 옵션을 선택하고 Snapcraft 채널을 찾습니다.
3. 스토어 링크를 엽니다.
4. 사용 중인 Linux 배포판 또는 기술 담당자가 안내하는 설치 절차를 따릅니다.
5. 애플리케이션 메뉴에서 **PIANO LouvorJA**를 찾습니다.
6. 앱을 열고 초기 테스트를 진행합니다.

Snap 스토어가 설치되어 있지 않거나 열리지 않는다면, 안식일에 시스템을 변경하려 하지 말고 AppImage를 사용하세요.

## Flathub로 설치할 수 있나요?

아직은 주요 방법으로 사용할 수 없습니다. Flathub 제출이 심사 중이며, 스토어 승인에 따라 사용 가능 여부가 결정됩니다.

1. [다운로드](/download) 페이지를 엽니다.
2. PIANO용 Flathub 버튼이 활성화되어 있는지 확인합니다.
3. 버튼이 있다면 클릭하여 스토어에서 직접 설치합니다.
4. 버튼이 없거나 페이지에서 이용 불가라고 안내하면 AppImage나 Snapcraft를 사용하세요.

공식 페이지에서 확인하기 전까지는 Flathub를 사용할 수 있는 것으로 간주하지 마세요.

## 처음 실행할 때는 무엇을 해야 하나요?

특히 인터넷 없이 사용할 콘텐츠를 예배 전에 미리 준비하세요.

1. PIANO LouvorJA를 엽니다.
2. 카탈로그 초기 준비가 완료될 때까지 기다립니다.
3. **미디어 센터**에서 구약성서 찬송가(한국침례교 발행)의 찬송가와 프로그램에 사용할 찬송집을 검색하고 다운로드합니다.
4. **예배 순서**에서 카테고리, 찬송가, 성경 구절, 로컬 파일로 예배 순서를 만듭니다.
5. **설정**에서 프로젝션 스타일을 조정합니다.
6. 교회 스크린에서 찬송가, 성경 구절, 시계를 테스트합니다.

다운로드, 예배 순서, 설정은 기기에 저장됩니다. 앱을 닫아도 준비된 내용은 사라지지 않습니다.

## AppImage가 열리지 않을 때는?

아무것도 삭제하지 말고 먼저 기본적인 사항을 확인하세요.

1. 컴퓨터 아키텍처에 맞는 올바른 파일을 다운로드했는지 확인합니다.
2. **속성**과 **권한**을 다시 확인합니다.
3. 파일이 USB나 네트워크에 있다면 **문서** 같은 로컬 폴더로 이동합니다.
4. 다운로드가 중단되었다면 공식 페이지에서만 다시 다운로드합니다.
5. 그래도 문제가 지속되면 가능한 경우 Snapcraft 채널이나 웹 앱을 사용하여 예배 중 문제가 없도록 합니다.

## 팀을 위한 바로가기를 만드는 방법은?

AppImage를 테스트한 후, 팀이 알아볼 수 있는 폴더에 보관하세요.

1. **문서**에 **PIANO LouvorJA**라는 이름의 폴더를 만들거나 선택합니다.
2. 테스트된 AppImage를 해당 폴더로 이동합니다.
3. 다시 열어 정상 작동하는지 확인합니다.
4. 파일 관리자가 **즐겨찾기에 추가** 또는 **바로가기 만들기** 옵션을 제공하면 활용하세요.
5. 팀에게 파일 위치를 알려줍니다.
6. 파일이 정상 작동한다고 해서 삭제하지 마세요. 그것이 앱입니다.
7. 비슷한 이름의 오래된 사본이 여러 개 생기지 않도록 주의하세요.

## 완전한 예배 순서를 준비하는 방법은?

1. **예배 순서**를 열고 새 프로그램 만들기를 선택합니다.
2. 예배의 각 순서를 구분할 카테고리를 추가합니다.
3. 찬송가, 로컬 미디어, 링크 또는 메모를 추가합니다.
4. 팀이 시간을 확인해야 한다면 카테고리별 시간을 입력합니다.
5. 항목을 드래그하여 최종 순서대로 정렬합니다.
6. 저장하고 프로그램 담당자와 함께 검토합니다.
7. 예배 중에는 순서를 따라가며 완료된 항목을 표시합니다.

## 안전하게 프로젝션하는 방법은?

1. **미디어 센터**에서 찬송가를 엽니다.
2. **프로젝션**을 클릭합니다.
3. 두 번째 스크린이나 TV를 확인합니다.
4. 텍스트를 넘기며 동기화를 점검합니다.
5. **성경**에서 구절을 열어 같은 테스트를 합니다.
6. **설정**에서 대비와 글자 크기를 조정합니다.
7. 테스트가 끝나면 **ESC**로 프로젝션을 종료합니다.

## 교회에서 돌발 상황을 피하는 방법은?

1. 다운로드와 테스트는 미리 마쳐둡니다.
2. 충전기, 비디오 케이블, 어댑터를 손이 닿는 곳에 둡니다.
3. 프로젝터나 TV가 올바른 입력에 연결되어 있는지 확인합니다.
4. 예배 직전에 Linux 배포판을 업데이트하지 마세요.
5. 인터넷이 있는 경우를 대비해 웹 앱을 대안으로 준비해 둡니다.
6. PIANO를 여는 방법을 두 번째 담당자에게도 설명해 둡니다.
7. 팀이 컴퓨터를 교체할 때를 대비해 설정을 백업해 둡니다.

## 예배 전 최종 체크리스트

1. 선택한 기기에서 PIANO가 열리는지 확인합니다.
2. 찬송가와 자료가 모두 준비되어 있는지 확인합니다.
3. 예배 순서가 올바른 순서로 되어 있는지 확인합니다.
4. 교회 스크린에 테스트 프로젝션이 표시되는지 확인합니다.
5. 강당 뒤에서도 글자 크기와 대비가 확인되는지 점검합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 운영 담당자를 지정해 둡니다.
