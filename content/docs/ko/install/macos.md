# macOS에 PIANO LouvorJA 설치하기

Mac에 맞는 DMG 파일을 다운로드하고, PIANO를 **응용 프로그램** 폴더로 드래그한 후 열어주세요. M1 칩 이상의 Mac은 ARM64를, Intel Mac은 X64를 사용합니다. macOS가 첫 실행을 차단하면 마우스 오른쪽 클릭 메뉴를 통해 열어주세요.

## 내 Mac이 Apple Silicon인지 Intel인지 확인하는 방법

칩 종류에 따라 다운로드할 파일이 달라집니다.

1. 화면 왼쪽 상단의 **Apple** 메뉴를 클릭합니다.
2. **이 Mac에 관하여**를 선택합니다.
3. **칩** 또는 **프로세서** 항목을 확인합니다.
4. **Apple M1**, **M2**, **M3**, **M4** 또는 다른 Apple 칩이 표시되면 **ARM64**를 선택하세요.
5. **Intel**이 표시되면 **X64**를 선택하세요.

잘 모르겠으면 두 파일을 모두 다운로드하지 마세요. 계속하기 전에 **이 Mac에 관하여** 화면을 다시 확인하세요.

## 올바른 파일은 어디에서 다운로드하나요?

공식 파일은 macOS용 PIANO LouvorJA 릴리스에서 DMG 형식으로 배포됩니다.

1. [다운로드](/download) 페이지를 엽니다.
2. **macOS**를 선택합니다.
3. Apple Silicon이라면 **DMG ARM64**를, Intel이라면 **DMG X64**를 선택합니다.
4. 다운로드가 끝날 때까지 기다립니다.
5. **다운로드** 폴더를 엽니다.

항상 공식 페이지에서만 다운로드하세요. 비슷한 이름으로 배포되는 제3자의 파일은 올바른 버전이 아닐 수 있습니다.

## DMG는 어떻게 설치하나요?

DMG를 열면 응용 프로그램과 응용 프로그램 폴더가 담긴 작은 창이 나타납니다.

1. 다운로드한 DMG 파일을 두 번 클릭합니다.
2. 설치 창이 나타날 때까지 기다립니다.
3. **PIANO LouvorJA**를 창에 표시된 **응용 프로그램** 폴더로 드래그합니다.
4. 복사가 끝날 때까지 기다립니다.
5. **파인더(Finder)**를 엽니다.
6. **응용 프로그램**으로 이동합니다.
7. **PIANO LouvorJA**를 두 번 클릭합니다.
8. 실행이 확인되면 파인더에서 설치 디스크를 추출합니다.

앱이 DMG 안에서만 실행되도록 두지 마세요. **응용 프로그램** 폴더로 복사하면 다운로드 파일에 의존하지 않고 실행됩니다.

## macOS가 첫 실행을 차단했습니다. 어떻게 해야 하나요?

인터넷에서 다운로드한 앱에서는 이런 일이 생길 수 있습니다. 마우스 오른쪽 클릭 메뉴로 한 번 열어주세요.

1. **파인더**를 열고 **응용 프로그램**으로 이동합니다.
2. **PIANO LouvorJA**를 찾습니다.
3. 아이콘을 마우스 오른쪽 버튼으로 클릭하거나 Control 키를 누른 채 클릭합니다.
4. **열기**를 선택합니다.
5. 확인 메시지가 나오면 다시 **열기**를 클릭합니다.
6. 이후에는 Launchpad, Dock 또는 응용 프로그램에서 정상적으로 열면 됩니다.

필요하지 않은 경우 Mac의 보안 설정을 변경하지 마세요. 이 절차는 열기로 선택한 앱에만 적용됩니다.

## 첫 실행 시 무엇을 해야 하나요?

PIANO는 콘텐츠 목록을 준비하며 정보를 기기 자체에 보관합니다.

1. **응용 프로그램**에서 PIANO LouvorJA를 엽니다.
2. 첫 준비 과정에서는 인터넷을 연결해 두세요.
3. 필요하면 상단의 **−** 및 **＋** 버튼으로 화면 크기를 조절합니다.
4. **미디어 센터**에서 구약성서 찬송가의 찬송가를 검색합니다.
5. 예배에서 사용할 찬송가와 선곡집을 다운로드합니다.
6. **예배 순서**에서 프로그램을 작성합니다.
7. **설정**을 열고 색상, 배경, 투사 크기를 조절합니다.

다운로드는 이후에도 계속할 수 있습니다. 앱을 닫더라도 저장된 진행 상태는 다시 열 때 그대로 유지됩니다.

## 예배 전에 어떻게 테스트하나요?

간단한 테스트로 찬양이나 말씀 시간의 당황스러운 상황을 피할 수 있습니다.

1. **미디어 센터**에서 찬송가를 엽니다.
2. **투사**를 클릭합니다.
3. 절과 후렴을 넘겨가며 확인합니다.
4. **성경**을 열어 구절을 선택하고 투사합니다.
5. **유틸리티**에서 시계, 타이머 또는 카운트다운을 테스트합니다.
6. **설정**에서 글자가 작아 보이면 글꼴 크기를 키웁니다.

TV, 프로젝터 또는 다른 화면을 사용하려면 미리 연결한 후 팀과 함께 전체 테스트를 하세요. PIANO는 조작 화면과 회중이 보는 화면을 분리합니다.

## PIANO를 어떻게 깔끔하게 관리하나요?

준비된 컴퓨터는 안식일 봉사를 수월하게 만듭니다.

1. 재설치가 필요한 경우를 대비해서만 DMG를 보관하세요. 앱은 **응용 프로그램** 폴더에서 실행됩니다.
2. 찬송가, 선곡집, 예배 순서 콘텐츠는 미리 다운로드해 두세요.
3. 예배 순서에서 **안식일 학교**, **찬양**, **봉헌**, **말씀** 같은 카테고리를 사용하세요.
4. 컴퓨터를 교체하기 전에 **설정**에서 백업하세요.
5. 프로그램 시작 전에 미디어 파일을 테스트하세요.

## 프로그램 작성 전에 예배 순서를 어떻게 준비하나요?

예배 순서는 예배 항목들을 모아 두어, 프로그램 진행 중 콘텐츠를 찾느라 헤매지 않도록 도와줍니다.

1. **예배 순서**를 열고 새 프로그램을 만듭니다.
2. **환영**, **찬양**, **말씀**, **마침** 같은 카테고리를 만듭니다.
3. 음악, 구절, 동영상, 이미지, PDF 또는 프레젠테이션을 추가합니다.
4. 팀을 위한 메모를 작성하세요. 메모는 회중 화면에 표시되지 않습니다.
5. 항목을 드래그하여 순서를 조정합니다.
6. 저장한 후 다시 열어 확인합니다.
7. 예배 중에는 항목을 하나씩 넘기며 완료된 내용을 확인합니다.

## 인터넷 없이 사용할 콘텐츠는 어떻게 준비하나요?

PIANO에서 이미 다운로드한 콘텐츠는 연결이 끊겨도 Mac에서 계속 사용할 수 있습니다.

1. 주중에 인터넷에 연결하세요.
2. 사용할 찬송가를 엽니다.
3. 필요한 항목에서 **download**를 누릅니다.
4. 진행 막대가 끝날 때까지 기다립니다.
5. 예배 순서의 동영상, PDF, 로컬 프레젠테이션 파일도 확인하세요.
6. 새로 검색하지 않고도 작동하는지 테스트하세요.
7. 앱을 닫아도 다운로드 진행 상태는 보존됩니다.

## TV에서 Stage를 사용하는 방법

네트워크에 연결된 TV가 회중 화면으로 사용될 때 Stage를 활용하세요.

1. TV 또는 리시버를 교회 네트워크에 연결합니다.
2. TV에 연결된 기기에서 Stage를 엽니다.
3. Mac에서 **원격 조종 및 Stage** 영역을 엽니다.
4. 화면 안내에 따라 로컬 페어링 또는 서버 방식을 선택합니다.
5. 표시된 코드 또는 정보를 확인합니다.
6. 찬송가를 투사하고 절을 하나 넘겨봅니다.
7. TV에 투사 화면만 표시되는지 확인합니다.

## 예배 전 최종 체크리스트

1. PIANO가 선택한 기기에서 열리는지 확인합니다.
2. 찬송가와 자료가 준비되어 있는지 확인합니다.
3. 예배 순서가 올바른 순서로 되어 있는지 확인합니다.
4. 교회 화면에 테스트 투사가 표시되는지 확인합니다.
5. 글자 크기와 대비가 강당 뒤쪽에서도 잘 보이는지 확인합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 조작을 담당할 사람을 정해 둡니다.
