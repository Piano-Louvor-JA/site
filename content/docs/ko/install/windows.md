# Windows에 PIANO LouvorJA 설치하기

가장 간단한 방법은 Microsoft Store를 통해 설치하는 것입니다. 원하시면 공식 다운로드 페이지에서 포터블 EXE 파일을 받을 수도 있습니다. 그런 다음 PIANO를 열어 초기 설정을 마치고, 한 모니터는 운영자용, 다른 모니터는 교회용으로 사용하세요.

## Microsoft Store로 설치하는 방법은?

Microsoft Store는 앱 설치와 업데이트를 관리해 줍니다.

1. 공식 [다운로드](/download) 페이지를 엽니다.
2. **Windows**를 선택하고 Microsoft Store 옵션을 엽니다.
3. Store에서 **LouvorJA**를 검색합니다. 직접 링크를 받았다면 해당 링크는 `9N1WPDQKFLR9` 제품을 사용합니다.
4. **가져오기** 또는 **설치**를 클릭합니다.
5. 다운로드가 끝날 때까지 기다립니다.
6. **열기**를 클릭하거나 시작 메뉴에서 **LouvorJA PIANO**를 찾습니다.

메신저나 알 수 없는 사이트로 받은 복사본은 설치하지 마세요. 반드시 공식 페이지를 통해 Store로 이동하세요.

## 포터블 EXE를 사용하는 방법은?

EXE는 Store를 사용하지 않으려는 분들을 위한 공식 대안입니다. GitHub에 게시된 버전으로 제공되며 다운로드 페이지에서 받을 수 있습니다.

1. [다운로드](/download) 페이지를 엽니다.
2. **Windows** 영역에서 EXE 다운로드를 선택합니다.
3. 파일 다운로드가 끝나기를 기다립니다.
4. **Downloads** 폴더를 엽니다.
5. PIANO EXE 파일을 두 번 클릭합니다.
6. Windows가 실행 허가를 요청하면 확인합니다.
7. **문서/PIANO LouvorJA**처럼 찾기 쉬운 폴더에 파일을 보관하세요.

포터블 버전은 별도의 설치 과정 없이 실행됩니다. 바탕 화면에 바로 가기를 만드는 것은 정상적으로 열리는 것을 확인한 후에 하세요.

## 첫 실행 시 해야 할 일은?

처음 실행하면 PIANO가 콘텐츠 목록을 준비하고 초기 설정 화면을 표시합니다. 이때는 인터넷을 연결해 두세요. 준비가 진행되는 동안 앱을 둘러볼 수는 있습니다.

1. PIANO LouvorJA를 엽니다.
2. 시작 화면이 준비를 마칠 때까지 기다립니다.
3. 헤더의 **−** 및 **＋** 버튼으로 화면 배율을 조절합니다.
4. **미디어 센터**를 열어 구약 찬송가(Adventist Hymnal)의 찬송가나 콘텐츠 모음을 검색합니다.
5. 예배에서 사용할 찬송가는 미리 다운로드하세요. 앱이 닫혀도 다운로드 진행 상황은 저장됩니다.
6. **예배 순서**를 열어 안식일 학교, 찬양, 말씀 등 순서를 구성합니다.
7. **설정**에서 교회 화면에 맞게 배경, 색상, 글자 크기를 조절합니다.

다운로드하고 설정한 내용은 컴퓨터에 저장됩니다. 여기에는 찬송가, 다운로드 진행 상황, 예배 순서, 환경 설정이 포함됩니다.

## 두 대의 모니터를 준비하는 방법은?

한 모니터는 PIANO 조작용, 다른 모니터는 회중용으로 사용하세요. 운영자는 검색, 버튼, 다음 항목을 보고, 교회는 투사 화면만 봅니다.

1. 프로젝터, TV 또는 두 번째 모니터를 컴퓨터에 연결합니다.
2. Windows에서 **설정**을 엽니다.
3. **시스템**으로 들어간 다음 **디스플레이**로 이동합니다.
4. **다중 디스플레이**에서 **디스플레이 확장**을 선택합니다.
5. 모니터 아이콘을 드래그하여 실제 배치와 일치시킵니다.
6. PIANO를 열고 테스트 투사를 시작합니다.
7. 교회용 창을 두 번째 모니터나 TV로 옮깁니다.
8. 예배 전에 가사 한 곡, 성구 한 구절, 시계가 제대로 나오는지 테스트합니다.

화면 복제 모드는 피하세요. 조작 화면이 그대로 교회에 보이게 됩니다. **확장** 모드만이 운영자와 투사 화면을 분리해 줍니다.

## 찬송가나 성구를 투사하는 방법은?

회중이 도착하기 전에 전체 테스트를 해 두세요.

1. **미디어 센터**에서 찬송가를 검색합니다.
2. 검색 결과를 열고 **투사**를 클릭합니다.
3. 절이나 후렴을 넘기면 교회 화면도 함께 바뀝니다.
4. **성경**에서 버전, 책, 장, 절을 선택합니다.
5. **투사**를 클릭하여 해당 구절을 두 번째 화면으로 보냅니다.
6. 투사를 종료하려면 **ESC**를 누르고 확인합니다.

곡에서 구간이 선택되지 않았을 때는 앨범 커버와 제목이 표시될 수 있습니다. 환영 시간이나 찬양 전에 유용합니다.

## 투사 가독성을 조절하는 방법은?

예배 전에 회중이 앉는 공간과 거리에 맞게 화면을 조정하세요.

1. **설정**을 엽니다.
2. **투사** 옵션으로 들어갑니다.
3. 배경색, 글자색, 글꼴 크기를 조절합니다.
4. 가로 및 세로 정렬을 선택합니다.
5. 밝은 배경이나 밝은 이미지를 사용할 때는 텍스트 상자를 활성화하세요.
6. 가능하면 교회 맨 뒷줄에서 테스트합니다.
7. 설정을 저장하면 컴퓨터에 그대로 유지됩니다.

찬송가 가사는 대비와 크기를 우선하세요. 아무리 아름다운 이미지라도 교회가 가사를 따라올 수 없다면 도움이 되지 않습니다.

## 영상이나 오디오가 엉뚱한 프로그램으로 열릴 때는?

Windows에서 PIANO는 영상과 미디어 파일을 여는 방식을 선택할 수 있습니다.

1. **설정**을 엽니다.
2. **외부 플레이어**를 찾습니다.
3. Windows 기본 프로그램을 사용하려면 **시스템 연결 프로그램**을 선택합니다.
4. 다른 플레이어가 감지되면 해당 플레이어를 선택하세요.
5. 예배 순서의 영상이나 오디오로 테스트해 봅니다.

## 다음 예배를 위해 미리 준비하는 방법은?

한 주 중에 여유 있게 준비해 두면 토요일 팀의 작업이 크게 줄어듭니다.

1. 이전 예배 순서를 열어 참고 자료로 삼으세요(필요한 경우).
2. 보조 제목, 시간, 프로그램 카테고리를 최신 상태로 update하세요.
3. 아직 컴퓨터에 없는 음악, 영상, 파일은 미리 다운로드하세요.
4. 각 미디어 항목을 열어 정상 작동하는지 확인합니다.
5. 컴퓨터를 바꾸기 전에 **설정**에서 백업을 만드세요.
6. 노트북을 전원에 연결하고 충전기를 가까이 두세요.
7. 시작 15분 전에 간단한 투사 테스트를 합니다.

## 투사 화면이 갱신되지 않을 때는?

1. 두 번째 모니터가 Windows에 계속 연결되어 있는지 확인합니다.
2. 투사 창이 올바른 모듈(**미디어** 또는 **성경** 등)에서 열려 있는지 확인합니다.
3. 사용 중인 항목의 투사를 다시 시작합니다.
4. Windows가 여전히 **디스플레이 확장** 모드인지 확인합니다.
5. 필요하면 PIANO를 닫았다가 다시 여세요. 저장된 콘텐츠는 그대로 유지됩니다.
6. 교회에 예비 케이블이 있다면 사용하세요.

## 팀으로 함께 운영하는 방법은?

한 사람은 조작을, 다른 한 사람은 교회 화면을 점검하도록 정하세요.

1. 운영자가 예배 순서를 열고 항목을 진행합니다.
2. 두 번째 사람이 가사, 성구, 대비가 투사 화면에 제대로 나오는지 확인합니다.
3. 시작 전에 두 사람이 찬양과 말씀 순서를 함께 점검합니다.
4. 변경 사항이 있으면 예배 순서에 메모를 남겨 팀에게 알리세요.
5. 진행 중에는 여러 사람이 같은 컴퓨터를 만지지 않도록 하세요.

## 예배 전 최종 점검 목록

1. PIANO가 선택한 기기에서 열리는지 확인합니다.
2. 찬송가와 자료가 준비되어 있는지 확인합니다.
3. 예배 순서가 올바른 순서인지 확인합니다.
4. 교회 화면에 테스트 투사가 나오는지 확인합니다.
5. 강당 뒷배경에서 글자 크기와 대비를 확인합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 운영 담당자를 한 명 지정해 둡니다.
