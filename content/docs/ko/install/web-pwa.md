# PIANO LouvorJA를 브라우저와 앱으로 사용하기

[app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)에서 PIANO를 바로 열 수 있습니다. Chrome, Edge 또는 Android에서는 홈 화면에 앱으로 추가할 수 있으며, 처음 불러온 이후에는 기기에 이미 저장된 콘텐츠를 기준으로 오프라인에서도 계속 사용할 수 있습니다.

## 아무것도 설치하지 않고 PIANO를 열려면?

브라우저는 가장 빠르게 시작할 수 있는 방법으로, PIANO를 사용해 보거나 다른 컴퓨터를 사용하거나 교회 밖 프로그램을 지원할 때 유용합니다.

1. 최신 브라우저를 엽니다.
2. `app.pianolouvorja.com.br`을 입력합니다.
3. 앱이 불러와질 때까지 기다립니다.
4. **미디어 센터**를 열어 찬송가와 찬송집을 찾습니다.
5. **예배 순서**를 사용하여 프로그램을 구성합니다.
6. 예배 시작 전에 프로젝션을 테스트합니다.

다중 화면 프로젝션을 위한 최상의 환경을 위해서는 컴퓨터가 가장 실용적인 선택입니다. 브라우저는 태블릿, 휴대폰, 공용 기기에서도 여전히 유용합니다.

## 컴퓨터의 Chrome 또는 Edge에서 앱으로 설치하려면?

PWA 설치를 하면 PIANO를 별도 창으로 열어주는 바로 가기가 생겨, 브라우저에서 탭을 찾을 필요가 없습니다.

1. Chrome 또는 Edge에서 [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)을 엽니다.
2. 주소창 옆에 나타나는 설치 아이콘을 찾습니다.
3. **설치** 또는 **PIANO LouvorJA 설치**를 클릭합니다.
4. 설치를 확인합니다.
5. 앱 메뉴나 바탕 화면에 생성된 바로 가기로 PIANO를 엽니다.
6. 찬송가, 성경, 프로젝션을 테스트합니다.

아이콘이 나타나지 않으면 브라우저의 점 세 개 메뉴를 열어 **앱 설치**, **이 페이지를 앱으로 설치** 또는 유사한 옵션을 찾아보세요.

## Android에서 홈 화면에 추가하려면?

Android에서는 PIANO를 홈 화면 아이콘으로 사용할 수 있습니다.

1. Chrome에서 [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)을 엽니다.
2. 점 세 개 메뉴를 누릅니다.
3. **홈 화면에 추가** 또는 **앱 설치**를 선택합니다.
4. 이름을 확인하고 **추가** 또는 **설치**를 누릅니다.
5. 홈 화면 또는 앱 목록에서 PIANO 아이콘을 찾습니다.
6. 아이콘으로 열어 예배 전에 테스트합니다.

브라우저에 따라 문구가 다를 수 있습니다. 사이트를 앱으로 추가하거나 홈 화면에 추가하는 옵션을 찾아보세요.

## 브라우저에서 PIANO가 오프라인으로 작동하나요?

처음 불러온 후에는 기기에 이미 저장된 데이터와 콘텐츠를 기준으로 PWA가 오프라인에서도 계속 사용 가능할 수 있습니다. 예배 전에 인터넷이 있을 때 모든 것을 준비하세요.

1. 인터넷이 있을 때 PIANO를 최소 한 번 엽니다.
2. 사용할 찬송가를 미리 검색하고 다운로드합니다.
3. 예배 순서를 열고 필요한 항목들이 준비되어 있는지 확인합니다.
4. 인터넷이 아직 연결되어 있을 때 프로젝션을 테스트합니다.
5. 이후 연결이 끊기더라도 기기에 준비되어 저장된 내용을 사용합니다.

아직 불러오지 않은 콘텐츠에 의존하는 일은 프로그램 시작을 기다리지 말고 미리 처리하세요. 최초 접속과 새로운 업데이트에는 인터넷 연결이 필요합니다.

## 언제 브라우저, PWA, 설치된 앱을 사용해야 하나요?

교회의 사용 형태에 따라 선택하세요.

| 상황 | 가장 좋은 선택 |
| ----------------------------------------------------------------- | --------------------------------------------- |
| 빠르게 사용해 보거나 빌린 컴퓨터 사용 | `app.pianolouvorja.com.br`의 브라우저 |
| 항상 같은 컴퓨터에서 전통 프로그램 설치 없이 사용 | Chrome 또는 Edge로 설치한 PWA |
| 듀얼 모니터 프로젝션과 교회의 고정 운영 | Windows, macOS 또는 Linux용 앱 |
| 휴대폰이나 태블릿에서 제어 | 브라우저의 PWA 또는 홈 화면에 추가 |
| 네트워크에 연결되어 프로젝션을 수신하는 TV | 호환 기기의 스테이지 화면 |

운영자 화면과 교회 화면이 분리된 안정적인 운영이 필요하다면 설치 버전이 더 적합합니다.

## PWA에서 프로그램을 준비하려면?

예배 준비 방법은 동일합니다: 미리 준비하고 프로그램 중에는 순서대로 진행하세요.

1. **미디어 센터**에서 찬송가를 이름이나 가사 일부로 검색합니다.
2. 찬송가를 다운로드하여 기기에서 콘텐츠를 사용할 수 있도록 합니다.
3. **예배 순서**에서 **환영**, **안식교 학교**, **찬양**, **말씀**, **마무리** 같은 카테고리를 만듭니다.
4. 음악, 영상, 이미지, PDF, 프레젠테이션, 링크, 팀 메모를 추가합니다.
5. 항목을 드래그하여 순서를 조정합니다.
6. 저장한 후 다시 열어 확인합니다.
7. 예배 중에는 항목을 하나씩 진행하며 완료된 항목을 확인합니다.

## 교회 화면을 알아보기 쉽게 만들려면?

1. **설정**을 엽니다.
2. **프로젝션**으로 들어갑니다.
3. 대비가 강한 색상을 선택합니다.
4. 회중과의 거리에 따라 글꼴 크기를 50%에서 200% 사이로 조정합니다.
5. 배경이 밝은 이미지일 경우 텍스트 상자를 활성화합니다.
6. 정렬과 배경을 조정합니다.
7. 시작 전에 프로젝터나 TV에서 테스트합니다.

## PWA에서 성경과 유틸리티를 사용하려면?

1. **성경**을 엽니다.
2. 버전, 책, 장과 절(또는 여러 절)을 선택합니다.
3. **프로젝션**을 클릭하여 본문을 교회 화면으로 보냅니다.
4. 시계가 필요하면 **유틸리티**를 열고 **시계**를 선택합니다.
5. 색상, 12시간 또는 24시간 형식, 초 표시를 조정합니다.
6. 시간을 관리하려면 **타이머** 또는 **카운트다운**을 사용합니다.
7. 프로그램 시작 전에 모두 테스트합니다.

## PIANO를 원격으로 제어하려면?

1. 기본 기기에서 **리모트 컨트롤 및 스테이지** 영역을 엽니다.
2. 같은 네트워크에서의 페어링 또는 서버를 통한 페어링을 선택합니다.
3. 기기에 표시되는 확인을 완료합니다.
4. 찬송가 검색과 음악 열기를 테스트합니다.
5. 구절 넘기기와 선택 지우기를 테스트합니다.
6. 타이머 시작, 일시정지, 초기화를 테스트합니다.
7. 두 번째 화면에 운영자용 컨트롤이 표시되지 않는지 확인합니다.

## PWA가 오프라인에서 열리지 않으면 어떻게 하나요?

1. 기기를 인터넷에 연결합니다.
2. 브라우저에서 `app.pianolouvorja.com.br`을 엽니다.
3. 페이지가 완전히 불러와질 때까지 기다립니다.
4. 준비와 다운로드를 다시 진행합니다.
5. 연결을 끊기 전에 찬송가와 예배 순서가 저장되어 있는지 확인합니다.
6. 인터넷이 있을 때 페이지를 새로 고침하여 최신 버전을 받습니다.
7. 고정된 프로젝션 운영을 위해서는 데스크톱 앱 사용을 고려하세요.

## 프로그램을 위해 브라우저를 준비 상태로 유지하려면?

1. 사용하지 않을 탭은 닫아둡니다.
2. 가능하면 브라우저 알림을 비활성화합니다.
3. 필요한 컨트롤이 가려지지 않는 경우에만 전체 화면을 사용합니다.
4. 컴퓨터가 절전 모드에 들어가지 않는지 확인합니다.
5. 충전기와 네트워크 연결을 사용할 수 있도록 유지합니다.
6. 예배 순서를 열고 첫 번째 항목을 준비해 둡니다.
7. 마지막으로 프로젝션을 테스트합니다.

## 예배 전 최종 체크리스트

1. PIANO가 선택한 기기에서 열리는지 확인합니다.
2. 찬송가와 자료를 사용할 수 있는지 확인합니다.
3. 예배 순서가 올바른 순서로 되어 있는지 확인합니다.
4. 교회 화면에 테스트 프로젝션이 표시되는지 확인합니다.
5. 예배당 뒤에서 글자 크기와 대비를 확인합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 운영을 담당할 사람을 지정해 둡니다.
