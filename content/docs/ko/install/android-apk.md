# 안드로이드에서 APK로 PIANO LouvorJA 설치하기

APK는 PIANO LouvorJA 공식 페이지에서만 다운로드하세요. Android가 브라우저에 해당 파일 설치 권한을 요청하면, 다운로드에 사용한 브라우저에만 권한을 허용하고 설치를 완료한 후 앱을 열어 예배 콘텐츠를 준비하면 됩니다.

## 공식 APK는 어디서 다운로드하나요?

안드로이드 APK는 공식 버전 페이지에 배포되며, 다운로드 페이지에서 올바른 경로를 확인할 수 있습니다.

1. 휴대폰이나 태블릿의 브라우저를 엽니다.
2. [다운로드](/download) 페이지로 이동합니다.
3. **Android** 섹션을 찾습니다.
4. APK 다운로드 버튼을 누릅니다.
5. 다운로드가 완전히 끝날 때까지 기다립니다.
6. 다운로드 알림이나 **Downloads** 폴더를 엽니다.

출처를 확인하지 않은 채 그룹 메시지, 이메일, USB로 받은 APK는 설치하지 마세요. 공식 페이지가 현재 버전의 기준입니다.

## APK 설치를 허용하려면 어떻게 하나요?

메뉴 이름은 제조사마다 다르지만 흐름은 비슷합니다. Android가 파일을 연 앱, 보통 Chrome이나 파일 관리자에 권한을 요청합니다.

1. 다운로드한 APK 파일을 누릅니다.
2. 보안 경고가 나타나면 **설정**을 누릅니다.
3. **이 출처 허용** 또는 **알 수 없는 앱 설치**를 활성화합니다.
4. 이전 화면으로 돌아갑니다.
5. **설치**를 누릅니다.
6. 완료될 때까지 기다립니다.
7. **열기**를 누릅니다.

설치 후에는 같은 메뉴에서 이 권한을 다시 끌 수 있습니다. 이렇게 하면 확인 없이 다른 파일이 설치되는 것을 막을 수 있습니다.

## 경고가 나타나지 않으면 권한은 어디에서 찾나요?

기기 시스템에서 같은 기능의 이름을 찾아 설정하세요.

1. Android의 **설정**을 엽니다.
2. **앱** 또는 **응용 프로그램**으로 이동합니다.
3. APK를 다운로드한 브라우저(예: Chrome) 또는 파일 관리자를 선택합니다.
4. **알 수 없는 앱 설치**를 엽니다.
5. **이 출처 허용**을 활성화합니다.
6. **Downloads** 폴더로 돌아가 APK를 다시 엽니다.

일부 기기에서는 **보안** 또는 **개인정보 보호** 메뉴에 있습니다. 중요한 것은 설치를 수행할 앱에만 권한을 주는 것이지, 통제 없는 전체 허용이 아닙니다.

## 첫 사용 시 무엇을 해야 하나요?

예배 일정 전에 콘텐츠를 미리 준비하세요.

1. **PIANO LouvorJA**를 엽니다.
2. 초기 준비 동안 기기를 인터넷에 연결해 둡니다.
3. 상단에 버튼이 표시되면 **−** 및 **＋** 버튼으로 화면 크기를 조절합니다.
4. **미디어 센터**를 열고 예배 프로그램의 찬양 찬송가를 검색합니다.
5. 필요한 콘텐츠를 다운로드합니다. 진행 상황은 저장됩니다.
6. **예배 순서**에서 팀의 찬양, 성경, 파일, 메모를 정리합니다.
7. **설정**에서 투사 색상과 글자 크기를 테스트합니다.

다운로드한 콘텐츠와 설정은 기기에 저장됩니다. 인터넷 없이 진행되는 예배를 위해서는 미리 항목을 다운로드하고 테스트해 두세요.

## 휴대폰을 리모컨으로 사용할 수 있나요?

PIANO는 같은 네트워크 또는 서버를 통해 기기를 페어링할 수 있습니다.

1. PIANO에서 **리모컨** 영역을 엽니다.
2. 사용 가능한 페어링 방식을 선택합니다: 같은 네트워크 또는 서버.
3. 화면에 표시된 코드 또는 확인 절차를 따릅니다.
4. 찬송가 검색, 가사 진행, 성경 구절 전환을 테스트합니다.
5. 예배 전에 선택 지우기와 투사 종료도 테스트해 둡니다.

리모컨을 사용하면 팀이 컴퓨터 곁에 머물지 않고도 가사, 성경 구절, 타이머, 카운트다운, 시계를 진행할 수 있습니다.

## 안드로이드 TV Box에서도 사용할 수 있나요?

네, 호환되는 안드로이드 기기에서 사용할 수 있는 옵션입니다. TV Box의 브라우저에서 공식 페이지로 APK를 다운로드하거나, 이미 확인된 공식 출처에서 전송하세요. TV에서 가장 좋은 용도는 **무대 화면**으로, 다른 기기에서 제어하는 투사를 받는 화면입니다.

1. TV Box를 PIANO를 제어하는 기기와 같은 네트워크에 연결합니다.
2. TV Box의 브라우저를 열고 사용 가능하다면 [다운로드](/download)에 접속합니다.
3. 공식 APK를 다운로드하고 해당 브라우저 또는 파일 관리자의 설치를 허용합니다.
4. 설치된 앱을 엽니다.
5. 조작 기기에서 **무대 화면** 페어링을 엽니다.
6. TV의 수신기를 네트워크에 연결하고 PIANO가 표시하는 페어링을 완료합니다.
7. 테스트 찬송가를 투사하여 TV에 교회 화면만 표시되는지 확인합니다.

Android TV 및 Google TV의 세부 단계는 전용 페이지를 참고하세요.

## 예배 당일 문제를 예방하려면 어떻게 하나요?

1. 기기를 충전해 두거나 전원에 연결해 둡니다.
2. 예배 전에 찬송가와 미디어를 다운로드해 둡니다.
3. 무대 화면이나 로컬 리모컨을 사용할 때는 모든 기기를 같은 네트워크에 연결합니다.
4. 동영상, PDF, 성경 구절을 포함해 예배 순서 전체를 테스트합니다.
5. 시작 몇 분 전에 Android 시스템을 업데이트하거나 앱을 바꾸지 마세요.

## 페어링 후 가사와 성경을 투사하려면 어떻게 하나요?

1. 조작 기기에서 **미디어 센터**를 엽니다.
2. 찬송가 제목이나 일부 구절로 검색합니다.
3. 결과를 열고 **투사**를 누릅니다.
4. 절과 후렴을 진행하면 무대 화면이 TV에서 함께 따라갑니다.
5. **성경**을 열어 버전, 책, 장, 절을 선택합니다.
6. **투사**를 눌러 해당 구절을 보냅니다.
7. **ESC** 또는 해당 명령으로 투사를 종료합니다.

## 안드로이드에서 예배 순서를 준비하려면 어떻게 하나요?

1. **예배 순서**를 열고 프로그램을 만듭니다.
2. 예배의 각 부분마다 구분 항목을 추가합니다.
3. 찬양, 파일, 링크, 메모를 추가합니다.
4. 필요하면 **기도**, **환영 인사** 같은 보조 제목을 사용합니다.
5. 항목을 드래그하여 최종 순서로 배치합니다.
6. 저장하고 결과를 확인합니다.
7. 예배 중에는 항목을 하나씩 진행합니다.

## 배터리와 네트워크는 어떻게 관리하나요?

1. 사용 전에 휴대폰, 태블릿, TV Box를 충전합니다.
2. 긴 예배에서는 조작 기기를 전원에 연결해 둡니다.
3. 로컬 무대 화면을 위해 장비를 같은 네트워크에 연결합니다.
4. 예배 중에는 Wi-Fi 네트워크를 자주 바꾸지 않습니다.
5. 조작자의 주의를 흩을 수 있는 알림은 끕니다.
6. 시작 전에 찬송가와 미디어를 다운로드해 둡니다.
7. 미리 연결과 투사를 테스트합니다.

## Android가 설치를 막으면 어떻게 하나요?

1. 파일이 공식 페이지에서 왔는지 확인합니다.
2. 다운로드가 완료되었는지 확인합니다.
3. **알 수 없는 앱 설치**는 APK를 연 앱에만 허용합니다.
4. 파일로 돌아가 다시 **설치**를 누릅니다.
5. 저장 공간이 부족하면 공간을 확보하고 다시 시도합니다.
6. APK가 기기와 호환되지 않으면 브라우저에서 PWA를 사용하세요.
7. 설치 권한 외에 시스템 보호 기능은 끄지 마세요.

## 예배 전 최종 체크리스트

1. PIANO가 선택한 기기에서 열리는지 확인합니다.
2. 찬송가와 자료가 준비되어 있는지 확인합니다.
3. 예배 순서가 올바른 순서로 되어 있는지 확인합니다.
4. 교회 화면에서 테스트 투사가 표시되는지 확인합니다.
5. 예배당 뒤쪽에서 글자 크기와 대비를 확인합니다.
6. 네트워크, 전원, 필요한 케이블을 확인합니다.
7. 조작을 담당할 사람을 정해 둡니다.
