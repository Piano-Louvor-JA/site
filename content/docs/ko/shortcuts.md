# 키보드 단축키

단축키를 사용하면 버튼을 찾느라 시간을 낭비하지 않고 예배를 진행할 수 있습니다. 예배 프로그램 전에 교회 컴퓨터에서 모든 단축키를 테스트해 보고, 검색어나 메모를 입력하는 등 입력 포커스가 텍스트 필드에 있지 않을 때만 사용하세요.

## 단축키를 안전하게 사용하는 방법

운영자 컴퓨터에 연결된 키보드를 사용하세요. 먼저 찬송가, 순서지, 성경 구절을 준비해 둔 다음, 프로젝션 중에 단축키로 빠르게 대응하세요.

1. 예배를 제어하는 컴퓨터에서 PIANO를 엽니다.
2. 시작 전에 찬송가와 프로젝션 화면을 준비합니다.
3. 방향키, 스페이스바, 문자 단축키를 사용하기 전에 텍스트 필드 밖을 클릭합니다.
4. 팀과 함께 짧게 리허설합니다.
5. 단축키가 작동하지 않을 경우를 대비해 화면의 버튼을 대안으로 유지하세요.

## 플레이어를 제어하는 단축키는 무엇인가요?

찬송가나 오디오를 들으며 사용하는 단축키입니다. 일시정지, 건너뛰기, 볼륨 조절을 위해 화면을 전환할 필요가 없습니다.

| 동작          | 단축키    | 사용 시점                                                        |
| ------------- | -------- | ---------------------------------------------------------------- |
| 재생/일시정지 | `스페이스` | 연습, 입창, 찬양 중에 찬송가 오디오를 재생하거나 일시정지할 때.     |
| 다음 트랙     | `→`      | 순서나 테스트에 따라 다음 트랙으로 넘어갈 때.                       |
| 이전 트랙     | `←`      | 팀이 반복하거나 선택을 수정해야 할 때 이전 트랙으로 돌아갈 때.       |
| 볼륨 높이기   | `↑`      | 사운드 출력이 올바른지 확인한 후 플레이어 볼륨을 높일 때.           |
| 볼륨 낮추기   | `↓`      | 음악을 중단하지 않고 플레이어 볼륨을 줄일 때.                       |
| 전체 화면 모드 | `F`      | 발표나 반주 연습 중 플레이어를 전체 화면으로 사용할 때.             |

검색 필드에 입력하거나 메모를 편집하는 동안에는 방향키를 사용하지 마세요. 그럴 경우 플레이어를 제어하는 대신 커서가 이동할 수 있습니다.

## 프로젝션을 제어하는 단축키는 무엇인가요?

예배 중에 프로젝션을 표시하거나 종료하거나 조작 화면과 프로젝션 사이를 빠르게 전환할 때 사용하는 명령입니다.

| 동작                                | 단축키         | 사용 시점                                                          |
| ----------------------------------- | -------------- | ------------------------------------------------------------------ |
| 프로젝션 전환                        | `P`            | 화면에서 버튼을 찾지 않고 현재 콘텐츠의 프로젝션을 켜거나 끌 때.     |
| 프로젝션 종료                        | `ESC`          | 찬송가, 성경 구절, 콘텐츠가 끝났을 때 프로젝션을 닫을 때. 앱에서 확인을 요청합니다. |
| 데스크톱 앱에서 조작 ↔ 프로젝션 전환 | `Ctrl+Alt+P`   | 두 화면을 모두 확인해야 할 때 데스크톱 앱에서 조작 창과 프로젝션 사이를 전환할 때. |

`ESC`를 사용하기 전에 무대 위에 있거나 찬양하는 사람에게 미리 알리세요. 이 명령은 프로젝션을 종료하며, 실수로 종료하는 일을 줄이기 위해 확인 절차를 거칩니다.

## 흐름을 벗어나지 않고 찬송가를 검색하는 방법

빠른 검색은 예배 직전에 순서가 바뀌었을 때 구약성서 찬송가(안식일 예배 찬송가), 성가집 또는 다른 콘텐츠를 찾는 데 유용합니다.

| 동작      | 단축키     | 사용 시점                                                        |
| --------- | ---------- | ---------------------------------------------------------------- |
| 빠른 검색 | `Ctrl+K`   | 메뉴를 탐색하지 않고 검색을 열어 찬송가 번호, 제목, 가사 일부를 입력할 때. |

1. `Ctrl+K`를 누릅니다.
2. 찬송가 번호, 제목 또는 가사 일부를 입력합니다.
3. 올바른 결과를 선택합니다.
4. 인터넷 없이 사용해야 할 경우를 대비해 찬송가가 다운로드되어 있는지 확인합니다.
5. 순서에 해당하는 시간이 되면 열어서 프로젝션합니다.

## 팀과 함께 단축키를 연습하는 방법

처음 하는 실사용에 의존하지 마세요. 예배에서 사용할 것과 동일한 짧은 시퀀스를 연습하세요.

1. 이미 다운로드한 찬송가를 엽니다.
2. `스페이스`로 재생하고 일시정지합니다.
3. `↑`와 `↓`로 볼륨을 조절합니다.
4. **프로젝션**을 클릭하고 `P`를 테스트합니다.
5. `ESC`를 누르고 종료를 확인한 후 프로젝션을 다시 엽니다.
6. `Ctrl+K`를 누르고 다음 찬송가를 검색합니다.
