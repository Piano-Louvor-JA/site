# 스테이지 및 다중 기기

스테이지 모드에서는 한 사람이 컴퓨터나 휴대폰으로 예배를 조작하고, 다른 화면에 교회를 위한 콘텐츠가 표시됩니다. TV, 프로젝터 또는 스테이지 수신기가 투영 화면을 보여주고, 조작 기기에는 명령어 화면이 계속 표시됩니다.

## 스테이지란 무엇인가요?

스테이지는 네트워크를 통해 예배 투영을 받는 화면입니다. 프로젝터와 별도로 배치된 TV나, 조작 화면을 노출하지 않고 가사, 성경, 시계, 카운트다운을 표시하고자 하는 교회에 적합합니다.

PIANO는 두 가지 역할로 작동합니다:

| 역할                          | 기능                                                              |
| --------------------------- | -------------------------------------------------------------------- |
| 운영자 또는 리모컨            | 찬송가 검색, 항목 열기, 슬라이드 진행, 투영 켜기/끄기                  |
| 스테이지, TV 또는 프로젝터    | 회중을 위한 콘텐츠 표시                                               |

투영 화면은 조작 화면으로 사용해서는 안 됩니다. 이 화면에는 교회를 위해 선택된 콘텐츠와 시각 스타일만 표시됩니다.

## TV에는 무엇이, 조작 화면에는 무엇이 표시되나요?

TV나 프로젝터는 활성 모듈의 투영을 받습니다. 컴퓨터나 휴대폰에는 예배를 진행하는 데 필요한 버튼과 목록이 그대로 유지됩니다.

| 콘텐츠           | TV, 프로젝터 또는 스테이지                          | 조작용 컴퓨터 또는 휴대폰                        |
| --------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| 찬송가          | 투영 설정에 따른 가사, 슬라이드, 표지 및 다음 소절 미리보기 | 검색, 찬송가 선택, 플레이어, 볼륨 및 슬라이드 진행       |
| 성경            | 고유한 스타일로 표시된 선택한 구절                       | 성경 버전, 책, 장, 절 선택 및 조작 기능                  |
| 예배 순서        | 활성 항목의 투영 콘텐츠                                 | 예배 순서, 카테고리, 완료된 항목 및 메모                 |
| 시계 및 타이머   | 시계, 타이머 또는 카운트다운                            | 색상, 형식, 시작, 일시정지, 마커 및 초기화 설정           |
| 추첨            | 결과, 사운드 및 애니메이션                             | 이름, 번호 또는 항목 목록 및 추첨 명령                   |

예배 순서 메모는 팀을 위한 것이며 교회 화면에 표시되어서는 안 됩니다.

## 페어링 전에 네트워크는 어떻게 준비하나요?

로컬 페어링을 사용하려면 조작 기기와 스테이지 수신기를 같은 네트워크에 연결하세요. 예배 전에 TV를 켠 상태로 전체 테스트를 진행하세요.

1. TV나 프로젝터, 그리고 스테이지를 표시할 기기를 켭니다.
2. PIANO를 운영할 컴퓨터를 켜거나 조작용 휴대폰을 준비합니다.
3. 모든 기기를 교회의 동일한 Wi‑Fi 또는 유선 네트워크에 연결합니다.
4. 기기 간 통신을 차단하는 방문자용 네트워크는 피하세요.
5. 테스트 중 두 기기가 계속 연결 상태를 유지하는지 확인합니다.
6. 조작용으로 사용할 휴대폰 근처에 충전기를 준비해 두세요.

매뉴얼에는 **같은 네트워크의 P2P**와 **서버를 통한 연결** 두 가지 페어링 방법이 별도의 페어링 탭으로 안내되어 있습니다. 화면의 세부 사용 방법과 연결 코드는 설치된 버전에서 확인해야 합니다.

**내부 작동 방식(기술팀용):** 스테이지 수신기가 운영자 컴퓨터에 연결하는 것이며, 그 반대는 절대 아닙니다. PIANO는 로컬 네트워크(P2P) 또는 중계 서버를 통해 자체 WebSocket 연결을 열며, Chromecast나 AirPlay는 사용하지 않습니다. 추가되는 각 TV는 고유한 연결 "슬롯"을 차지하므로, 여러 화면이 서로 간섭 없이 동시에 사용될 수 있습니다.

## 휴대폰이나 다른 조작 기기는 어떻게 페어링하나요?

리모컨 영역을 열고 교회의 환경에 맞는 페어링 방식을 사용하세요. 연결 후 페어링된 기기는 스테이지 화면을 대체하지 않고 투영을 조작할 수 있습니다.

1. 메인 컴퓨터에서 **리모컨** 또는 페어링 영역을 엽니다.
2. 사용 가능한 페어링 탭을 선택합니다: **같은 네트워크의 P2P** 또는 **서버를 통한 연결**.
3. 휴대폰이나 다른 컴퓨터에서 해당 연결 옵션을 엽니다.
4. PIANO에 표시되는 안내에 따라 두 기기가 연결되었음을 확인할 때까지 진행합니다.
5. 테스트해 보세요: 찬송가를 검색하고 열어 슬라이드를 한 장 넘겨봅니다.
6. 휴대폰의 배터리나 네트워크가 끊길 경우를 대비해 메인 컴퓨터를 대안으로 열어 두세요.

페어링 후 리모컨으로 찬송가 검색, 앨범이 포함된 음악 열기, 성경 구절 넘기기, 선택 지우기, 투영 닫기, 타이머 및 카운트다운 시작·일시정지·초기화, 마커 저장, 시계 설정, 각 모듈의 투영 켜기/끄기가 가능합니다.

## 스테이지는 TV에 어떻게 연결하나요?

스테이지 수신기는 네트워크에 연결되어 투영을 표시합니다. TV가 운영자 컴퓨터와 분리되어 있거나 예배 공간에 화면이 두 대 이상 있을 때 유용합니다.

1. TV에 연결된 기기에서 스테이지 또는 수신기를 엽니다.
2. 해당 기기를 팀이 사용하는 네트워크에 연결합니다.
3. PIANO에서 페어링 또는 스테이지 투영 옵션을 엽니다.
4. 사용 가능한 수신기를 선택하거나 연결합니다.
5. 찬송가를 열고 **투영**을 클릭합니다.
6. 슬라이드를 넘기고 TV에서 업데이트되는지 확인합니다.
7. 성경 구절, 시계, 카운트다운도 함께 테스트합니다.

스테이지 수신기는 LG TV(webOS), 삼성 TV(Tizen), Android TV/Google TV 및 브라우저용으로 제공됩니다. 추가되는 각 수신기는 별도의 화면으로 나타납니다. 여러 대의 TV를 동시에 사용하려면 각 수신기를 운영자 컴퓨터에 연결하고 각 항목을 어느 화면에 투영할지 선택하면 됩니다 — 한 TV에는 가사를, 다른 TV에는 시계나 카운트다운을 표시할 수 있습니다.

## 스테이지에서 찬송가는 어떻게 투영하나요?

스테이지가 연결되면 찬송가 투영은 두 번째 모니터에서 사용하는 것과 동일한 흐름을 따릅니다.

1. 조작 화면에서 **미디어 센터**를 엽니다.
2. 찬송가(Hinário Adventista), 성가집 또는 예배를 위해 준비된 다른 음악을 검색합니다.
3. 찬송가를 열고 가사를 확인합니다.
4. **투영**을 클릭합니다.
5. TV나 프로젝터에 가사가 표시되는지 확인합니다.
6. 노래에 맞춰 절, 벌스와 후렴을 넘깁니다.
7. 선택된 가사가 없을 때는 사전 로비에 표지와 제목이 적절한지 확인합니다.

가사를 읽기 어렵다면 투영 설정을 변경하세요: 배경색, 글자색, 크기, 굵기, 정렬, 배경 이미지 및 텍스트 상자.

## 성경과 유틸리티는 어떻게 투영하나요?

스테이지에서는 운영자가 사용하는 것과 동일한 투영 기능을 표시할 수 있습니다. 안식일 학교, 청년 예배나 의식 같은 특별한 프로그램 전에 각 기능을 테스트해 보세요.

1. 성경의 경우 **성경**을 엽니다.
2. 버전, 책, 장과 절을 선택합니다.
3. **투영**을 클릭하고 TV에서 읽혀지는 내용을 확인합니다.
4. 시계, 타이머, 카운트다운 또는 추첨의 경우 **유틸리티**를 엽니다.
5. 기능을 설정합니다. 가능한 경우 색상과 형식도 포함합니다.
6. 해당 모듈의 투영을 켭니다.
7. 마쳤으면 더 이상 필요하지 않을 때 투영을 끄거나 닫습니다.

## TV가 업데이트되지 않으면 어떻게 하나요?

먼저 네트워크, 연결된 수신기 및 활성 투영을 확인하세요. 이 테스트를 예배 시작 직전으로 미루지 마세요.

1. 로컬 P2P 사용 시 TV/수신기와 조작 기기가 같은 네트워크에 있는지 확인합니다.
2. 스테이지 수신기가 계속 열려 있고 연결되어 있는지 확인합니다.
3. PIANO에서 사용 중인 모듈의 투영을 껐다가 다시 켭니다.
4. 다른 찬송가나 구절을 테스트하여 문제가 특정 항목에 있는지 파악합니다.
5. 페어링 연결이 끊겼다면 연결을 닫고 다시 엽니다.
6. 가능하다면 비디오 케이블이나 두 번째 화면을 대비책으로 준비하세요.
