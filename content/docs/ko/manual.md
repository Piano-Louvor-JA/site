# PIANO LouvorJA 전체 매뉴얼

이 문서는 **1.29.1** 버전 기준의 PIANO LouvorJA 사용자 매뉴얼 목차입니다. 시작하기 가이드로 다음 예배를 준비하거나, 설정이 필요한 기능으로 바로 이동하세요.

## 원본 전체 매뉴얼은 어디서 볼 수 있나요?

전체 기본 텍스트는 사이트 저장소에서 확인할 수 있습니다:

- [GitHub에서 Markdown 매뉴얼 열기](https://github.com/Piano-Louvor-JA/site/blob/main/content/user-manual/manual-usuario.md)

저장소에 게시된 사본은 직접 읽기, 인쇄, 내용 검토 및 문서 탐색을 사용할 수 없을 때 접근하는 데 유용합니다. `main` 브랜치는 사이트의 게시 버전이며, 향후 변경 사항은 pull request를 통해 반영되고 링크는 항상 최신 버전을 가리킵니다.

## 앱은 예배를 어떻게 구성하나요?

PIANO는 운영자 화면과 교회 화면을 분리합니다. 운영자 화면에서는 팀이 찬송가를 검색하고 예배 순서를 구성하며 기능을 제어합니다. 프로젝션 화면에서는 회중이 가사, 성경 구절, 시계, 타이머, 카운트다운 또는 추첨을 봅니다.

1. 예배 전에 다운로드, 예배 순서, 화면 모양을 준비합니다.
2. 컴퓨터 또는 페어링된 기기로 제어합니다.
3. 다른 모니터, 프로젝터, TV 또는 Palco 수신기로 투사합니다.
4. 프로그램의 각 순서에 맞춰 내용을 진행합니다.
5. 컴퓨터를 변경하기 전에 백업을 저장합니다.

## PIANO는 기기에 무엇을 저장하나요?

다운로드, 진행 상황, 예배 순서 및 설정은 로컬에 저장됩니다. 따라서 앱을 닫거나, 컴퓨터를 재시작하거나, 인터넷이 끊겨도 이미 준비한 내용은 사라지지 않습니다.

컴퓨터를 변경할 때 이 작업을 보호하려면 **설정**에서 **백업**을 내보내세요. 포맷이나 유지보수를 하기 전에 반드시 사본을 보관하세요.

## 프로젝션 가독성을 유지하려면?

회중이 도착하기 전에 프로젝션을 조정하세요. **설정**에서 배경색, 글자색, 글꼴 크기와 굵기, 정렬, 텍스트 상자 및 배경 이미지를 선택할 수 있습니다. 성경에는 별도의 스타일 조정 기능이 있습니다.

1. 실제 환경 조명 아래에서 찬송가를 투사합니다.
2. 먼 거리에서 화면을 읽어봅니다.
3. 밝은 배경 위에는 어두운 텍스트 상자를 사용합니다.
4. 읽기 어려우면 글꼴 크기를 키웁니다.
5. 성경 구절과 시계도 함께 테스트합니다.
