# ステージとマルチデバイス

ステージモードでは、一人がパソコンやスマホで礼拝を操作し、別のスクリーンが教会にコンテンツを表示します。テレビ、プロジェクター、またはステージレシーバーが投影を表示し、操作用デバイスにはコントロール画面が表示されたままになります。

## ステージとは？

ステージとは、ネットワークを通じて礼拝の投影を受け取るスクリーンのことです。プロジェクターとは別のテレビや、歌詞・聖書・時計・カウントダウンを操作画面を見せずに表示したい教会に適しています。

PIANOは2つの役割で動作します：

| 役割                               | 機能                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| オペレーター（リモコン操作）       | 賛美歌の検索、項目を開く、スライド送り、投影のオン/オフ。 |
| ステージ（テレビ・プロジェクター） | 会衆向けのコンテンツを表示。                              |

投影用スクリーンは操作用スクリーンとしては使わないでください。ここには、教会向けに選ばれたコンテンツとビジュアルスタイルのみが表示されます。

## テレビに表示されるものと操作画面に残るもの

テレビやプロジェクターは、アクティブなモジュールの投影を受け取ります。パソコンやスマホには、礼拝を進行するためのボタンやリストが保持されます。

| コンテンツ     | テレビ・プロジェクター・ステージ                                 | 操作用パソコン・スマホ                             |
| -------------- | ---------------------------------------------------------------- | -------------------------------------------------- |
| 賛美歌         | 投影設定に応じた歌詞、スライド、カバー、次のフレーズのプレビュー | 検索、賛美歌の選択、プレーヤー、音量、スライド送り |
| 聖書           | 選択した聖句と専用スタイル                                       | 訳・書・章・節の選択とコントロール                 |
| 礼拝プログラム | アクティブな項目の投影コンテンツ                                 | 礼拝の順序、カテゴリー、完了項目、メモ             |
| 時計とタイマー | 時計、タイマー、カウントダウン                                   | 色・形式の設定、開始、一時停止、マーカー、リセット |
| 抽選           | 結果、サウンド、アニメーション                                   | 名前・番号・項目のリストと抽選コマンド             |

礼拝プログラムのメモはチーム用のものであり、教会のスクリーンには表示されないようにしてください。

## ペアリング前にネットワークを準備するには？

ローカルペアリングを使用するには、操作用デバイスとステージレシーバーを同じネットワークに接続してください。礼拝前に、テレビの電源を入れた状態でテストを完了しておきましょう。

1. テレビまたはプロジェクターと、ステージを表示するデバイスの電源を入れます。
2. PIANOを操作するパソコンの電源を入れるか、操作用スマホを準備します。
3. すべてを教会の同じWi‑Fiネットワークまたは有線ネットワークに接続します。
4. デバイス同士が互いに見えないゲスト用ネットワークは避けてください。
5. テスト中も2つのデバイスが接続されたままであることを確認します。
6. 操作用として使うスマホの近くに充電器を置いておきましょう。

マニュアルには2つのペアリング方法が記載されています：**同一ネットワーク上のP2P**と**サーバー経由**で、ペアリングのタブが分かれています。画面の詳細な使い方や接続コードは、インストールされているバージョンでご確認ください。

**仕組み（技術チーム向け）：** ステージレシーバーがオペレーターのパソコンに接続する方式で、その逆はありません。PIANOはローカルネットワーク（P2P）または中継サーバー経由で独自のWebSocket接続を開き、ChromecastやAirPlayは使用しません。テレビを1台追加するごとに専用の接続「スロット」を使用するため、複数のスクリーンを互いに干渉せず同時に使えます。

## スマホなどのコントロールをペアリングするには？

リモートコントロールエリアを開き、教会の環境に合ったペアリング方法を使用してください。接続後、ペアリングされたデバイスはステージ画面を置き換えることなく投影を操作できます。

1. メインのパソコンで**リモートコントロール**（またはペアリング）エリアを開きます。
2. 利用可能なペアリングタブを選択：**同一ネットワーク上のP2P**または**サーバー経由**。
3. スマホまたは別のパソコンで、対応する接続オプションを開きます。
4. PIANOに表示される識別情報に従い、両方のデバイスが「接続済み」と表示されるまで進めます。
5. テストします：賛美歌を検索して開き、スライドを1枚送ります。
6. スマホのバッテリーやネットワークが切れた場合に備え、メインのパソコンを開いたままにしておきます。

ペアリング後、リモートコントロールから賛美歌の検索、アルバム付き楽曲の再生、聖句送り、選択解除、投影の終了、タイマーとカウントダウンの開始・一時停止・リセット、マーカーの保存、時計の設定、各モジュールの投影のオン/オフが行えます。

## ステージをテレビに接続するには？

ステージレシーバーはネットワークに接続して投影を表示します。テレビがオペレーターのパソコンと別の場所にある場合や、礼拝スペースに複数のスクリーンがある場合に便利です。

1. テレビに接続されたデバイスでステージ（レシーバー）を開きます。
2. そのデバイスをチームが使用するネットワークに接続します。
3. PIANOでペアリングまたはステージ投影のオプションを開きます。
4. 利用可能なレシーバーを選択または接続します。
5. 賛美歌を開き、**投影**をクリックします。
6. スライドを送り、テレビで更新されることを確認します。
7. 聖句、時計、カウントダウンもテストしてください。

ステージレシーバーは、LG TV（webOS）、Samsung TV（Tizen）、Android TV/Google TV、およびブラウザー向けに用意されています。レシーバーを追加するごとに別のスクリーンとして表示されます。複数のテレビを同時に使うには、各レシーバーをオペレーターのパソコンに接続し、各項目をどのスクリーンに投影するかを選びます — 1台のテレビで歌詞を表示しながら、別のテレビで時計やカウントダウンを表示できます。

## ステージで賛美歌を投影するには？

ステージが接続されていれば、賛美歌の投影はセカンドモニターの場合と同じ流れで行えます。

1. コントロールで**メディアセンター**を開きます。
2. アドベンチスト賛美歌集、聖歌集、または礼拝用に準備したその他の楽曲を検索します。
3. 賛美歌を開き、歌詞を確認します。
4. **投影**をクリックします。
5. テレビやプロジェクターに歌詞が表示されているか確認します。
6. 歌いながら節・番・リフレーンを送ります。
7. 歌詞が選択されていない場合は、プレロビー用にカバーとタイトルが適切か確認します。

歌詞が読みにくい場合は、投影設定を変更しましょう：背景色、文字色、サイズ、太さ、配置、背景画像、テキストボックス。

## 聖書とユーティリティを投影するには？

ステージでは、オペレーターが使用するのと同じ投影機能を表示できます。安息日学校、ユース礼拝、式典などの特別なプログラムの前に、各機能のテストを行ってください。

1. 聖書の場合は、**聖書**を開きます。
2. 訳、書、章、節を選択します。
3. **投影**をクリックし、テレビでの表示を確認します。
4. 時計、タイマー、カウントダウン、抽選の場合は、**ユーティリティ**を開きます。
5. 機能を設定します（利用可能な場合は色や形式も含む）。
6. 該当モジュールの投影をオンにします。
7. 終了後、不要になったら投影をオフにするか閉じます。

## テレビが更新されない場合は？

まずネットワーク、接続されたレシーバー、アクティブな投影を確認してください。このテストは礼拝開始時に回さないようにしましょう。

1. ローカルP2Pを使用している場合、テレビ/レシーバーとコントロールが同じネットワーク上にあるか確認します。
2. ステージレシーバーが開いたまま接続されているか確認します。
3. PIANOで、使用中のモジュールの投影をオフにしてから再度オンにします。
4. 別の賛美歌や聖句をテストし、問題が特定の項目だけのものか確認します。
5. 接続が切れている場合は、ペアリング接続を閉じて再接続します。
6. 可能であれば、ビデオケーブルやセカンドスクリーンを代替案として用意しておきます。
