# PIANO LouvorJA で最初の礼拝を

礼拝前にすべてを準備しましょう：PIANOを開き、賛美歌を検索してダウンロードし、シンプルなプログラム(リトゥルギア)を組み立てて、投影の準備を整えます。当日は次の項目を選んでスライドを進めるだけです。

## 事前に何を用意すればいいですか?

PIANO LouvorJA を開いたコンピューターを用意してください。投影するには、セカンドスクリーン、プロジェクター、またはテレビを接続します。賛美歌の初回ダウンロードはインターネット接続があるときに行ってください。ダウンロードしたコンテンツはオフラインでも利用できます。

1. コンピューター、テレビ、またはプロジェクターの電源を入れます。
2. PIANO LouvorJA を開きます。
3. オペレーター画面(礼拝を準備する画面)が表示されていることを確認します。
4. インターフェースが小さい場合は、ヘッダーのズームボタンを使用します。
5. 必要なコンテンツを選択・ダウンロードする間は、インターネットを接続したままにします。

初回起動時には、賛美歌・コレクション・カバーアートのカタログがバックグラウンドで準備されることがあります。その間もアプリケーションは引き続き使用できます。

## 5番の賛美歌やタイトルから検索するには?

メディアセンターには、賛美歌、コレクション、歌詞、スライド、オーディオがまとめられています。番号、タイトル、または歌詞の一部から賛美歌を検索できます。

1. ナビゲーションバーで **メディアセンター** を開きます。
2. 検索フィールドをクリックします。
3. 番号で検索する場合は `5` と入力します。
4. タイトルで検索する場合は、賛美歌の名前または歌詞の一部を入力します。
5. 使用する「 Adventist Hymnal(アドベンチスト賛美歌集)」またはコレクションの該当する賛美歌を選びます。
6. 進む前に賛美歌を開いて、タイトル・歌詞・カバーアートを確認します。

似た結果が複数ある場合は、プログラムに追加する前に番号とタイトルを確認してください。賛美の時間に違う曲を投影してしまうのを防ぎます。

## 礼拝で使う賛美歌をダウンロードするには?

礼拝で使う可能性のあるものは、事前にすべてダウンロードしておきましょう。プログレスインジケーターが進行状況を表示します。アプリを終了したり接続が切断されたりしても、進行状況は保存され、後で再開できます。

1. 賛美歌を開いた状態で、**ダウンロード** ボタンを探します。
2. クリックしてダウンロードを開始します。
3. プログレスバーが完了するまで待ちます。
4. プログラム内のすべての賛美歌、コレクション、メディアについて繰り返します。
5. 礼拝前にダウンロード済みの項目を開いて、利用可能になっているか確認します。

ダウンロード済みの賛美歌はインターネットなしでデバイス上で利用できます。設定、プログラム(リトゥルギア)、ダウンロードの進行状況もデバイスに保存されたままになります。

## シンプルなプログラム(リトゥルギア)を作るには?

リトゥルギア(礼拝プログラム)は、礼拝を実際に行う順番で整理します。シンプルなプログラムでは、賛美ブロックを作成し、賛美歌を追加し、必要に応じて聖書、ビデオ、オーディオ、チーム向けメモの項目を追加します。

1. **リトゥルギア** を開きます。
2. 新しいリトゥルギアを作成します。
3. `賛美` などシンプルな名前で **カテゴリー/セパレーター** を追加します。
4. チームが時間帯での計画を立てている場合は、開始時刻と終了時刻を入力します。
5. **音楽** タイプの項目を追加します。
6. 先ほど確認した最初の賛美歌を検索して選択します。
7. 礼拝の順番に沿って他の賛美歌を追加します。
8. 必要に応じて、`お言葉` や `サバス・スクール` など別のカテゴリーを追加します。
9. プログラムに応じて、**聖書**、**ビデオ**、**オーディオ**、**画像**、**PDF**、**PowerPoint プレゼンテーション**、**サイト/オンラインビデオ**、**メモ** の項目を追加します。
10. 項目をドラッグして正しい順番に並べます。
11. リトゥルギアを保存します。

カテゴリーはその中の項目をグループ化します。カテゴリーをドラッグすると、グループ内の項目も一緒に移動します。メモはチーム専用で、教会には表示されません。

## 教会用の画面を準備するには?

オペレーター画面はアプリを操作する人向けです。教会画面には投影内容のみが表示されます：歌詞、聖句、時計、カウントダウン、その他選択したコンテンツです。

1. プロジェクター、モニター、またはテレビをコンピューターに接続します。
2. **メディアセンター** で賛美歌を開きます。
3. **投影** をクリックします。
4. セカンドスクリーンに歌詞が表示されているか確認します。
5. 背景色、文字色、フォントサイズ、配置、背景画像、テキストボックスを調整する必要がある場合は、**設定** を開きます。
6. 明るい背景には暗めのテキストボックスを、暗い背景には明るめのテキストボックスかボックスなしの方が見やすいでしょう。
7. 賛美歌に戻り、賛美が始まる前に最初のスライドを準備しておきます。

歌詞が選択されていない場合、投影にはタイトル付きのアルバムカバーが表示されることがあります。会衆が歌う準備をしている間に便利です。

## 礼拝を進行し、スライドを送るには?

礼拝中はリトゥルギアを開き、準備した順番に従います。音楽、聖書、ユーティリティは、プログラムのそれぞれの場面に応じて投影できます。

1. 保存したリトゥルギアを開きます。
2. 最初の音楽項目を選択します。
3. 投影がまだ有効でない場合は **投影** をクリックします。
4. 歌いながら、番(スタンザ)、節、サビのスライドを送ります。
5. プログレスバーと次のフレーズのプレビューを使って、現在位置を把握します。
6. 終わったら、その項目を完了としてマークし、次の項目を開きます。
7. メッセージを投影するには、**聖書** を開き、翻訳・書・章・節を選んでから **投影** をクリックします。
8. 投影を終了するには、`ESC` を押してアクションを確認します。

オーディオは別のセクションに移動しても再生が続きます。そのため、賛美歌を再生したまま、次の聖句やリトゥルギアの項目を準備できます。オーディオ再生中に別の賛美歌に切り替えると、アプリはスムーズにトランジションします。

## 礼拝中にインターネットが切断されたら?

すでにダウンロード済みの賛美歌とメディアで進めてください。ローカルコンテンツ、リトゥルギア、設定、保存済みの進行状況は、準備が完了すればインターネットに依存しません。

1. 使用中のリトゥルギアを閉じないでください。
2. 礼拝前に確認済みの賛美歌とメディアのみを使用します。
3. 新しいコンテンツを検索する必要がある場合は、接続が回復するまで待ちます。
4. 礼拝後に、次のプログラムに向けて未完了のダウンロードを確認します。

## 準備内容のコピーを保存するには?

アプリケーションは作業内容をデバイス自体に保存します。コンピューターを交換する場合やバックアップコピーを維持する場合は、バックアップ機能を使用してください。

1. **設定** を開きます。
2. **バックアップ** のオプションを探します。
3. 設定とデータをエクスポートします。
4. コンピューターを初期化したり交換したりする前に、ファイルを安全な場所に保管します。
