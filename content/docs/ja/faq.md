# PIANO LouvorJA よくある質問

PIANO LouvorJA は、賛美歌、聖書、典礼(プログラム)、礼拝に必要な素材の準備と投影をサポートします。安全に使用するために、礼拝プログラムの前にパソコン、プロジェクター、テレビをテストし、使用予定のメディアを事前にダウンロードしておきましょう。

## インストールとアクセス

## PIANO LouvorJA は本当に無料ですか?

はい。PIANO LouvorJA は無料のオープンソースです。アプリの機能を使うためにサブスクリプションや広告はありません。

アプリを使って、礼拝、賛美歌集、典礼(プログラム)、聖書、投影を整理できます。ただし、賛美歌や歌詞などのコンテンツの著作権はそれぞれの作者・権利者に帰属します。教会の用途に応じて適切にお使いください。

## 使用するにはアカウントを作成する必要がありますか?

開始するには不要です。アプリは登録なしで開いて使用でき、礼拝の準備やローカルデータの操作も可能です。

アカウントエリアでは、ログイン、新規登録、パスワードの復旧ができます。利用する場合、セキュリティのため、パスワード復旧ではリセット用トークンが送信され、メールアドレスが存在するかどうかは通知されません。

## どのデバイスで使えますか?

PIANO は、最新のブラウザーが動作するパソコン、タブレット、スマートフォンで利用できます。礼拝全体の準備と投影には、マルチスクリーン、独立した投影、キーボードショートカットに対応しているデスクトップが最適です。

1. 操作担当者用とプロジェクター/テレビ用に、デスクトップを分けて使用します。
2. ペアリングが利用可能でテスト済みの場合は、スマートフォンをリモコンとして使用します。
3. アプリがインストールされていない場合は、ブラウザーを手軽な代替手段として使用します。

## スマートテレビではない古いテレビでも使えますか?

はい。ケーブルでパソコンなどの対応デバイスから映像を入力できれば使用できます。この場合、テレビは投影用のセカンドスクリーンとして機能します。

1. テレビの対応入力端子を使ってパソコンをテレビに接続します。
2. テレビで正しい入力を選択します。
3. PIANO で賛美歌を開き、**投影** をクリックします。
4. 礼拝前に歌詞が表示されることを確認します。

ステージモードは、テレビとネットワークに接続されたレシーバーまたはデバイスが必要です。ペアリングの注意点については [ステージモードと複数デバイス](/docs/palco-multi-device) をご覧ください。

## 礼拝中の使用

## 礼拝中はインターネットなしで使えますか?

デスクトップアプリは、必要なメディアをダウンロードした後はオフラインで動作します。ダウンロード済みの賛美歌、典礼(プログラム)、設定、ローカルの進捗はデバイスに保存されます。

Web 版の動作には接続が必要です。信頼できる接続のない礼拝の前に、以下を行ってください:

1. 使用するすべての賛美歌、歌集、メディアをダウンロードします。
2. 各アイテムを一度開いて、利用可能か確認します。
3. 完全な順序で典礼(プログラム)を保存します。
4. プロジェクターまたはテレビで投影をテストします。
5. 別のパソコンを使う場合は、データのバックアップを持参します。

## 同じ礼拝で何台のデバイスを使えますか?

基本的な使い方では、操作用デバイスと表示用スクリーンの2つの役割に分かれます。マニュアルでは、ネットワーク経由で接続されたリモコンとステージモードについても案内しています。

ステージモードのレシーバーと同時接続できるリモコンの最大数は、現時点の情報では明記されていません。礼拝で頼りにする前に、必要な台数でテストを行ってください。

各ステージモードのレシーバーは操作用パソコンとの個別の接続を使用するため、スクリーンを増やすほどネットワークへの負担と操作担当者の負担が増えます。実際には、メインのテレビ1台とサブのテレビ1台(例:廊下やロビー)という構成が最も一般的です。

## 事前にプログラム全体を組み立てられますか?

はい。**典礼(プログラム)** を使えば、開始前に礼拝の順序を組み立てられます。カテゴリー、楽曲、動画、音声、画像、PDF、PowerPoint プレゼンテーション、ウェブサイト、オンライン動画、チーム向けのメモを追加できます。

1. `安息日学校`、`賛美`、`献金`、`説教` などのカテゴリーを作成します。
2. 実際のプログラムの順序でアイテムを追加します。
3. ドラッグして順序を修正します。
4. 保存します。
5. 礼拝中は、済んだ項目に印を付け、次の項目を開きます。

## 聖書を開いても音声は再生し続けますか?

はい。オーディオプレイヤーは、他のセクションに移動しても再生を続けます。賛美歌を流したまま、次の聖句や典礼(プログラム)の項目を準備できます。

再生中に別の賛美歌に切り替えると、現在の音声から新しい音声へスムーズに切り替わります。教会の音響での意外な事態を避けるため、礼拝前に音量と音声出力をテストしてください。

## パソコンを替える前にバックアップはどう取ればいいですか?

設定のバックアップ機能からデータをエクスポートしてください。パソコンの初期化、交換、貸し出しの前に、コピーを安全な場所に保管してください。

1. **設定** を開きます。
2. **バックアップ** を探します。
3. 設定とデータをエクスポートします。
4. ファイルを信頼できるメディアやストレージにコピーします。
5. 別のパソコンで、対応するインポート機能を使用します。

## プライバシーとデータ

## データはどこに保存されますか?

デスクトップアプリでは、ダウンロードした賛美歌、典礼(プログラム)、設定はデバイス内にローカル保存されます。これにより、インターネットがなくても準備した内容をそのまま使用できます。

ウェブサイトでは、お問い合わせフォームから名前、メールアドレス、メッセージが返信のために送信されます。この取り扱いの詳細については、サイトのプライバシーポリシーをご覧ください。

## プライバシーはどのように保護されていますか?

ウェブサイトでは、トラッキング、アナリティクス、広告のクッキーは使用していません。優先言語を記憶する技術的なクッキーのみが使用されます。連絡先データはリクエストへの返信のためだけに使用され、第三者によるマーケティングには使われません。

個人データに関する権利の行使や詳細については、PIANO LouvorJA のサイトで公開されているプライバシーポリシーをご覧ください。

## 問題とアップデート

## アプリはどのように更新されますか?

Web アプリでは、ページを再読み込みすると更新が適用されます。このバージョンでは、手動でアップデートをダウンロードする必要はありません。

大事な礼拝の前には、余裕をもってアプリを開いてください。バージョンが正しく読み込まれていること、および投影・音声・典礼(プログラム)の賛美歌をテストできます。

## アプリが読み込まれない、またはエラーが出る場合はどうすればいいですか?

まず再読み込みと接続の確認から始めてください。特に初回アクセス時や Web 版で重要です。

1. ページを再読み込みします。必要に応じて `Ctrl+F5` でキャッシュを更新します。
2. 初回アクセス時はインターネット接続を確認します。
3. ブラウザーの設定からサイトのデータを消去します。
4. 競合する拡張機能を切り分けるため、シークレットウィンドウでテストします。
5. それでも解決しない場合は、アプリにオプションがあるときは **再試行** を使用します。
6. ブラウザー、デバイス、バージョン、エラー発生前の操作内容を記録しておきます。

症状別の解決方法は [よくある問題](/docs/troubleshooting) をご覧ください。

## サポートへの問い合わせや問題の報告はどうすればいいですか?

サイトのお問い合わせフォームを利用するか、プロジェクトのリポジトリで issue を起票してください。詳細な情報を提供するほど、問題の再現が容易になります。

以下を含めてください:

1. デバイスの型番と使用中の OS。
2. ブラウザーまたはアプリのバージョン。
3. 影響を受けたモジュール:賛美歌、典礼(プログラム)、聖書、ステージモード、投影、音声。
4. 問題を引き起こした手順。
5. 期待された結果と実際の結果。
6. 個人情報が写っていない写真またはスクリーンショット。

## プロジェクトに貢献できますか?

はい。オープンソースプロジェクトですので、バグの報告、改善の提案、コードの貢献、翻訳の手伝い、他の教会や賛美チームへの PIANO の紹介などができます。
