# キーボードショートカット

ショートカットを使えば、ボタンを探すことなく礼拝をスムーズに進められます。プログラムの前に教会のコンピューターですべて試し、検索やメモを入力中でフォーカスが外れているときだけ使うようにしましょう。

## ショートカットを安全に使うには？

操作用コンピューターに接続されたキーボードを使用します。まず賛美歌、礼拝程序、聖書を準備し、その後ショートカットを使ってプロジェクション中に素早く対応できるようにします。

1. 礼拝を操作するコンピューターでPIANOを開きます。
2. 開始前に賛美歌とプロジェクション画面を準備します。
3. 矢印キー、スペース、ショートカット文字を使う前に、テキスト入力欄の外をクリックします。
4. チームと短いリハーサルを行います。
5. ショートカットが反応しない場合に備え、画面上のボタンも使えるようにしておきます。

## プレイヤーを操作するショートカットは？

賛美歌やオーディオに合わせて使うショートカットです。一時停止や送り、音量調整のために画面を切り替える必要がなくなります。

| 操作                 | ショートカット | 使う場面                                                             |
| -------------------- | -------------- | -------------------------------------------------------------------- |
| 再生/一時停止        | `スペース`     | 練習、入場、賛美中に賛美歌のオーディオを再生または一時停止するとき。 |
| 次のトラック         | `→`            | プログラムやテストの都合で次のトラックに進むとき。                   |
| 前のトラック         | `←`            | チームが同じ曲を繰り返したり、選択を修正したりするとき。             |
| 音量を上げる         | `↑`            | 音声出力が正しいことを確認したうえで、プレイヤーの音量を上げるとき。 |
| 音量を下げる         | `↓`            | 音楽を中断せずにプレイヤーの音量を下げるとき。                       |
| フルスクリーンモード | `F`            | 会議や練習の際にプレイヤーをフルスクリーンで使うとき。               |

検索欄への入力中やメモの編集中は矢印キーを使わないでください。その場合、プレイヤーを操作する代わりにカーソルが移動してしまいます。

## プロジェクションを操作するショートカットは？

礼拝中にプロジェクションの表示・終了、操作画面とプロジェクションの切り替えを素早く行うためのコマンドです。

| 操作                                                      | ショートカット | 使う場面                                                                                           |
| --------------------------------------------------------- | -------------- | -------------------------------------------------------------------------------------------------- |
| プロジェクションの切り替え                                | `P`            | 画面上のボタンを探さずに、現在のコンテンツのプロジェクションのオン/オフを切り替えるとき。          |
| プロジェクションの終了                                    | `ESC`          | 賛美歌、聖句、その他のコンテンツが終わったときにプロジェクションを閉じる。アプリが確認を求めます。 |
| デスクトップアプリでの操作画面 ↔ プロジェクション切り替え | `Ctrl+Alt+P`   | デスクトップアプリで操作ウィンドウとプロジェクションの両画面を確認したいときに切り替える。         |

`ESC` を使う前には、壇上や歌を担当している人に伝えてください。このコマンドはプロジェクションを終了し、誤操作を防ぐために確認を求めるようになっています。

## 画面を離れずに賛美歌を検索するには？

クイック検索は、礼拝程序が直前に変わったときなどに、 Adventist賛美歌（Hinário Adventista）の賛美歌や聖歌集などのコンテンツを素早く見つけるのに便利です。

| 操作         | ショートカット | 使う場面                                                                   |
| ------------ | -------------- | -------------------------------------------------------------------------- |
| クイック検索 | `Ctrl+K`       | メニューを操作せずに、番号、タイトル、歌詞の一部を入力して検索を開くとき。 |

1. `Ctrl+K` を押します。
2. 賛美歌の番号、タイトル、または歌詞の一部を入力します。
3. 正しい結果を選びます。
4. インターネットなしで使う前に、賛美歌がダウンロード済みか確認します。
5. プログラムの順番が来たら開いてプロジェクションします。

## チームでショートカットを練習するには？

本番での初使用だけに頼らないでください。礼拝で使うのと同じ流れを短く通して練習しましょう。

1. ダウンロード済みの賛美歌を開きます。
2. `スペース` で再生と一時停止を試します。
3. `↑` と `↓` で音量を調整します。
4. **プロジェクション** をクリックし、`P` を試します。
5. `ESC` を押し、終了を確認して、再度プロジェクションを開きます。
6. `Ctrl+K` を押して次の賛美歌を検索します。
