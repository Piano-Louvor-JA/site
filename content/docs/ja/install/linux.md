# Linux に PIANO LouvorJA をインストールする

Linux では、公式の AppImage をダウンロードするのが最も簡単な方法です。Snapcraft も利用できます。Flathub は現在審査中のため、ストアに表示されるまでは他の公式チャネルをご利用ください。

## どのインストール方法を選べばよいですか？

教会のコンピューターで実際に動作している方法を選びましょう。

- **AppImage:** 単一のファイルを公式ページからダウンロードします。ダウンロードフォルダーにアクセスできる場合、最もシンプルな方法です。
- **Snapcraft:** Snap ストアをすでに利用しているディストリビューション向けの選択肢です。
- **Flathub:** 現在審査中です。PIANO がストアで利用可能になってからご使用ください。それまでは AppImage または Snapcraft を選んでください。

いずれも、公開済みバージョンを案内する公式の[ダウンロード](/download)ページからアクセスできます。

## ARM64 と X64 のどちらを選べばよいですか？

ダウンロードページには、AppImage のバージョンが 2 種類表示される場合があります。

1. コンピューターが一般的な Intel または AMD プロセッサーを使用している場合は、**X64** を選びます。
2. ARM プロセッサーの場合は、**ARM64** を選びます。
3. わからない場合は、ダウンロードする前に、以前コンピューターを設定した人に確認しましょう。
4. 手当たり次第にファイルを試すのは避けてください。誤ったアーキテクチャのファイルは起動できません。

Intel または AMD を搭載した教会のコンピューターは、通常 X64 です。

## AppImage を使ってインストールするには？

AppImage は、ダウンロードして実行を許可し、開くだけで使えるファイルです。

1. [ダウンロード](/download)ページを開きます。
2. **Linux** を選び、コンピューターに合った AppImage をダウンロードします。
3. ファイルマネージャーを開き、**ダウンロード**フォルダーに移動します。
4. AppImage ファイルを右クリックします。
5. **プロパティ**を選びます。
6. **アクセス権**（権限）タブを開きます。
7. 「プログラムとして実行を許可する」に相当する項目にチェックを入れます。
8. プロパティのウィンドウを閉じます。
9. AppImage をダブルクリックすると、PIANO が開きます。

オプションの名称は Linux ディストリビューションによって多少異なる場合があります。「アクセス権」や実行許可に関する項目を探してください。

## ターミナルしか使えない場合は？

できるだけファイルマネージャーを使ってください。教会の技術担当者がターミナルを使う場合は、保存先のフォルダーで次のコマンドによりファイルを実行可能にできます。

```bash
chmod +x 名前.AppImage
```

その後、ファイルマネージャーからファイルを開いてください。PIANO の日々の利用にターミナルは必要ありません。

## Snapcraft からインストールするには？

PIANO 用に公開されている Snapcraft チャネルへは、公式ダウンロードページからアクセスできます。

1. [ダウンロード](/download)ページを開きます。
2. **Linux** のオプションを選び、Snapcraft チャネルを見つけます。
3. ストアのリンクを開きます。
4. お使いの Linux ディストリビューションまたは技術担当者の案内に従ってインストールします。
5. アプリケーションメニューで **PIANO LouvorJA** を探します。
6. アプリを開き、初期テストを行います。

Snap ストアがインストールされていない、または開けない場合は、安息日にシステムを変更しようとせず、AppImage をご利用ください。

## Flathub からインストールできますか？

まだ主要な方法としては利用できません。Flathub への申請は審査中で、利用可能になるかはストアの承認次第です。

1. [ダウンロード](/download)ページを開きます。
2. PIANO の Flathub ボタンが有効になっているか確認します。
3. ボタンがあれば開き、ストアからインストールします。
4. ボタンがない場合やページで利用不可と表示される場合は、AppImage または Snapcraft をご使用ください。

公式ページで確認できるまで、Flathub は利用可能と見なさないでください。

## 初回起動時に何をすればよいですか？

礼拝の前に、特にオフラインで使用するコンテンツを準備しておきましょう。

1. PIANO LouvorJA を開きます。
2. カタログの初期準備が完了するまで待ちます。
3. **メディアセンター**で、アドベンチスト賛美歌集の賛美歌やプログラムで使用するコレクションを検索・ダウンロードします。
4. **リトゥルギア（礼拝プログラム）**で、カテゴリー、音楽、聖書、ローカルファイルを使った礼拝の順序を作成します。
5. **設定**でプロジェクションのスタイルを調整します。
6. 賛美歌、聖句、時計を教会の画面でテストします。

ダウンロード、リトゥルギア、設定は端末に保存されます。アプリを閉じても準備した内容は消えません。

## AppImage が開かない場合は？

まず基本的な点を、データを消さずに確認しましょう。

1. コンピューターのアーキテクチャに合った正しいファイルをダウンロードしたか確認します。
2. **プロパティ**と**アクセス権**をもう一度確認します。
3. ファイルが USB メモリーやネットワーク上にある場合は、**ドキュメント**などのローカルフォルダーに移動します。
4. ダウンロードが中断されていた場合は、必ず公式ページから再ダウンロードします。
5. それでも解決しない場合は、利用可能なら Snapcraft チャネルか、ウェブアプリを使い、礼拝で困らないようにしましょう。

## チームが使いやすいショートカットを用意するには？

AppImage のテスト後、チームが分かるフォルダーに保管しましょう。

1. **ドキュメント**内に **PIANO LouvorJA** という名前のフォルダーを作成または選択します。
2. テスト済みの AppImage をそのフォルダーに移動します。
3. 再度開いて、正常に動作するか確認します。
4. ファイルマネージャーに「お気に入りに追加」や「ショートカットを作成」の機能があれば利用します。
5. チームにファイルの保存場所を伝えます。
6. 動作したファイルを削除しないでください。それがアプリ本体です。
7. 似た名前の古いコピーを複数残さないようにしましょう。

## 完全なリトゥルギアを準備するには？

1. **リトゥルギア**を開き、プログラムの作成を選びます。
2. 礼拝の各場面ごとにカテゴリーを追加します。
3. 音楽、ローカルメディア、リンク、メモを追加します。
4. チームが時間を確認する必要がある場合は、カテゴリーの時間を入力します。
5. 項目をドラッグして最終的な順序に並べます。
6. 保存し、プログラム担当者と一緒に確認します。
7. 礼拝中は順序に沿って進め、完了した項目に印を付けます。

## 安心してプロジェクションするには？

1. **メディアセンター**で賛美歌を開きます。
2. **投影**をクリックします。
3. 2 番目の画面や TV を確認します。
4. テキストを送り、同期を確認します。
5. **聖書**で聖句を開き、同じテストを行います。
6. **設定**でコントラストとフォントサイズを調整します。
7. テストが終わったら **ESC** で投影を終了します。

## 教会でのトラブルを避けるには？

1. ダウンロードとテストは余裕を持って済ませておきます。
2. 充電器、ビデオケーブル、アダプターを手の届く場所に置いておきます。
3. プロジェクターや TV が正しい入力に接続されているか確認します。
4. 礼拝の直前に Linux ディストリビューションをアップデートしないでください。
5. インターネットがある場合に備え、ウェブアプリを代替手段として使えるようにしておきます。
6. PIANO の開き方を 2 人目の人にも説明しておきます。
7. チームがコンピューターを交代する際は、設定のバックアップを取っておきます。

## 礼拝前の最終チェックリスト

1. PIANO が選択した機器で開くことを確認します。
2. 賛美歌や資料が利用可能であることを確認します。
3. リトゥルギアが正しい順序になっていることを確認します。
4. 教会の画面にテスト投影が表示されることを確認します。
5. 会堂の後方から見える文字サイズとコントラストを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 操作担当者を一人決めておきます。
