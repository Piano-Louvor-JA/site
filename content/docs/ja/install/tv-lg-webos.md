# LG webOS TVでPIANO LouvorJAを使う

LG webOS TVは**Palco**による投影を受け取り、礼拝の操作はパソコンやスマートフォンから行います。ダウンロードページでwebOS公式ファイルが公開されているか確認してください。公開されていない場合は、テレビのブラウザーを代替として使うか、HDMIで互換性のあるレシーバーを接続してください。

## LG TVでのPalcoの仕組み

Palcoはテレビを会衆用のスクリーンに変えます。オペレーターは別の機器でプログラムを準備・送り、LGテレビには投影されたコンテンツだけが表示されます。

以下の内容を表示できます：

- アドベンチスト賛美歌集（Hinário Adventista）、アルバム、コレクションの歌詞；
- 聖書で選択した聖句；
- 礼拝の開始や進行のための時計とタイマー；
- PIANOのどのモジュールから開始した投影も表示可能です。

## ペアリングの前に必要なもの

1. LGテレビの電源を入れ、教会のネットワークに接続します。
2. 操作用のパソコンまたはスマートフォンを同じネットワークに接続して、ローカルペアリングを可能にします。
3. 別の機器で[ダウンロード](/download)ページを開きます。
4. テレビのセクションと**LG/webOS**カードを確認します。
5. ダウンロードボタンが有効になっている場合のみ、公式ファイルを使用します。
6. 公開ファイルがない場合は、webOSのブラウザーまたはHDMI経由の外部レシーバーを準備します。
7. プログラムの前に、テレビのネットワーク接続をテストします。

ダウンロードページは、レシーバーによって公開されたアセットが存在する場合にwebOSチャンネルを認識します。LG Content Storeによる現在の公開については、参照した情報源では確認されていません。

## webOSのブラウザーを代替として使うには？

レシーバーアプリが利用できない場合、ブラウザーが役立ちます。名称はwebOSのバージョンによって異なる場合があります。

1. リモコンの**Home**ボタンを押します。
2. **ウェブブラウザー**、**Browser**、または同等の項目を開きます。
3. `app.pianolouvorja.com.br` を入力します。
4. ページが読み込まれるのを待ちます。
5. ページの表示と読み込みのテストを行います。
6. フリーズや操作しづらさがある場合は、HDMIで接続した外部機器でPalcoを使用してください。

ブラウザーはあくまで代替手段です。専用投影のための推奨フローは、別の機器で操作し、テレビをPalcoの画面として使うことです。

## Palcoを操作機器とペアリングするには？

1. テレビに接続したレシーバーでPalcoを開くか、テレビで準備したWebアプリを開きます。
2. 礼拝を操作するパソコン、スマートフォン、またはタブレットでPIANOを開きます。
3. **リモコンとPalco**（Controle remoto e Palco）を開きます。
4. 画面に応じて、同一ネットワークでのペアリングまたはサーバー経由のペアリングを選択します。
5. コードまたは要求された情報を確認します。
6. 接続状態が表示されるのを待ちます。
7. 賛美歌を開いて**投影**（Projetar）をクリックします。
8. 一節送りして、テレビで更新されることを確認します。

ローカルモードを選ぶ場合は、両方の機器を同じネットワークに接続してください。来訪者用ネットワークでは互いに認識できないことがあります。

## 礼拝のテストを行うには？

1. 賛美歌を投影し、一節ずつ送ってください。
2. **聖書**の一節をテストします。
3. **ユーティリティ**（Utilitários）を開き、時計を投影します。
4. 礼拝で使用する場合は、タイマーとカウントダウンをテストします。
5. 計画した礼拝順序を開き、メディア項目を確認します。
6. 音声がある場合はテレビの音量を確認します。
7. 投影を終了し、テレビが正しく反応することを確認します。

メディアと賛美歌は事前に準備してください。PIANOは、プログラムを操作している機器にダウンロード、進捗、設定を保存します。

## 歌詞・背景・コントラストを調整するには？

1. 操作機器で**設定**（Configurações）を開きます。
2. **投影**（Projeção）を開きます。
3. 背景色と文字色を設定します。
4. 会堂の距離に合わせてフォントサイズを大きくします。
5. 明るい背景の上ではテキストボックスを有効にします。
6. 配置と背景画像を調整します。
7. 教会の後ろから読み取れるか、誰かに確認してもらいます。

## LGテレビが接続できない場合は？

1. テレビと操作機器のWi-Fiまたはネットワークケーブルを確認します。
2. テレビのブラウザーまたはレシーバーを閉じて開き直します。
3. 操作機器が来訪者用ネットワークに接続されていないか確認します。
4. PIANOで利用可能な場合は、サーバー経由のオプションでペアリングをやり直します。
5. 急ぎの場合は、HDMIでパソコンをテレビに接続して礼拝を続けてください。

## 操作機器で礼拝を準備するには？

1. テレビを操作するパソコン、スマートフォン、またはタブレットで**礼拝順序**（Liturgia）を開きます。
2. プログラムの各場面ごとにカテゴリを作成します。
3. 楽曲、メディアファイル、リンク、チーム用メモを追加します。
4. 項目をドラッグして順序を調整します。
5. 必要な賛美歌と資料は事前にダウンロードします。
6. プログラムを保存します。
7. 開始前に最初の項目を開いた状態にしておきます。

## LGテレビで聖書とユーティリティを使うには？

1. 操作機器で**聖書**を開きます。
2. 版、書巻、章、聖節を選択します。
3. **投影**をクリックし、テレビで聖句を確認します。
4. **ユーティリティ**を開いて時計またはタイマーを表示します。
5. テレビでの視認性に合わせて色を調整します。
6. タイマーまたはカウントダウンを開始します。
7. 礼拝前に投影の終了操作をテストします。

## プログラム前に問題を避けるには？

1. テレビは早めに電源を入れます。
2. インターネットまたはローカルネットワークを確認します。
3. リモコンを手元に置いておきます。
4. 教会の後方からの画面表示テストを行います。
5. 外部レシーバーがある場合はHDMIケーブルを確認します。
6. 礼拝の直前にテレビをアップデートしないでください。
7. ネットワーク障害に備えて、HDMIによる代替手段を準備しておきます。

## プログラムの変更があった場合は？

1. オペレーターは**メディアセンター**（Central de Mídia）で新しい賛美歌を探します。
2. その項目をテレビに直接投影します。
3. チームが変更を記録する必要がある場合は礼拝順序を更新します。
4. メモを使って次のプログラム担当者に伝えます。
5. テレビはPalcoのままにし、リモコンで礼拝を操作しようとしないでください。
6. 会衆に歌っていただく前に、歌詞を目視で確認します。
7. 変更が終わったら通常の順序に戻ります。

## 礼拝前の最終チェックリスト

1. 選んだ機器でPIANOが開くことを確認します。
2. 賛美歌と資料が利用可能であることを確認します。
3. 礼拝順序が正しい順になっていることを確認します。
4. 教会のスクリーンにテスト投影が表示されることを確認します。
5. 会堂の後方で文字サイズとコントラストを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 操作担当者を一人決めておきます。
