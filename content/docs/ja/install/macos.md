# PIANO LouvorJA を macOS にインストールする

お使いの Mac に対応した DMG ファイルをダウンロードし、PIANO を**アプリケーション**フォルダにドラッグして開きます。M1 以降のチップを搭載した Mac は ARM64、Intel Mac は X64 を使用します。macOS が初回起動をブロックした場合は、右クリックメニューから開いてください。

## Mac が Apple Silicon か Intel かを確認するには?

チップの種類によってダウンロードするファイルが決まります。

1. 画面左上の **Apple** メニューをクリックします。
2. **この Mac について** を選択します。
3. **チップ** または **プロセッサ** の行を確認します。
4. **Apple M1**、**M2**、**M3**、**M4** などの Apple チップと表示された場合は、**ARM64** を選びます。
5. **Intel** と表示された場合は、**X64** を選びます。

迷った場合は、両方のファイルをダウンロードしないでください。続行する前に **この Mac について** の画面をもう一度確認しましょう。

## 正しいファイルはどこからダウンロードする?

公式ファイルは、macOS 用 PIANO LouvorJA の各バージョンで DMG として公開されています。

1. [ダウンロード](/download) を開きます。
2. **macOS** を選択します。
3. Apple Silicon の場合は **DMG ARM64** を、Intel の場合は **DMG X64** を選択します。
4. ダウンロードが完了するまで待ちます。
5. **ダウンロード** フォルダを開きます。

必ず公式ページからダウンロードしてください。似た名前のファイルが第三者から送られてきた場合、正しいバージョンではない可能性があります。

## DMG のインストール方法は?

DMG を開くと、アプリ本体とアプリケーションフォルダが入った小さなウィンドウが表示されます。

1. ダウンロードした DMG ファイルをダブルクリックします。
2. インストールウィンドウが表示されるまで待ちます。
3. **PIANO LouvorJA** を、ウィンドウに表示されている **アプリケーション** フォルダへドラッグします。
4. コピーが完了するまで待ちます。
5. **Finder** を開きます。
6. **アプリケーション** に移動します。
7. **PIANO LouvorJA** をダブルクリックします。
8. 開けることを確認したら、Finder からインストーラのディスクを取り出します。

アプリを DMG 内で実行したままにしないでください。**アプリケーション** フォルダにコピーすることで、ダウンロードしたファイルに依存しなくなります。

## macOS が初回起動をブロックした場合は?

インターネットからダウンロードしたアプリでは発生することがあります。一度だけ右クリックメニューから開いてください。

1. **Finder** を開き、**アプリケーション** に移動します。
2. **PIANO LouvorJA** を見つけます。
3. アイコンを右クリック、または Control キーを押しながらクリックします。
4. **開く** を選択します。
5. 確認メッセージが表示されたら、もう一度 **開く** をクリックします。
6. 次回以降は、Launchpad、Dock、アプリケーションフォルダから普通に開けます。

必要がない限り、Mac のセキュリティ設定を変更しないでください。この手順で許可されるのは、開こうと選択したアプリのみです。

## 初回起動時に何をすればいい?

PIANO はカタログを準備し、情報を端末内に保存します。

1. **アプリケーション** から PIANO LouvorJA を開きます。
2. 初回の準備中はインターネットに接続したままにします。
3. 必要に応じて、ヘッダーの **−** と **＋** ボタンで画面サイズを調整します。
4. **メディアセンター** でアドベンチスト讃美歌の讃美歌を検索します。
5. 礼拝でチームが使用する讃美歌やコレクションをダウンロードします。
6. **リトゥルギア（礼拝プログラム）** でプログラムを作成します。
7. **設定** を開き、色、背景、投影サイズを調整します。

ダウンロードは後から続けることもできます。アプリを閉じても、保存された進行状況は戻ったときにそのまま使えます。

## 礼拝前にどうテストする?

簡単なテストで、賛美やメッセージの時間に驚かされることを避けられます。

1. **メディアセンター** で讃美歌を開きます。
2. **投影** をクリックします。
3. 番とサビを送ります。
4. **聖書** を開き、一節を選んで投影します。
5. **ユーティリティ** で時計、タイマー、カウントダウンを試します。
6. 文字が小さく感じる場合は、**設定** でフォントサイズを大きくします。

テレビやプロジェクターなどの画面を使う場合は、事前に接続し、チーム全体で十分にテストしてください。PIANO は操作用の画面と、教会が見る画面を分けています。

## PIANO を整理した状態に保つには?

準備されたコンピュータは、安息日の作業をスムーズにします。

1. DMG は再インストールが必要なときだけ保管し、アプリは **アプリケーション** フォルダから使います。
2. 讃美歌、コレクション、リトゥルギアのコンテンツは事前にダウンロードしておきます。
3. リトゥルギアでは、**安息日学校**、**賛美**、**献金**、**メッセージ** などのカテゴリを使用しましょう。
4. コンピュータを買い替える前に、**設定** でバックアップを作成します。
5. プログラム開始前にメディアファイルをテストします。

## プログラムの前にリトゥルギアを整理するには?

リトゥルギアを使うと、礼拝の項目を順序立ててまとめられ、プログラム中にコンテンツを探す必要がなくなります。

1. **リトゥルギア** を開き、新しいプログラムを作成します。
2. **受付**、**賛美**、**メッセージ**、**閉会** などのカテゴリを作成します。
3. 楽曲、聖句、動画、画像、PDF、プレゼンテーションを追加します。
4. チーム用のメモを書きましょう。教会の画面には表示されません。
5. 項目をドラッグして順序を調整します。
6. 保存して開き直し、確認します。
7. 礼拝中は項目ごとに送り、完了した内容を追跡します。

## インターネットなしで使えるようコンテンツを準備するには?

PIANO にダウンロード済みのコンテンツは、接続が切れても Mac 上で引き続き利用できます。

1. 週のうちにインターネットへ接続します。
2. 使用予定の讃美歌を開きます。
3. 必要な項目で **ダウンロード** をタップします。
4. 進行状況バーが完了するまで待ちます。
5. リトゥルギアの動画、PDF、ローカルのプレゼンテーションファイルも確認します。
6. 新たな検索に頼らずに動作するかテストします。
7. アプリを閉じても、ダウンロードの進行状況は保持されます。

## ステージをテレビで使うには?

ネットワークに接続されたテレビを会衆用の画面として使う場合に、ステージを利用します。

1. テレビまたはレシーバーを教会のネットワークに接続します。
2. テレビに接続された機器でステージを開きます。
3. Mac で **リモコンとステージ** エリアを開きます。
4. 画面の表示に応じて、ローカルペアリングまたはサーバー経由を選択します。
5. 表示されたコードまたはデータを確認します。
6. 讃美歌を投影し、一つ番を送ります。
7. テレビに投影画面だけが表示されていることを確認します。

## 礼拝前の最終チェックリスト

1. PIANO が選択した機器で開けることを確認します。
2. 讃美歌や資料が利用可能であることを確認します。
3. リトゥルギアが正しい順序になっていることを確認します。
4. 教会の画面にテスト投影が表示されることを確認します。
5. 会堂の背景に対する文字サイズとコントラストを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 操作担当者を一人決めておきます。
