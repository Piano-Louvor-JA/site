# AndroidにAPKでPIANO LouvorJAをインストールする

APKはPIANO LouvorJAの公式ページからのみダウンロードしてください。Androidはブラウザーにこのファイルのインストール許可を求めます。ダウンロードに使用したブラウザーだけを許可し、インストールを完了させてからアプリを開き、礼拝のコンテンツを準備しましょう。

## 公式APKはどこからダウンロードできますか？

Android版APKは公式リリースとして公開されており、ダウンロードページで正しい手順が案内されます。

1. スマートフォンまたはタブレットのブラウザーを開きます。
2. [download](/download) にアクセスします。
3. **Android** セクションを探します。
4. APKをダウンロードするボタンをタップします。
5. ダウンロードが完全に終わるまで待ちます。
6. ダウンロードの通知、または **ダウンロード** フォルダーを開きます。

出所を確認できないグループ、メール、USBメモリーなどで受け取ったAPKはインストールしないでください。公式ページが最新バージョンの基準となります。

## APKのインストールを許可するには？

メニュー名はメーカーによって異なりますが、流れは似ています。Androidはファイルを開いたアプリ（通常はChromeやファイルマネージャー）に対して許可を求めます。

1. ダウンロードしたAPKファイルをタップします。
2. セキュリティ警告が表示されたら、**設定** をタップします。
3. **このソースを許可** または **不明なアプリのインストール** を有効にします。
4. 前の画面に戻ります。
5. **インストール** をタップします。
6. 完了を待ちます。
7. **開く** をタップします。

インストール後は、同じメニューでこの許可を無効にできます。これにより、確認なしに他のファイルがインストールされるのを防げます。

## 警告が表示されない場合、この許可はどこにありますか？

端末のシステム内で相当する名称を探してください。

1. Androidの **設定** を開きます。
2. **アプリ** または **アプリケーション** に入ります。
3. APKのダウンロードに使用したブラウザー（Chromeなど）、またはファイルマネージャーを選択します。
4. **不明なアプリのインストール** を開きます。
5. **このソースを許可** を有効にします。
6. **ダウンロード** フォルダーに戻り、APKを再度開きます。

機種によっては、**セキュリティ** や **プライバシー** の中にこの項目があります。大切なのは、インストールを実行するアプリだけを許可することで、管理できない包括的な許可を与えないことです。

## 初回使用時に行うことは？

教会のプログラムの前にコンテンツを準備しましょう。

1. **PIANO LouvorJA** を開きます。
2. 初期準備の間は端末をインターネットに接続したままにします。
3. ヘッダーに表示される場合は、**−** と **＋** のボタンでインターフェースのサイズを調整します。
4. **メディアセンター** を開き、プログラムの賛美歌を検索します。
5. 必要なコンテンツをダウンロードします。進行状況は保存されます。
6. ** liturgy（礼拝程序）** で、賛美、聖書、ファイル、チームのメモを整理します。
7. **設定** で、投影の色や文字サイズをテストします。

ダウンロードしたコンテンツと設定は端末内に保存されます。インターネットのない礼拝に備えて、事前に項目をダウンロードし、テストしておきましょう。

## スマートフォンをリモコンとして使うには？

PIANOは同じネットワークまたはサーバーを介して端末同士をペアリングできます。

1. PIANOの **リモートコントロール** エリアを開きます。
2. 利用可能なペアリング方式を選択します：同じネットワークまたはサーバー。
3. 画面に表示されるコードまたは確認に従います。
4. 賛美歌の検索、歌詞の送り、聖句の切り替えをテストします。
5. 礼拝の前に、選択のクリアと投影の終了もテストしておきましょう。

リモートコントロールがあれば、チームはコンピューターのそばにいなくても、歌詞、聖句、タイマー、カウントダウン、時計を操作できます。

## Android TV Boxでも使えますか？

はい、対応するAndroid端末の選択肢として利用できます。TV Boxのブラウザーから公式ページ経由でAPKをダウンロードするか、確認済みの公式ソースから転送してください。テレビでの最適な使い方は **ステージ（Palco）** で、別の端末から操作された投影を受け取ります。

1. TV Boxを、PIANOを操作する端末と同じネットワークに接続します。
2. TV Boxのブラウザーを開き、使用可能であれば [download](/download) にアクセスします。
3. 公式APKをダウンロードし、そのブラウザーまたはファイルマネージャーに対してインストールを許可します。
4. インストールしたアプリを開きます。
5. 操作用端末で、**ステージ（Palco）** のペアリングを開きます。
6. テレビ側の受信端末をネットワークに接続し、PIANOが表示するペアリングを完了させます。
7. テスト用の賛美歌を投影し、テレビに教会の画面のみが表示されることを確認します。

Android TVやGoogle TVでの具体的な手順は、専用のページをご覧ください。

## 礼拝当日のトラブルを防ぐには？

1. 端末を充電しておくか、電源に接続しておきます。
2. プログラムの前に賛美歌とメディアをダウンロードしておきます。
3. ステージやローカルのリモートコントロールを使う場合は、すべての端末を同じネットワークに接続します。
4. 動画、PDF、聖書箇所を含め、礼拝程序全体をテストします。
5. 開始の数分前にAndroidシステムを更新したり、アプリを変更したりしないでください。

## ペアリング後に歌詞と聖書を投影するには？

1. 操作用端末で **メディアセンター** を開きます。
2. タイトルまたは賛美歌の一部で検索します。
3. 結果を開き、**投影** をタップします。
4. 番と副歌を送り進めると、ステージがテレビ上で同期します。
5. **聖書** を開き、バージョン、書、章、節を選択します。
6. **投影** をタップして箇所を送信します。
7. **ESC** または利用可能なコマンドで投影を終了します。

## Androidで礼拝程序を準備するには？

1. **礼拝程序（Liturgy）** を開き、プログラムを作成します。
2. 礼拝の各部分のために区切りを追加します。
3. 賛美、ファイル、リンク、メモを追加します。
4. 必要に応じて、**祈り** や **歓迎** などの補助タイトルを使用します。
5. 項目をドラッグして最終的な順序に並べます。
6. 保存して結果を確認します。
7. プログラム中は項目を一つずつ送り進めます。

## バッテリーとネットワークの管理は？

1. 使用前にスマートフォン、タブレット、TV Boxを充電します。
2. 長いプログラムでは、操作用端末を電源に接続したままにします。
3. ローカルのステージのために、機器を同じネットワークに接続します。
4. 礼拝中はWi-Fiネットワークを切り替えないようにします。
5. 操作者の注意を妨げる可能性のある通知は無効にします。
6. 開始前に賛美歌とメディアをダウンロードしておきます。
7. 接続と投影を事前にテストします。

## Androidがインストールを妨げる場合は？

1. ファイルが公式ページからのものであるか確認します。
2. ダウンロードが完了しているか確認します。
3. **不明なアプリのインストール** は、APKを開いたアプリに対してのみ許可します。
4. ファイルに戻り、再度 **インストール** をタップします。
5. ストレージがいっぱいの場合は、空き容量を作ってから再試行します。
6. APKが端末に対応していない場合は、ブラウザーでPWAを使用してください。
7. インストール時の一時的な許可以外の、システムの保護機能は無効にしないでください。

## 礼拝前の最終チェックリスト

1. PIANOが選択した端末で開くことを確認します。
2. 賛美歌と資料が利用可能であることを確認します。
3. 礼拝程序が正しい順序になっていることを確認します。
4. 教会のスクリーンがテスト投影を受け取ることを確認します。
5. 会堂の後ろで文字サイズとコントラストを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 操作担当者を一人決めておきます。
