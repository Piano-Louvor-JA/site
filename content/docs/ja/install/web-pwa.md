# ブラウザーとアプリでPIANO LouvorJAを使う

PIANOは[app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)から直接開けます。Chrome、Edge、Androidでは、アプリとしてホーム画面に追加できます。初回の読み込み後は、端末にすでに読み込まれたコンテンツに応じて、オフラインでも引き続き利用できる場合があります。

## 何もインストールせずにPIANOを開くには?

ブラウザーは最も手軽に始められる方法で、PIANOの試用、別のパソコンでの使用、教会以外でのプログラムのサポートに便利です。

1. 最新のブラウザーを開きます。
2. `app.pianolouvorja.com.br` と入力します。
3. アプリの読み込みを待ちます。
4. **メディアセンター**を開いて、賛美歌や歌集を探します。
5. **礼拝程序**を使ってプログラムを整理します。
6. 礼拝の開始前に投影をテストします。

マルチスクリーン投影を快適に行うには、パソコンが最も実用的な選択肢です。ブラウザーはタブレット、スマートフォン、共用端末でも引き続き活用できます。

## パソコンのChromeやEdgeでアプリとしてインストールするには?

PWAとしてインストールすると、PIANOを専用ウィンドウで開くショートカットが作成され、ブラウザーのタブを探す必要がなくなります。

1. ChromeまたはEdgeで [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br) を開きます。
2. アドレスバーの横にインストールアイコンが表示されたら、探します。
3. **インストール** または **PIANO LouvorJAをインストール** をクリックします。
4. インストールを確認します。
5. アプリメニューやデスクトップに作成されたショートカットからPIANOを開きます。
6. 賛美歌、聖書、投影をテストします。

アイコンが表示されない場合は、ブラウザーの三点メニューを開き、**アプリをインストール**、**このページをアプリとしてインストール** などの項目を探してください。

## Androidでホーム画面に追加するには?

Androidでは、PIANOをホーム画面のアイコンとして利用できます。

1. Chromeで [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br) を開きます。
2. 三点メニューをタップします。
3. **ホーム画面に追加** または **アプリをインストール** を選びます。
4. 名前を確認して、**追加** または **インストール** をタップします。
5. ホーム画面またはアプリ一覧でPIANOのアイコンを探します。
6. アイコンから開き、礼拝前にテストします。

ブラウザーによって表記は異なる場合があります。サイトをアプリとして追加、またはホーム画面に追加する項目を探してください。

## PIANOはブラウザーでオフライン動作しますか?

初回の読み込み後は、端末にすでに読み込まれたデータやコンテンツに応じて、PWAがオフラインでも利用できる場合があります。礼拝の前に、インターネット接続があるうちに準備を済ませましょう。

1. インターネットに接続した状態で、PIANOを少なくとも一度は開きます。
2. 使用する賛美歌をあらかじめ検索してダウンロードしておきます。
3. 礼拝程序を開き、必要な項目が準備できているか確認します。
4. インターネットがまだ利用できるうちに投影をテストします。
5. その後、接続が切れても、端末に保存済みの準備済みコンテンツを使用できます。

まだ読み込んでいないコンテンツに頼るのは、プログラムの開始を待ってからにしないでください。初回アクセスや新しいアップデートには接続が必要です。

## ブラウザー、PWA、インストールアプリはいつ使い分ける?

教会の利用形態に合わせて選びましょう。

| 状況                                                         | 最適な選択                              |
| ------------------------------------------------------------ | --------------------------------------- |
| 素早く試す、または借用したパソコンを使う                     | `app.pianolouvorja.com.br` のブラウザー |
| 従来型のプログラムをインストールせず同じパソコンで使い続ける | ChromeまたはEdgeでインストールしたPWA   |
| デュアルモニターでの投影と教会の定例運用                     | Windows、macOS、Linux向けアプリ         |
| スマートフォンやタブレットでの操作                           | ブラウザーのPWAまたはホーム画面に追加   |
| 投影を受信するネットワーク接続のテレビ                       | 対応端末でのステージ                    |

オペレーターの画面と教会の画面を分けた安定した運用が必要なチームには、インストール版がおすすめです。

## PWAでプログラムを準備するには?

礼拝の進行のしかたは同じです。事前に準備し、プログラム中に進めていきます。

1. **メディアセンター**で、タイトルまたは歌詞の一部から賛美歌を検索します。
2. 賛美歌をダウンロードして、端末でコンテンツを利用できるようにします。
3. **礼拝程序**で、**受付**、**安息日学校**、**賛美**、**メッセージ**、**閉会** などのカテゴリーを作成します。
4. 楽曲、動画、画像、PDF、プレゼンテーション、リンク、チームのメモを追加します。
5. 項目をドラッグして順番を調整します。
6. 保存して、再度開いて確認します。
7. 礼拝中は項目を一つずつ進め、完了した項目を確認しながら進行します。

## 教会の画面を読みやすくするには?

1. **設定** を開きます。
2. **投影** に入ります。
3. コントラストの強い色を選びます。
4. 会衆との距離に応じて、フォントを50%〜200%の間で調整します。
5. 背景が明るい画像の場合は、テキストボックスを有効にします。
6. 配置と背景を調整します。
7. 開始前にプロジェクターまたはテレビでテストします。

## PWAで聖書とユーティリティを使うには?

1. **聖書** を開きます。
2. バージョン、書巻、章、節(または複数の節)を選びます。
3. **投影** をクリックして、教会の画面にテキストを送ります。
4. 時刻を表示するには、**ユーティリティ** を開いて **時計** を選びます。
5. 色、12時間制・24時間制、秒の表示を調整します。
6. 時間を管理するには、**タイマー** または **カウントダウン** を使います。
7. 開始前にすべてテストします。

## PIANOをリモートで操作するには?

1. メイン端末で **リモートコントロールとステージ** のエリアを開きます。
2. 同一ネットワークでのペアリングまたはサーバー経由を選びます。
3. 端末に表示される確認を完了します。
4. 賛美歌の検索と楽曲の再生をテストします。
5. 節送りの進行と選択解除をテストします。
6. タイマーの開始、一時停止、リセットをテストします。
7. セカンドスクリーンにチーム用のコントロールが表示されないことを確認します。

## PWAがオフラインで開かない場合は?

1. 端末をインターネットに接続します。
2. ブラウザーで `app.pianolouvorja.com.br` を開きます。
3. ページの読み込みが完了するのを待ちます。
4. 準備とダウンロードをやり直します。
5. 接続を切る前に、賛美歌と礼拝程序を保存しておきます。
6. インターネットに接続できたときにページを更新し、最新バージョンを受け取ります。
7. 定例の投影運用には、デスクトップアプリの利用を検討してください。

## プログラムに向けてブラウザーを準備しておくには?

1. 使用しないタブを閉じます。
2. 可能であれば、ブラウザーの通知を無効にします。
3. 必要なコントロールが隠れない場合にのみ、全画面表示を使います。
4. パソコンがスリープモードに入らないよう確認します。
5. 充電器とネットワーク接続を確保しておきます。
6. 礼拝程序を開き、最初の項目を準備しておきます。
7. 最終的な投影テストを行います。

## 礼拝前の最終チェックリスト

1. 選択した端末でPIANOが開くことを確認します。
2. 賛美歌と素材が利用可能であることを確認します。
3. 礼拝程序が正しい順序になっていることを確認します。
4. 教会の画面でテスト投影が表示されることを確認します。
5. 会堂の奥から見た文字サイズとコントラストを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 運用担当者を一人決めておきます。
