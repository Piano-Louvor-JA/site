# PIANO LouvorJAをWindowsにインストールする

最も簡単な方法は、Microsoft Storeからインストールすることです。お好みであれば、公式ダウンロードページからポータブル版のEXEファイルをダウンロードすることもできます。その後、PIANOを開いて初期設定を完了し、操作者用と教会用にそれぞれモニターを用意しましょう。

## Microsoft Storeからインストールするには？

Microsoft Storeがアプリのインストールとアップデートを管理します。

1. 公式の[ダウンロード](/download)ページを開きます。
2. **Windows**を選択し、Microsoft Storeのオプションを開きます。
3. Storeで**LouvorJA**を検索します。直接リンクが届いた場合は、プロダクトコード `9N1WPDQKFLR9` を使用します。
4. **入手**または**インストール**をクリックします。
5. ダウンロードの完了を待ちます。
6. **開く**をクリックするか、スタートメニューから**LouvorJA PIANO**を探します。

メッセージや見知らぬサイトで受け取ったコピーはインストールしないでください。Storeには必ず公式ページからアクセスしてください。

## ポータブル版EXEを使うには？

EXEは、Storeを使いたくない方向けの公式な代替手段です。GitHubで公開されているバージョンから入手でき、ダウンロードページからダウンロードできます。

1. [ダウンロード](/download)ページを開きます。
2. **Windows**エリアで、EXEのダウンロードを選択します。
3. ファイルのダウンロードが完了するのを待ちます。
4. **ダウンロード**フォルダを開きます。
5. PIANOのEXEファイルをダブルクリックします。
6. Windowsが許可を求めた場合は、起動を確認します。
7. ファイルは**ドキュメント/PIANO LouvorJA**など、見つけやすいフォルダに保存しておきましょう。

ポータブル版は従来型のインストールなしで起動します。デスクトップにショートカットを作成するのは、正常に起動することを確認してからにしてください。

## 初回起動時にすることは？

初回起動時、PIANOはカタログを準備し、初期設定画面を表示します。この際はインターネット接続を有効にしておいてください。コンテンツの準備中でも、アプリの操作を覚え始めることはできます。

1. PIANO LouvorJAを開きます。
2. スタート画面の準備が完了するのを待ちます。
3. ヘッダーの**−**と**＋**ボタンでインターフェースのサイズを確認します。
4. **メディアセンター**を開き、アドベント・賛美歌集（Hinário Adventista）の賛美歌やコレクションを検索します。
5. 礼拝で使う賛美歌は事前にダウンロードしておきます。アプリを閉じてもダウンロードの進行状況は保存されます。
6. **礼拝式**を開いて、安息日学校、賛美、メッセージなどの順番を組み立てます。
7. **設定**で、教会のスクリーンに合わせて背景、色、文字サイズを調整します。

ダウンロードしたものや設定はコンピューターに保存されます。これには賛美歌、ダウンロードの進行状況、礼拝式、各種設定が含まれます。

## デュアルモニターを準備するには？

一方のモニターでPIANOを操作し、もう一方を会衆向けに使います。操作者は検索結果、ボタン、次の項目を確認でき、教会側は投影のみを見ることができます。

1. プロジェクター、テレビ、またはセカンドモニターをコンピューターに接続します。
2. Windowsで**設定**を開きます。
3. **システム**に入り、次に**ディスプレイ**を開きます。
4. **マルチディスプレイ**で**これらのディスプレイを拡張する**を選択します。
5. モニターのアイコンをドラッグして、実際の配置と一致させます。
6. PIANOを開き、テスト投影を開始します。
7. 教会用のウィンドウをセカンドモニターまたはテレビに表示します。
8. 礼拝前に、歌詞、聖句、時計をテストします。

画面を複製するモードは避けてください。操作画面が教会側に見えてしまいます。**拡張**モードにより、操作者と投影が分かれます。

## 賛美歌や聖句を投影するには？

会衆が到着する前に、十分にテストしておきましょう。

1. **メディアセンター**で賛美歌を検索します。
2. 検索結果を開き、**投影**をクリックします。
3. 番やサビを進めると、教会のスクリーンも連動します。
4. **聖書**で、バージョン、書巻、章、節を選択します。
5. **投影**をクリックして、その箇所をセカンドスクリーンに送ります。
6. 投影を終了するには、**ESC**を使い、確認します。

曲内で指定された箇所がない場合、PIANOはタイトル付きのアルバムカバーを表示することがあります。これは迎拝の時や賛美の前に役立ちます。

## 投影の見やすさを調整するには？

礼拝前に、会堂の広さや会衆との距離に合わせて画面を調整しましょう。

1. **設定**を開きます。
2. **投影**のオプションに入ります。
3. 背景色、文字色、フォントサイズを調整します。
4. 水平・垂直の配置を選択します。
5. 明るい背景や明るい画像を使う場合は、テキストボックスを有効にします。
6. 可能であれば、教会の最後尾の席からテストします。
7. 設定を保存すると、コンピューターに保持されます。

聖なる賛美歌の歌詞では、コントラストとサイズを優先しましょう。どんなに美しい画像でも、教会が歌詞を追えなければ意味がありません。

## 動画や音声が別のプログラムで開いたら？

Windowsでは、PIANOで動画やメディアファイルの開き方を選択できます。

1. **設定**を開きます。
2. **外部プレイヤー**を探します。
3. Windowsの標準プログラムを使うには、**システムに紐付け**を選択します。
4. 他のプレイヤーが検出されていれば、それを選択できます。
5. 礼拝式の動画や音声でテストしてください。

## 次の礼拝に向けて準備を整えるには？

週のうちに落ち着いて準備しておくことで、安息日のチームの負担が減ります。

1. 前回の礼拝式を開き、参考にできるなら活用します。
2. プログラムの補足タイトル、時刻、カテゴリーを更新します。
3. まだコンピューターにない賛美歌、動画、ファイルを事前にダウンロードします。
4. 各メディア項目を開いて、正常に動作するか確認します。
5. コンピューターを変更する前に、**設定**でバックアップを作成します。
6. ノートパソコンを電源に接続し、充電器を取り出しやすい場所に置きます。
7. 開始15分前に、短いテスト投影を行います。

## 投影が更新されない場合は？

1. セカンドモニターがWindowsに接続されたままであることを確認します。
2. 投影ウィンドウが**メディア**や**聖書**など、正しいモジュールで開かれているか確認します。
3. 使用中の項目の投影を開き直します。
4. Windowsがまだ**これらのディスプレイを拡張する**になっているか確認します。
5. 必要であれば、PIANOを閉じて開き直します。保存されたコンテンツは引き続き利用できます。
6. 教会に予備があれば、予備のビデオケーブルを使います。

## チームで作業するには？

操作する人と、教会のスクリーンを確認する人をそれぞれ決めましょう。

1. 操作者が礼拝式を開き、項目を進めます。
2. もう一人が、投影された歌詞、聖句、コントラストを確認します。
3. 開始前に、二人で賛美とメッセージの順番を見直します。
4. 変更がある場合は、礼拝式にメモを残してチームに伝えます。
5. プログラムの進行中に、複数の人が同じコンピューターを操作しないようにしましょう。

## 礼拝前の最終チェックリスト

1. PIANOが選択した機器で開くことを確認します。
2. 賛美歌と資料が利用可能であることを確認します。
3. 礼拝式が正しい順番になっていることを確認します。
4. 教会のスクリーンにテスト投影が表示されることを確認します。
5. 会堂の後方でも文字サイズとコントラストが十分であることを確認します。
6. ネットワーク、電源、必要なケーブルを確認します。
7. 操作の担当者を決めておきます。
