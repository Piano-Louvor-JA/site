# Android TV・Google TVでPIANO LouvorJAを使う

Android TVやGoogle TVでは、TVのブラウザまたは安全な転送方法で公式APKをインストールし、**ステージ（Palco）**を使って投影を受け取ります。別の端末で賛美歌・聖書・典礼・ユーティリティを操作し、TVは教会が見る映像専用になります。

## ステージはAndroid TVで何をする？

ステージはネットワーク経由でPIANOの投影を受け取ります。チームの作業と会衆のスクリーンを分ける役割を持ちます。

TVでは、教会が見るのは以下のみです：

- アドベンチストの賛美歌や歌集の歌詞；
- 聖書の節；
- 時計、タイマー、カウントダウン；
- オペレーターが開いたその他の投影資料。

パソコン・スマートフォン・タブレットでは、チームが検索、典礼、調整、操作を行います。

## インストール前にTVを準備するには？

1. Android TVまたはGoogle TVの電源を入れます。
2. 教会のネットワークに接続します。
3. 操作用のパソコンやスマートフォンが同じネットワークに接続できるか確認します。
4. 信頼できる端末で [download](/download) を開きます。
5. **Android TV**用の公式ファイルまたは互換性のあるAPKがあるか確認します。
6. ダウンロードは公式チャネルからのみ行ってください。
7. プログラムの前にテストする時間を確保してください。

ダウンロードページでは、公開されているアセットがあればAndroid TVがレシーバー用プラットフォームとして認識されます。Android用APKも、互換性のあるAndroid端末にインストールするための公式チャネルです。

## TVのブラウザでAPKをダウンロードするには？

TVに使えるブラウザがある場合にこの方法を使います。

1. Android TVまたはGoogle TVのブラウザを開きます。
2. [download](/download) にアクセスします。
3. PIANOの公式APKを見つけます。
4. ファイルをダウンロードし、完了を待ちます。
5. ダウンロード一覧またはファイルマネージャーを開きます。
6. TVが許可を求めた場合は、使用したブラウザまたはファイルマネージャーに対してのみ「不明なアプリのインストール」を許可します。
7. **インストール** を選択します。
8. PIANOまたはインストールされたレシーバーを開きます。

メニュー名はメーカーによって異なります。**セキュリティ**、**アプリ**、**権限**、**不明なアプリのインストール** などを探してください。

## 安全な転送でインストールするには？

TVのブラウザが限られている場合はこの方法を使います。転送するのは公式ページからダウンロードしたAPKのみにしてください。

1. 信頼できるパソコンやスマートフォンで公式APKをダウンロードします。
2. ファイルをUSBメモリーや、TVで使えるファイル転送手段に移します。
3. その方法を選んだ場合は、USBメモリーをTVに接続します。
4. TVのファイルマネージャーを開きます。
5. 必要に応じて、そのファイルマネージャーに「不明なアプリのインストール」を許可します。
6. APKを開き、**インストール** を選択します。
7. インストール後、古いファイルとの混同を避けるためUSBメモリーを取り外します。

出所不明のAPKは使用しないでください。教会のインターネットが不安定な場合に備え、公式ファイルの確認済みコピーを保管しておきましょう。

## PIANOとペアリングするには？

1. Android TVでステージまたはレシーバーを開きます。
2. チームのパソコン・スマートフォン・タブレットでPIANOを開きます。
3. **リモートコントロールとステージ** に入ります。
4. 表示されるオプションに応じて、同じネットワークでのペアリングまたはサーバー経由を選択します。
5. 両方の端末が求めるコードや情報を確認します。
6. 接続が確認されるまで待ちます。
7. **メディアセンター** で賛美歌を開き、**投影** をクリックします。
8. 番を送り、TVの画面を確認します。

ローカルペアリングでは、両方の端末が同じネットワーク上にある必要があります。ゲスト用ネットワークは通常、端末同士を分離します。

## 礼拝前にテストするには？

完全なテストを行いましょう。インストールの確認だけでは不十分です。

1. 賛美歌を投影し、番・リフレーン・表紙を送ります。
2. 聖書の一節を投影します。
3. **ユーティリティ** で時計・タイマー・カウントダウンをテストします。
4. プログラムのカテゴリーを含む典礼を開きます。
5. 礼拝で使う動画・音声・画像・PDF・プレゼンテーションを確認します。
6. **設定** でフォントとコントラストを調整します。
7. ホールの最も遠い場所からの視認性を確認します。
8. 投影を終了し、TVが反応することを確認します。

## 投影を読みやすくするには？

1. 操作端末で **設定** を開きます。
2. **投影** に入ります。
3. 文字と背景に高いコントラストを使います。
4. 教会の距離に合わせてフォントサイズを調整します。
5. 背景に明るい画像がある場合はテキストボックスを有効にします。
6. 水平・垂直の配置を調整します。
7. 長い歌詞と聖書の一節でテストします。

## APKがインストールできない、またはステージが接続できない場合は？

1. ファイルが公式ページから来たものか確認します。
2. TVに空き容量があるか、ダウンロードが完了しているか確認します。
3. 使用したブラウザまたはファイルマネージャーにインストールの許可があるか確認します。
4. レシーバーまたはTVを再起動して再試行します。
5. 操作端末とTVが同じネットワーク上にあることを確認します。
6. 礼拝間近で接続が失敗する場合は、一時的にHDMIでTVに接続したパソコンを使いましょう。

## 操作端末で典礼を整理するには？

1. チームのパソコン・スマートフォン・タブレットで **典礼** を開きます。
2. 礼拝の各場面を分けるカテゴリーを作成します。
3. 音楽・聖書・ローカルメディア・リンク・メモを追加します。
4. 項目をドラッグして最終的な順序に整えます。
5. 必要な賛美歌やコンテンツは事前にダウンロードしておきます。
6. プログラムを保存して見直します。
7. 礼拝中は項目を一つずつ送り、TVに投影を受け取らせます。

## Android TVでリモートコントロールを使うには？

1. PIANOのメニューから操作端末をペアリングします。
2. 表紙と歌詞付きの楽曲を開くテストをします。
3. 節の送りとクリアのテストをします。
4. 投影を閉じるテストをします。
5. タイマーの開始・一時停止・リセットのテストをします。
6. 時計・カウントダウンのテストをします。
7. 礼拝中の操作は一人だけが担当するようにしましょう。

## 電源・ネットワーク・映像の問題を防ぐには？

1. TVと操作端末を電源に接続したままにします。
2. ステージを開く前にネットワークを確認します。
3. TVにその機能があれば、自動スリープを無効にします。
4. リモートコントロールを充電しておくか、良い電池を入れておきます。
5. ホールの照明に合わせてTVの明るさと画質モードを調整します。
6. プログラム中にWi-Fiネットワークを切り替えないでください。
7. 念のためHDMIケーブルを用意しておきましょう。

## 直前の変更にはどう対応する？

1. 操作端末で **メディアセンター** の検索を使います。
2. 必要な賛美歌やコンテンツを開きます。
3. **投影** をクリックします。
4. 先に進む前にTVで確認します。
5. 典礼のメモを使ってチームに指示します。
6. 変更が終わったら順序に戻ります。
7. 礼拝中のアプリの再インストールや更新は避けましょう。

## 礼拝前の最終チェックリスト

1. PIANOが選択した端末で開くことを確認します。
2. 賛美歌と資料が利用可能であることを確認します。
3. 典礼が正しい順序であることを確認します。
4. 教会のスクリーンにテスト投影が表示されることを確認します。
5. ホールの後方で文字サイズとコントラストを確認します。
6. ネットワーク・電源・必要なケーブルを確認します。
7. 操作担当者を一人決めておきます。
