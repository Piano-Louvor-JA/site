# よくある問題と解決方法

まず症状を確認し、礼拝前に解決方法をテストし、投影のための代替手段を用意しておきましょう。すでにダウンロード済みのコンテンツ、礼拝プログラム（リトゥルギア）、ローカル設定は端末に保存されたままです。

## サポートに問い合わせる前に確認すべきこと

メッセージを送る前に、まずこのチェックを行ってください。頻繁に発生するエラーの多くはこれで解決し、問題が残った場合にもチームが必要な情報を得られます。

1. アプリを閉じて再度開く、またはページを再読み込みする。
2. コンピューター、プロジェクター、TV、音声出力の電源が入っているか確認する。
3. 映像ケーブルが接続されており、TVが正しい入力に設定されているか確認する。
4. コンテンツをダウンロードする場合やWeb版を使用している場合は、インターネット接続を確認する。
5. すでにダウンロード済みの賛美歌を開き、インターネットの問題とアプリの問題を切り分ける。
6. 賛美歌と聖句で投影をテストする。
7. OS、ブラウザまたはアプリのバージョン、影響を受けたモジュール、表示されたメッセージを記録する。
8. パスワード、個人情報、教会の情報が写らないよう注意してスクリーンショットを撮る。

## アプリが開かない、または読み込まれない場合は？

まず再読み込みしてください。Web版では初回アクセスにインターネットが必要です。アプリ版では**再試行**オプションで一時的な不具合を回復できる場合があります。

1. ページを再読み込みする。
2. ブラウザ使用時は `Ctrl+F5` でキャッシュを更新する。
3. 別のサイトでインターネットが機能しているか確認する。
4. シークレットウィンドウでテストし、拡張機能が干渉していないか調べる。
5. ブラウザの設定でサイトのデータを消去し、再度開く。
6. エラー画面が表示されたら、**再試行**をクリックする。
7. ブラウザモードでブリッジがないことがアプリから通知された場合は、利用可能なローカルデータで作業を続けるか、お使いの端末に適したバージョンを使用してください。

それでも解決しない場合は、チェックリストの情報を添え、エラーが発生した時点をお知らせください。

## 賛美歌カタログが読み込まれない場合は？

接続を確認してください。アプリはカタログソースを順番に試しますが、それでもすでにダウンロード済みの項目はオフラインで利用できます。

1. インターネット接続を確認する。
2. アプリを再読み込みする。
3. 必要に応じて、ダウンロード済みの賛美歌を開いてリハーサルや礼拝を続ける。
4. 礼拝プログラムの実行中はローカルデータを削除しない。
5. 接続が回復したら、再度検索を試す。

## 賛美歌がダウンロードできない場合は？

プログレスバーを確認し、接続を維持してください。アプリを閉じても進捗は消えず、後で再開できるように保存されます。

1. インターネットが安定しているか確認する。
2. ダウンロードを開始し、しばらく待つ。
3. 進捗が止まったら、再読み込みするかアプリを開き直す。
4. 同じ賛美歌を再度検索し、ダウンロードが再開されたか確認する。
5. 礼拝では、事前にダウンロードを確認した賛美歌のみを使用する。

## 音声が再生されない場合は？

まずコンピューターの音量と音声出力を確認してください。PIANOは他のセクションに移動しても音声の再生を続けるため、問題は選択された出力またはアイテム自体にある可能性があります。

1. プレイヤーが一時停止ではなく再生中か確認する。
2. PIANOとコンピューターの音量を上げる。
3. 正しいミキサー、スピーカー、またはヘッドホンが選択され、電源が入っているか確認する。
4. 音声付きの別の賛美歌でテストする。
5. デスクトップで外部動画や音声に問題がある場合は、**設定**を開き**外部プレイヤー**を確認する。
6. 既定のプレイヤーを使うには**システムに連動**を選択するか、検出された別のプレイヤーを選びます。
7. 礼拝開始前に再度テストする。

## 動画・PDF・プレゼンテーションが別のプログラムで開く場合は？

デスクトップでは、PIANOはシステムに関連付けられたプレイヤー、または検出・設定された別のプレイヤーを使用できます。

1. **設定**を開く。
2. **外部プレイヤー**に移動する。
3. コンピューターの既定のプログラムを使うには**システムに連動**を選択する。
4. 必要に応じて、VLCなど検出されたプレイヤーを選ぶか、ファイルセレクターで別の実行ファイルを追加する。
5. 項目を再度開いてテストする。
6. 元に戻すには、カスタムプレイヤーを削除しシステム関連付けに戻す。

## 投影が表示されない場合は？

ケーブル、TV／プロジェクターの入力、正しいモジュールの投影が有効かを確認してください。教会のスクリーンはオペレーター画面とは別です。

1. プロジェクターまたはTVの電源を入れる。
2. TVまたはプロジェクターで正しい入力を選択する。
3. コンピューターとスクリーン両方の映像ケーブルを確認する。
4. **メディアセンター**で賛美歌を開く。
5. **投影**をクリックする。
6. スライドを送り、更新されるかテストする。
7. 表示されない場合は、**メディア**や**聖書**など正しいモジュールで投影ウィンドウを開き直す。
8. 聖句や時計など別のコンテンツでテストする。

## セカンドスクリーンが検出されない場合は？

追加スクリーンの認識はコンピューター、ケーブル、OSに依存します。まず物理的な接続とコンピューター自体の画面設定を確認してください。

1. TVまたはプロジェクターの電源を切り、再度入れる。
2. ケーブルを抜き、再度接続する。
3. 可能であれば別のケーブルや入力を試す。
4. コンピューターの画面設定を開き、セカンドスクリーンが表示されているか確認する。
5. お使いのコンピューターに適したデュアルディスプレイモードを選択する。
6. システムがスクリーンを認識したら、PIANOに戻り**投影**をテストする。

Windowsでは `Win+P` ショートカットで「複製」と「拡張」を切り替えられます。macOSではシステム設定 → ディスプレイを開き、画面を物理的な配置に合わせてドラッグしてください。Linuxではディスプレイ設定は設定 → ディスプレイにあります（名称はディストリビューションにより異なります）。

## 歌詞の位置がずれている、または読みにくい場合は？

投影の設定を調整してください。歌詞と聖書にはそれぞれ独自の表示オプションがあります。

1. **設定**を開く。
2. **投影**で、背景色、文字色、フォントサイズ、フォントの太さを調整する。
3. 水平・垂直の配置を調整する。
4. テキストボックスを有効にし、背景が読みにくい場合は不透明度・枠線を変更する。
5. 必要に応じて背景画像を変更・調整する。
6. 聖書については、聖書スタイル固有の設定も確認する。
7. 会衆がスクリーンを見る位置から離れてテストする。

## TVまたはステージ（Palco）が接続できない場合は？

ネットワークとペアリングを確認してください。マニュアルでは、同じネットワーク上でのP2P接続またはサーバー経由の接続を、別々のタブで案内しています。

1. TV／ステージ（Palco）レシーバーと操作用端末の電源が入っているか確認する。
2. P2Pの場合は、両方を同じローカルネットワークに接続する。
3. 端末同士を分離してしまう来訪者用Wi‑Fiは避ける。
4. 操作側とレシーバー側でペアリング画面を開き直す。
5. 再接続し、賛美歌と聖句でテストする。
6. 礼拝中に接続が切れた場合は、可能であれば有線のセカンドスクリーンを代替手段として使用する。

再接続後にTVに古いコンテンツや静止した画面が表示される場合は、PIANO側で再接続を試みる前に、TV上のステージ（Palco）レシーバーを閉じて開き直してください（ブラウザの場合はページを再読み込み）。TVはすでに終了した以前の接続の画面をメモリに保持している場合があります。

## 更新が届いていないように見える場合は？

Web版では、ページを再読み込みすると更新が適用されます。礼拝開始直前ではなく、事前に更新してください。

1. ページを再読み込みする。
2. キャッシュを更新する必要がある場合は `Ctrl+F5` を使用する。
3. インストール版を使用している場合は、アプリを閉じて再度開く。
4. 重要な機能（検索、ダウンロード済み賛美歌、音声、礼拝プログラム、投影）が引き続き動作するか確認する。
5. 変更により使用できなくなった場合は、バージョン、ブラウザ、症状をサポートに報告してください。

## 礼拝プログラム、ダウンロード、設定が失われることはありますか？

アプリを閉じたり、コンピューターを再起動したり、インターネットが切れたりしても、保存済みのローカルデータは消えないはずです。それでも、マシンを変更したりシステムのメンテナンスを行う前にはバックアップを取ってください。

1. **設定**を開く。
2. **バックアップ**を使用してデータと設定をエクスポートする。
3. コピーは、変更対象のコンピューター以外に保管する。
4. 礼拝で頼る前に、別のコンピューターでインポートをテストする。
5. コピーを取らずにアプリのファイルやデータを削除しない。
