# 舞台与多设备

在舞台模式下，一人通过电脑或手机控制聚会，另一块屏幕向教会展示内容。电视、投影仪或舞台接收端负责显示投影；控制设备则继续显示操作界面。

## 什么是舞台？

舞台是通过网络接收聚会投影的屏幕。它适用于与投影仪分开的电视，或希望在不显示控制界面的情况下展示歌词、圣经、时钟和倒计时的教会。

PIANO 有两种功能：

| 功能                       | 作用                                             |
| -------------------------- | ------------------------------------------------ |
| 操作员或遥控器             | 搜索诗歌、打开项目、切换幻灯片、开启或关闭投影。 |
| 舞台、电视或投影仪         | 显示面向会众的内容。                             |

投影屏幕不应作为操作屏幕使用。它只显示为教会选定的内容和视觉风格。

## 电视上显示什么，控制端保留什么？

电视或投影仪接收当前启用模块的投影。电脑或手机则保留带领聚会所需的按钮和列表。

| 内容         | 电视、投影仪或舞台                        | 控制用电脑或手机                         |
| ------------ | ----------------------------------------- | ---------------------------------------- |
| 诗歌         | 歌词、幻灯片、封面及下一句预览，随投影显示 | 搜索、选择诗歌、播放器、音量和切换幻灯片 |
| 圣经         | 以专属样式显示所选经文                    | 选择版本、书卷、章节、经文及控制项       |
| 礼仪程序     | 当前项目的投影内容                        | 聚会流程、分类、已完成项目和备注         |
| 时钟与计时   | 时钟、计时器或倒计时                      | 设置颜色、格式、开始、暂停、标记和归零   |
| 抽签         | 结果、音效和动画                          | 姓名列表、号码或项目以及抽签命令         |

礼仪程序备注是供团队使用的，不应出现在教会屏幕上。

## 配对前如何准备网络？

要使用本地配对，请将控制设备和舞台接收端连接到同一网络。聚会前，请在电视已开机的情况下进行完整测试。

1. 打开电视或投影仪以及显示舞台的设备。
2. 打开将运行 PIANO 的电脑，或准备好控制用的手机。
3. 将所有设备连接到教会的同一 Wi‑Fi 或有线网络。
4. 避免使用会阻止设备互相发现的访客网络。
5. 确认两台设备在测试期间保持连接。
6. 将充电器放在用作控制的手机附近。

手册介绍了两种配对方式：**同一网络 P2P** 和 **通过服务器**，分别位于独立的配对选项卡中。各界面的详细用法和连接码需以实际安装的版本为准。

**底层原理（供技术团队参考）：** 舞台接收端连接到操作员电脑，绝不会反向连接。PIANO 在本地网络（P2P）上开启自有的 WebSocket 连接，或通过中间服务器连接；不使用 Chromecast 或 AirPlay。每台额外的电视占用一个独立的连接"槽位"，因此多块屏幕可以同时工作而互不干扰。

## 如何配对手机或其他控制设备？

打开遥控区域，使用适合教会环境的配对方式。连接后，配对的设备即可控制投影，而不会取代舞台屏幕。

1. 在主电脑上，打开**遥控**或配对区域。
2. 选择可用的配对选项卡：**同一网络 P2P** 或 **通过服务器**。
3. 在手机或其他电脑上，打开相应的连接选项。
4. 按照 PIANO 显示的标识操作，直到两台设备都显示已连接。
5. 进行测试：搜索一首诗歌、打开它并切换一张幻灯片。
6. 保持主电脑开启，作为手机断电或断网时的备用方案。

配对完成后，遥控器可以搜索诗歌、打开带专辑的音乐、切换经文、清除选择、关闭投影、开始、暂停或归零计时器和倒计时、保存标记、设置时钟，以及开启或关闭各模块的投影。

## 如何将舞台连接到电视？

舞台接收端连接到网络并显示投影。它适用于电视与操作电脑分开的情况，或聚会场地有多个屏幕的情况。

1. 在连接电视的设备上打开舞台或接收端。
2. 将该设备连接到团队使用的网络。
3. 在 PIANO 中，打开配对或舞台投影选项。
4. 选择或连接可用的接收端。
5. 打开一首诗歌并点击**投影**。
6. 切换一张幻灯片，确认电视已更新。
7. 再测试一段圣经经文、时钟和倒计时。

舞台接收端支持 LG 电视（webOS）、三星电视（Tizen）、Android TV/Google TV 和浏览器。每个额外的接收端显示为一块独立屏幕：要同时使用多台电视，请将每个接收端连接到操作电脑，并为每个项目选择投影到哪块屏幕——一台电视显示歌词，另一台可以显示时钟或倒计时。

## 如何在舞台上投影诗歌？

舞台连接后，诗歌投影的流程与使用第二显示器时相同。

1. 在控制端，打开**媒体中心**。
2. 搜索《基督复临安息日会赞美诗》中的诗歌、圣诗集或其他为聚会准备的歌曲。
3. 打开诗歌并检查歌词。
4. 点击**投影**。
5. 查看歌词是否出现在电视或投影仪上。
6. 随着演唱切换主歌、副歌和叠句。
7. 当没有选定歌词时，检查封面和标题是否适合会前预热画面。

如果歌词不易阅读，请调整投影设置：背景颜色、文字颜色、大小、字重、对齐方式、背景图片和文本框。

## 如何投影圣经和实用工具？

舞台可以显示与操作员相同的多项投影功能。在特别聚会（如安息日学、青年聚会或典礼）之前，请先逐项测试每个功能。

1. 投影圣经时，打开**圣经**。
2. 选择版本、书卷、章节和经文。
3. 点击**投影**，并在电视上确认显示效果。
4. 使用时钟、计时器、倒计时或抽签时，打开**实用工具**。
5. 配置该功能，包括可用的颜色和格式。
6. 开启相应模块的投影。
7. 结束后，在不再需要时关闭或退出投影。

## 电视不更新怎么办？

首先确认网络、已连接的接收端和正在进行的投影。不要把这项测试留到聚会开始时才做。

1. 使用本地 P2P 时，确认电视/接收端和控制端在同一网络上。
2. 检查舞台接收端是否仍处于打开并连接状态。
3. 在 PIANO 中，关闭再重新开启当前使用模块的投影。
4. 测试另一首诗歌或经文，判断问题是否只出现在某个项目上。
5. 如果配对连接已断开，请关闭并重新连接。
6. 可能的情况下，准备一条视频线或第二块屏幕作为备用方案。
