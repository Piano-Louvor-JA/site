# 使用 PIANO LouvorJA 进行首次崇拜

在崇拜开始前做好一切准备：打开 PIANO，搜索并下载赞美诗，搭建简单的崇拜流程，让投影准备就绪。在崇拜过程中，您只需选择下一个项目并切换幻灯片即可。

## 我需要提前准备什么？

使用一台已打开 PIANO LouvorJA 的电脑。要进行投影，请连接第二块屏幕、投影仪或电视。首次下载赞美诗时需要联网；已下载的内容即使没有网络也可使用。

1. 打开电脑、电视或投影仪。
2. 打开 PIANO LouvorJA。
3. 确认您能看到操作员屏幕，即您准备崇拜的地方。
4. 如果界面显得太小，可使用顶部的缩放按钮。
5. 在选择和下载所需内容时，请保持网络连接。

首次打开时，赞美诗、诗歌集和封面目录可能在后台准备。在此期间您可以继续使用应用程序。

## 如何查找第 5 首赞美诗或按标题查找？

媒体中心汇集了赞美诗、诗歌集、歌词、幻灯片和音频。您可以按编号、标题或部分歌词来查找赞美诗。

1. 在导航栏中，打开**媒体中心**。
2. 点击搜索框。
3. 要按编号查找，请输入 `5`。
4. 要按标题查找，请输入诗歌名称或部分歌词。
5. 选择与将要使用的《基督复临安息日会赞美诗》（Hinário Adventista）或诗歌集相对应的结果。
6. 打开该赞美诗，在继续之前确认标题、歌词和封面。

如果有多个相似的结果，请在将赞美诗加入崇拜流程之前核对编号和标题。这样可以避免在敬拜时投影出不同的歌曲。

## 如何下载赞美诗以备崇拜使用？

请在崇拜前下载所有可能用到的内容。进度指示器会显示下载进度；如果应用程序关闭或连接中断，进度会保存下来，以便稍后继续。

1. 打开赞美诗后，找到**下载**按钮。
2. 点击开始下载。
3. 等待进度条完成。
4. 对崇拜流程中的每首赞美诗、诗歌集或媒体重复此操作。
5. 崇拜前，打开已下载的项目，确认它们可用。

已下载的赞美诗在没有网络的情况下仍可在设备上使用。设置、崇拜流程和下载进度也会保存在设备上。

## 如何搭建简单的崇拜流程？

崇拜流程按照崇拜将进行的顺序来组织。对于简单的安排，可以创建一个敬拜板块，添加赞美诗，如果需要，还可为团队添加圣经、视频、音频或笔记项目。

1. 打开**崇拜流程**。
2. 创建新的崇拜流程。
3. 添加一个**类别/分隔符**，并使用简单的名称，例如 `敬拜赞美`。
4. 如果您的团队按时间进行规划，请填写开始和结束时间。
5. 添加一个**音乐**类型的项目。
6. 搜索并选择您刚才确认的第一首赞美诗。
7. 按崇拜顺序添加其他赞美诗。
8. 如有需要，可添加其他类别，例如 `证道` 或 `安息日学`。
9. 根据安排添加**圣经**、**视频**、**音频**、**图片**、**PDF**、**PowerPoint 演示文稿**、**网站/在线视频**或**笔记**等项目。
10. 拖动项目以将其排列到正确的顺序。
11. 保存崇拜流程。

类别会将其中的项目分组。拖动类别时，其中的项目会随之移动。笔记仅供团队使用：不会显示给教会会众。

## 如何准备教会大屏幕？

操作员屏幕供操作应用程序的人员使用。教会屏幕仅显示投影内容：歌词、经文、时钟、倒计时和其他选定的内容。

1. 将投影仪、显示器或电视连接到电脑。
2. 在**媒体中心**中打开赞美诗。
3. 点击**投影**。
4. 在第二块屏幕上确认歌词是否显示。
5. 如果需要调整背景颜色、文字颜色、字体大小、对齐方式、背景图片或文本框，请打开**设置**。
6. 浅色背景建议使用深色文本框；深色背景建议使用浅色文本框或不用文本框，效果可能更佳。
7. 返回赞美诗页面，在敬拜开始前将第一张幻灯片准备就绪。

在没有选中歌词的情况下，投影可以显示带有标题的专辑封面。这在会众准备唱歌时很有用。

## 如何主持崇拜并切换幻灯片？

在崇拜期间，打开崇拜流程并按准备的顺序进行。音乐、圣经和实用工具可根据安排的每个环节进行投影。

1. 打开已保存的崇拜流程。
2. 选择第一个音乐项目。
3. 如果投影尚未激活，请点击**投影**。
4. 根据唱诗的进度切换主歌、副歌或诗节的幻灯片。
5. 使用进度条和下一句预览来掌握当前位置。
6. 完成后，将该标记为已完成并打开下一个项目。
7. 要投影经文，请打开**圣经**，选择版本、书卷、章和节，然后点击**投影**。
8. 要结束投影，请按 `ESC` 并确认操作。

当您切换到其他部分时，音频会继续播放。这样，您可以让赞美诗继续播放，同时准备下一节经文或崇拜流程的下一个项目。在音频播放期间切换赞美诗时，应用程序会进行平滑过渡。

## 如果崇拜期间断网怎么办？

请继续使用已下载的赞美诗和媒体。本地内容、崇拜流程、设置和已保存的进度在准备完成后都不依赖网络。

1. 不要关闭正在使用的崇拜流程。
2. 仅使用您在崇拜前已确认的赞美诗和媒体。
3. 如果需要查找新内容，请等待网络恢复。
4. 崇拜结束后，检查待下载的项目，为下次安排做准备。

## 如何保存准备工作副本？

应用程序会将您的工作保存在设备本身。如需更换电脑或保留备份副本，请使用备份功能。

1. 打开**设置**。
2. 查找**备份**选项。
3. 导出设置和数据。
4. 在格式化或更换电脑之前，将文件保存在安全的地方。
