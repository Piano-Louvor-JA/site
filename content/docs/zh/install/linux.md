# 在 Linux 上安装 PIANO LouvorJA

在 Linux 上，最直接的方式是下载官方 AppImage。您也可以使用 Snapcraft；Flathub 正在审核中，在上架商店之前，请使用其他官方渠道。

## 我应该选择哪种安装方式？

请选择在教会电脑上已经运行最好的渠道。

- **AppImage：** 单一文件，从官方页面下载。当您能访问下载文件夹时，这是最简单的选择。
- **Snapcraft：** 适用于已使用 Snap 商店的发行版。
- **Flathub：** 提交正在审核中；只有当 PIANO 在商店上架后才能使用。在此之前，请选择 AppImage 或 Snapcraft。

所有渠道都应从官方[下载](/download)页面进入，该页面指向已发布的版本。

## 如何在 ARM64 和 X64 之间选择？

下载页面可能会显示两个版本的 AppImage。

1. 如果电脑使用常见的 Intel 或 AMD 处理器，请选择 **X64**。
2. 如果使用 ARM 处理器，请选择 **ARM64**。
3. 如果不确定，请在下载前向之前配置该电脑的人寻求帮助。
4. 避免随意尝试文件：使用错误的架构会导致无法打开。

使用 Intel 或 AMD 的教会电脑通常使用 X64。

## 如何使用 AppImage 安装？

AppImage 是一个您下载、授权执行然后打开的文件。

1. 打开[下载](/download)页面。
2. 选择 **Linux**，下载适合您电脑的 AppImage。
3. 打开文件管理器，进入 **下载** 文件夹。
4. 右键点击 AppImage 文件。
5. 选择 **属性**。
6. 打开 **权限** 选项卡。
7. 勾选类似 **允许将文件作为程序执行** 的选项。
8. 关闭属性窗口。
9. 双击 AppImage 打开 PIANO。

该选项的名称可能因 Linux 发行版而略有不同。请寻找 **权限** 以及执行文件的授权选项。

## 如果我只能使用终端怎么办？

请优先使用文件管理器。如果教会的技术负责人使用终端，可以在文件保存的文件夹中使用以下命令授权该文件：

```bash
chmod +x nome-do-arquivo.AppImage
```

之后，通过文件管理器打开该文件。日常使用 PIANO 不需要终端。

## 如何通过 Snapcraft 安装？

请使用官方下载页面进入已发布的 PIANO Snapcraft 渠道。

1. 打开[下载](/download)页面。
2. 选择 **Linux** 选项，找到 Snapcraft 渠道。
3. 打开商店链接。
4. 按照您的 Linux 发行版或技术负责人显示的步骤安装。
5. 在应用菜单中查找 **PIANO LouvorJA**。
6. 打开应用并进行初始测试。

如果 Snap 商店未安装或无法在电脑上打开，请使用 AppImage，避免在安息日修改系统。

## 可以通过 Flathub 安装吗？

目前还不能作为主要途径。Flathub 的提交正在审核中；能否使用取决于商店的批准。

1. 打开[下载](/download)页面。
2. 检查是否有 PIANO 的可用 Flathub 按钮。
3. 如果有，点击该按钮并通过商店本身安装。
4. 如果没有按钮或页面显示不可用，请使用 AppImage 或 Snapcraft。

在官方页面上看到之前，请不要将 Flathub 视为可用。

## 第一次打开时应该做什么？

在敬拜之前准备好 PIANO，尤其是将在无网络环境下使用的内容。

1. 打开 PIANO LouvorJA。
2. 等待目录初始准备完成。
3. 在 **媒体中心**，搜索并下载基督复临安息日会赞美诗（Hinário Adventista）中的赞美诗以及节目单中的合辑。
4. 在 **礼仪** 中，使用分类、歌曲、圣经和本地文件创建敬拜流程。
5. 在 **设置** 中，调整投影样式。
6. 在教会大屏幕上测试一首赞美诗、一节经文和时钟。

下载、礼仪和设置都会保存在设备上。关闭应用不会删除已准备好的内容。

## 如果 AppImage 无法打开怎么办？

请先检查基本问题，不要删除任何内容。

1. 确认下载了与电脑架构匹配的正确文件。
2. 再次检查 **属性** 和 **权限**。
3. 如果文件位于 U 盘或网络位置，请将其移动到本地文件夹，如 **文档**。
4. 如果下载中断，请仅通过官方页面重新下载。
5. 如果问题仍然存在，请使用 Snapcraft 渠道（如可用），或使用网页版应用，以免在敬拜时失去支持。

## 如何为团队设置方便的快捷方式？

测试 AppImage 后，请将其保存在团队能识别的文件夹中。

1. 在 **文档** 中创建或选择一个名为 **PIANO LouvorJA** 的文件夹。
2. 将测试过的 AppImage 移动到该文件夹。
3. 再次打开它，确认它仍能正常运行。
4. 如果文件管理器提供 **添加到收藏夹** 或 **创建快捷方式** 选项，请使用该功能。
5. 告知团队文件的存放位置。
6. 不要因为文件已经打开就删除它；它就是应用程序本身。
7. 避免保留多个名称相似且已过时的副本。

## 如何准备完整的礼仪？

1. 打开 **礼仪** 并选择创建一个节目单。
2. 添加分类以区分敬拜的各个环节。
3. 添加歌曲、本地媒体、链接或注释。
4. 当团队需要掌控时间时，请设置各分类的时间。
5. 拖动项目直到排列成最终顺序。
6. 保存并与节目负责人一起审核。
7. 在敬拜期间，按顺序进行并标记已完成的项目。

## 如何安全地进行投影？

1. 在 **媒体中心** 打开一首赞美诗。
2. 点击 **投影**。
3. 检查第二屏幕或电视。
4. 翻页文字以检查同步情况。
5. 在 **圣经** 中打开一节经文并进行同样的测试。
6. 在 **设置** 中调整对比度和字体大小。
7. 测试完成后，使用 **ESC** 结束投影。

## 如何避免教会出现意外情况？

1. 提前进行下载和测试。
2. 保持充电器、视频线和转接头随手可得。
3. 确认投影仪或电视连接在正确的输入端口。
4. 不要在敬拜前临时更新 Linux 发行版。
5. 如果有网络，请将网页版应用作为备用方案。
6. 向第二个人讲解如何打开 PIANO。
7. 当团队更换电脑时，请备份设置。

## 敬拜前的最终检查清单

1. 确认 PIANO 能在所选设备上打开。
2. 确认赞美诗和资料已就绪。
3. 确认礼仪顺序正确。
4. 确认教会大屏幕能接收测试投影。
5. 确认从礼堂后排看，文字大小和对比度是否合适。
6. 确认网络、电源和所需线缆。
7. 指定一名负责操作的人员。
