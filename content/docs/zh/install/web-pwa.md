# 在浏览器和应用程序中使用 PIANO LouvorJA

直接在 [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br) 打开 PIANO。在 Chrome、Edge 或 Android 上，您可以将其作为应用添加到主屏幕；首次加载后，只要内容已下载到设备上，它就可以继续离线使用。

## 不安装任何东西如何打开 PIANO？

浏览器是最快速的入门方式，适合试用 PIANO、使用其他电脑，或支持教会以外的活动安排。

1. 打开一个更新的浏览器。
2. 输入 `app.pianolouvorja.com.br`。
3. 等待应用程序加载完成。
4. 打开**媒体中心**查找诗歌和诗歌集。
5. 使用**礼仪流程**来组织活动安排。
6. 在崇拜开始前测试投影。

要获得最佳的多屏投影体验，电脑通常是最实用的选择。浏览器在平板电脑、手机和共用设备上仍然很有用。

## 在电脑上的 Chrome 或 Edge 中如何安装为应用？

安装 PWA 会创建一个快捷方式，可以在独立窗口中打开 PIANO，无需在浏览器中寻找标签页。

1. 在 Chrome 或 Edge 中打开 [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)。
2. 当出现时，寻找网站地址旁边的安装图标。
3. 点击**安装**或**安装 PIANO LouvorJA**。
4. 确认安装。
5. 通过应用程序菜单或桌面上创建的快捷方式打开 PIANO。
6. 测试一首诗歌、圣经和投影功能。

如果图标没有出现，请打开浏览器的三点菜单，寻找**安装应用**、**将此页面安装为应用**或类似选项。

## 在 Android 上如何添加到主屏幕？

在 Android 上，PIANO 可以作为图标显示在主屏幕上。

1. 在 Chrome 中打开 [app.pianolouvorja.com.br](https://app.pianolouvorja.com.br)。
2. 点击三点菜单。
3. 选择**添加到主屏幕**或**安装应用**。
4. 确认名称并点击**添加**或**安装**。
5. 在主屏幕或应用列表中找到 PIANO 图标。
6. 通过图标打开，并在崇拜前进行测试。

在不同的浏览器中，文字可能有所不同。请寻找将网站添加为应用或添加到主屏幕的选项。

## PIANO 在浏览器中可以离线使用吗？

首次加载后，只要数据和内容已下载到设备上，PWA 就可以继续离线使用。请在崇拜前在有网络的情况下做好准备。

1. 在有网络的情况下，至少打开一次 PIANO。
2. 提前搜索并下载将要使用的诗歌。
3. 打开礼仪流程，确认所需项目已准备就绪。
4. 在网络仍然可用时测试投影。
5. 之后如果网络中断，可以使用已准备并保存在设备上的内容。

不要等到活动开始才依赖尚未下载的内容。初次访问和新的更新都需要网络连接。

## 何时使用浏览器、PWA 或已安装的应用程序？

根据教会的使用类型来选择。

| 情况                                   | 最佳选择                              |
| -------------------------------------- | ------------------------------------- |
| 快速试用或使用借来的电脑               | `app.pianolouvorja.com.br` 上的浏览器 |
| 始终在同一台电脑上使用，不安装传统程序 | 通过 Chrome 或 Edge 安装的 PWA        |
| 双显示器投影和教会固定流程             | Windows、macOS 或 Linux 应用程序      |
| 在手机或平板上控制                     | 浏览器中的 PWA 或添加到主屏幕         |
| 连接到网络以接收投影的电视             | 兼容设备上的舞台屏幕                  |

当团队需要稳定的操作、操作员屏幕与教会屏幕分离时，建议使用已安装的版本。

## 如何在 PWA 中准备活动安排？

崇拜的组织方式相同：提前准备，并在活动中逐项推进。

1. 在**媒体中心**中，按名称或歌词片段搜索诗歌。
2. 下载诗歌，使内容在设备上可用。
3. 在**礼仪流程**中，创建诸如**接待**、**安息日学**、**赞美**、**证道**和**结束**等类别。
4. 添加音乐、视频、图片、PDF、演示文稿、链接和团队备注。
5. 拖动项目以调整顺序。
6. 保存并重新打开以核对。
7. 崇拜期间，逐项推进并跟踪已完成的项目。

## 如何让教会屏幕清晰易读？

1. 打开**设置**。
2. 进入**投影**。
3. 选择对比度强的颜色。
4. 根据会众的距离，在 50% 到 200% 之间调整字体大小。
5. 如果背景是浅色图片，请启用文字框。
6. 调整对齐方式和背景。
7. 在开始前于投影仪或电视上进行测试。

## 如何在 PWA 中使用圣经和实用工具？

1. 打开**圣经**。
2. 选择版本、书卷、章节和一节或多节经文。
3. 点击**投影**将文字发送到教会屏幕。
4. 要显示时间，请打开**实用工具**并选择**时钟**。
5. 调整颜色、12 或 24 小时制以及秒数显示。
6. 要控制时间，请使用**计时器**或**倒计时**。
7. 在活动开始前测试所有功能。

## 如何远程控制 PIANO？

1. 在主设备上打开**远程控制和舞台屏幕**区域。
2. 选择同一网络配对或通过服务器配对。
3. 完成设备上显示的确认。
4. 测试诗歌搜索和打开音乐。
5. 测试经文翻页和清除选择。
6. 测试计时器的启动、暂停和重置。
7. 确认第二块屏幕不显示团队控制界面。

## 如果 PWA 无法离线打开怎么办？

1. 将设备连接到互联网。
2. 在浏览器中打开 `app.pianolouvorja.com.br`。
3. 等待页面加载完成。
4. 重新进行准备工作和下载。
5. 在断开连接之前，保持诗歌和礼仪流程已保存。
6. 有网络时刷新页面，以获取最新版本。
7. 对于固定的投影流程，请考虑使用桌面应用程序。

## 如何让浏览器为活动做好准备？

1. 关闭不会使用的标签页。
2. 如果可以，请禁用浏览器通知。
3. 仅在全屏不会隐藏必要控件时才使用全屏。
4. 确认电脑不会进入休眠状态。
5. 保持充电器和网络连接可用。
6. 打开礼仪流程，让第一个项目准备就绪。
7. 进行最后的投影测试。

## 崇拜前的最终检查清单

1. 确认 PIANO 可以在所选设备上打开。
2. 确认诗歌和资料可用。
3. 确认礼仪流程顺序正确。
4. 确认教会屏幕能接收测试投影。
5. 确认在礼堂后排的字体大小和对比度。
6. 确认网络、电源和所需的连接线。
7. 指定一名负责操作的人员。
