# 在 Android 上通过 APK 安装 PIANO LouvorJA

请仅通过 PIANO LouvorJA 官方页面下载 APK。Android 会请求允许浏览器安装该文件；只需为您下载时所用的浏览器授予权限，完成安装后打开应用，即可为聚会准备内容。

## 在哪里下载官方 APK？

Android APK 随官方版本一同发布，下载页面会显示正确的路径。

1. 打开手机或平板的浏览器。
2. 进入 [下载](/download) 页面。
3. 找到 **Android** 部分。
4. 点击按钮下载 APK。
5. 等待下载完全结束。
6. 打开下载通知或 **Downloads（下载）** 文件夹。

请勿安装来自群组、电子邮件或 U 盘且未经确认来源的 APK。官方页面是获取当前版本的唯一可靠途径。

## 如何允许安装 APK？

菜单名称因设备厂商而异，但流程相似：Android 会请求对打开该文件的应用进行授权，通常是 Chrome 或文件管理器。

1. 点击已下载的 APK 文件。
2. 出现安全提示时，点击 **设置**。
3. 启用 **允许来自此来源** 或 **安装未知应用**。
4. 返回上一屏。
5. 点击 **安装**。
6. 等待安装完成。
7. 点击 **打开**。

安装完成后，您可以在同一菜单中关闭该权限。这样可以防止其他文件在未经您确认的情况下被安装。

## 如果没有出现提示，在哪里找到该权限？

请在设备系统中查找对应的名称。

1. 打开 Android 的 **设置**。
2. 进入 **应用** 或 **应用程序**。
3. 选择下载 APK 时使用的浏览器（如 Chrome）或文件管理器。
4. 打开 **安装未知应用**。
5. 启用 **允许来自此来源**。
6. 返回 **Downloads（下载）** 文件夹，重新打开该 APK。

在某些设备上，该选项位于 **安全性** 或 **隐私** 中。重点是只对执行安装的那个应用授予权限，而不是开启不受控制的通用权限。

## 首次使用需要做什么？

请在教会聚会之前提前准备好内容。

1. 打开 **PIANO LouvorJA**。
2. 在初始准备期间保持设备联网。
3. 如果页眉中出现 **−** 和 **＋** 按钮，可用来调整界面大小。
4. 打开 **媒体中心**，搜索聚会节目中的圣诗。
5. 下载所需内容；下载进度会自动保存。
6. 在 **礼拜程序** 中整理诗歌、圣经、文件和团队备注。
7. 在 **设置** 中测试投影的颜色和字体大小。

已下载的内容和设置都保存在设备上。如需在无网络的环境下聚会，请提前下载所需内容并进行测试。

## 如何把手机当作遥控器使用？

PIANO 可以通过同一网络或服务器配对设备。

1. 打开 PIANO 中的 **遥控器** 区域。
2. 选择可用的配对方式：同一网络或服务器。
3. 按屏幕上显示的代码或确认步骤操作。
4. 测试搜索一首诗歌、翻页歌词和切换经文。
5. 聚会前也请测试清除选择和结束投影的功能。

遥控器可以帮助团队在不靠近电脑的情况下推进歌词、经文、计时器、倒计时和时钟。

## 可以在 Android TV Box 上使用吗？

可以，作为兼容 Android 设备的一种选择。请通过 TV Box 的浏览器从官方页面下载 APK，或从已核实过的官方来源传输。对于电视，最佳用途是 **舞台屏**，由另一台设备控制并接收投影内容。

1. 将 TV Box 连接到与控制 PIANO 的设备相同的网络。
2. 打开 TV Box 的浏览器，如果可用，访问 [下载](/download) 页面。
3. 下载官方 APK，并为该浏览器或文件管理器授予安装权限。
4. 打开已安装的应用。
5. 在操作设备上，打开 **舞台屏** 的配对功能。
6. 将电视端接收设备连接到网络，并按 PIANO 显示的步骤完成配对。
7. 投影一首测试诗歌，确认电视只显示教会画面。

有关 Android TV 和 Google TV 的具体步骤，请参阅专门的页面。

## 如何避免聚会当天出现问题？

1. 保持设备电量充足或连接电源。
2. 在聚会前下载诗歌和媒体内容。
3. 使用舞台屏或本地遥控时，将所有设备连接到同一网络。
4. 完整测试礼拜流程，包括视频、PDF 和经文。
5. 不要在聚会开始前几分钟更新 Android 系统或更换应用。

## 配对后如何投影歌词和圣经？

1. 在操作设备上，打开 **媒体中心**。
2. 按标题或诗歌片段搜索。
3. 打开搜索结果并点击 **投影**。
4. 推进诗节和副歌；舞台屏会在电视上同步显示。
5. 打开 **圣经**，选择版本、书卷、章节和经节。
6. 点击 **投影** 发送该段经文。
7. 使用 **ESC** 或可用命令结束投影。

## 如何在 Android 上准备礼拜程序？

1. 打开 **礼拜程序** 并创建一个节目。
2. 为聚会的每个环节添加分隔项。
3. 添加诗歌、文件、链接和备注。
4. 需要时可使用补充标题，如 **祷告** 或 **欢迎**。
5. 拖动项目调整到最终顺序。
6. 保存并检查结果。
7. 聚会期间逐项推进。

## 如何维护电池和网络？

1. 使用前为手机、平板或 TV Box 充电。
2. 在较长的聚会中，保持操作设备连接电源。
3. 将设备连接到同一网络以使用本地舞台屏。
4. 避免在聚会期间切换 Wi-Fi 网络。
5. 关闭可能分散操作员注意力的通知。
6. 开始前预先下载好诗歌和媒体内容。
7. 提前测试网络连接和投影效果。

## 如果 Android 阻止安装怎么办？

1. 确认文件来自官方页面。
2. 检查下载是否已完成。
3. 仅为打开该 APK 的应用启用 **安装未知应用**。
4. 返回文件并再次点击 **安装**。
5. 如果存储空间已满，请清理空间后重试。
6. 如果 APK 与设备不兼容，请在浏览器中使用 PWA。
7. 除这一项安装权限外，不要关闭其他系统保护。

## 聚会前的最终检查清单

1. 确认 PIANO 能在所选设备上正常打开。
2. 确认诗歌和资料已就绪。
3. 确认礼拜程序顺序正确。
4. 确认教会屏幕能收到测试投影。
5. 根据会场背景确认字体大小和对比度。
6. 确认网络、电源和所需线缆。
7. 指定一名负责操作的人员。
