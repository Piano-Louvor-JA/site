# 在 Windows 上安装 PIANO LouvorJA

最简单的安装方式是通过 Microsoft Store。如果愿意，也可以在官方下载页面下载便携版 EXE 文件；然后打开 PIANO，完成初始设置，并让一个显示器供操作员使用，另一个供教会观看。

## 如何通过 Microsoft Store 安装？

Microsoft Store 会处理应用程序的安装和更新。

1. 打开官方[下载](/download)页面。
2. 选择 **Windows**，然后打开 Microsoft Store 选项。
3. 在 Store 中搜索 **LouvorJA**。如果收到直接链接，该链接使用产品代码 `9N1WPDQKFLR9`。
4. 点击 **获取** 或 **安装**。
5. 等待下载完成。
6. 点击 **打开**，或在开始菜单中找到 **LouvorJA PIANO**。

请不要安装通过消息或陌生网站收到的副本。请使用官方页面进入 Store。

## 如何使用便携版 EXE？

EXE 是不想使用 Store 的用户的官方替代方案。它通过 GitHub 上发布的版本提供，可以从下载页面下载。

1. 打开[下载](/download)页面。
2. 在 **Windows** 区域，选择 EXE 下载。
3. 等待文件下载完成。
4. 打开 **下载** 文件夹。
5. 双击 PIANO 的 EXE 文件。
6. 如果 Windows 要求授权，请确认打开。
7. 将文件保存在容易找到的文件夹中，例如 **文档/PIANO LouvorJA**。

便携版无需传统安装即可打开。只有在确认其能正常打开后，才在桌面创建快捷方式。

## 首次打开时需要做什么？

首次使用时，PIANO 会准备曲库并显示初始配置。此时请保持网络连接，但您可以在内容准备期间先熟悉该应用程序。

1. 打开 PIANO LouvorJA。
2. 等待启动画面完成准备工作。
3. 通过页眉的 **−** 和 **＋** 按钮调整界面大小。
4. 打开 **媒体中心**，搜索《基督复临安息日会圣诗》（Hinário Adventista）中的赞美诗或某本诗歌选集。
5. 提前下载聚会中将使用的赞美诗；即使应用程序关闭，下载进度也会保存。
6. 打开 **礼仪流程**，安排安息日学、敬拜赞美、证道及其他环节的顺序。
7. 在 **设置** 中，为教会大屏幕调整背景、颜色和字体大小。

您下载和配置的内容都会保存在计算机上，包括赞美诗、下载进度、礼仪流程和偏好设置。

## 如何准备双显示器？

用一个显示器控制 PIANO，另一个供会众观看。操作员可以看到搜索、按钮和接下来的项目；教会只能看到投影画面。

1. 将投影仪、电视或第二个显示器连接到计算机。
2. 在 Windows 中，打开 **设置**。
3. 进入 **系统**，然后进入 **显示**。
4. 在 **多显示器** 中，选择 **扩展这些显示器**。
5. 拖动显示器图标，使其与实际摆放位置一致。
6. 打开 PIANO 并启动测试投影。
7. 将教会画面窗口放在第二个显示器或电视上。
8. 在聚会前测试歌词、经文和时钟。

请避免使用复制屏幕的模式：它会把控制画面显示给教会。**扩展** 模式可以将操作与投影分开。

## 如何投影赞美诗或经文？

在会众到来之前，先做一次完整的测试。

1. 在 **媒体中心** 中搜索赞美诗。
2. 打开搜索结果并点击 **投影**。
3. 切换诗节或副歌；教会屏幕会同步显示。
4. 在 **圣经** 中，选择版本、书卷、章节和经文。
5. 点击 **投影** 将经文发送到第二块屏幕。
6. 要结束投影，请按 **ESC** 并确认。

当诗歌没有选中任何段落时，PIANO 可以显示带有标题的专辑封面。这在招待环节或敬拜赞美开始前很有帮助。

## 如何调整投影的可读性？

在聚会前，根据场地空间和会众的距离调整画面。

1. 打开 **设置**。
2. 进入 **投影** 选项。
3. 调整背景颜色、文字颜色和字体大小。
4. 选择水平和垂直对齐方式。
5. 使用浅色背景或浅色图片时，启用文字底框。
6. 如果可能，请从教会最后一排座位进行测试。
7. 保存配置；它会保留在计算机上。

对于圣诗歌词，应优先考虑对比度和大小。如果教会看不清歌词，再美的图片也无济于事。

## 如果视频或音频在错误的程序中打开怎么办？

在 Windows 上，PIANO 允许选择视频和媒体文件的打开方式。

1. 打开 **设置**。
2. 找到 **外部播放器**。
3. 选择 **系统关联** 以使用 Windows 默认程序。
4. 如果检测到其他播放器，请选择它。
5. 用礼仪流程中的视频或音频做一次测试。

## 如何为下次聚会做好准备？

在周间从容进行的准备，可以减轻团队在安息日的工作量。

1. 打开上次的礼仪流程，如有需要可将其作为参考。
2. 更新补充标题、时间和节目分类。
3. 提前下载尚未保存在计算机上的歌曲、视频和文件。
4. 打开每个媒体项目，确认其正常运行。
5. 在更换计算机之前，在 **设置** 中进行备份。
6. 让笔记本电脑连接电源，并确保充电器便于取用。
7. 在聚会开始前十五分钟进行一次快速投影测试。

## 如果投影不更新该怎么办？

1. 确认第二个显示器仍连接到 Windows。
2. 检查投影窗口是否在正确的模块中打开，例如 **媒体** 或 **圣经**。
3. 重新打开您正在使用的项目的投影。
4. 确认 Windows 仍处于 **扩展这些显示器** 模式。
5. 如有必要，关闭并重新打开 PIANO；已保存的内容仍然可用。
6. 当教会有备用视频线时，请使用备用线缆。

## 如何进行团队协作？

指定一人操作，另一人核对教会屏幕。

1. 操作员打开礼仪流程并推进各项内容。
2. 第二人核对投影中的歌词、经文和对比度。
3. 开始之前，两人一起检查敬拜和证道的顺序。
4. 如有变动，请在礼仪流程中添加备注，以便指引团队。
5. 在节目进行期间，避免多人同时操作同一台计算机。

## 聚会前的最终检查清单

1. 确认 PIANO 能在所选设备上打开。
2. 确认赞美诗和资料可用。
3. 确认礼仪流程顺序正确。
4. 确认教会屏幕能收到测试投影。
5. 确认在大厅背景下的字体大小和对比度。
6. 确认网络、电源和所需线缆。
7. 指定一名负责操作的人员。
