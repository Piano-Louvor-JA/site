# 在三星电视上使用 PIANO LouvorJA

三星电视应通过 **Palco** 接收投射：由另一台设备控制崇拜，电视仅显示教会画面。在下载页面上，当有已发布的文件时，会出现三星电视频道；如果没有可用文件，请使用电视的浏览器访问网页版应用，或将兼容的接收器连接到电视。

## 什么是 Palco？

Palco 是安装在电视上的接收器，用于显示 PIANO 发送的投射内容。团队继续通过电脑、手机或其他设备进行操作；电视无需显示搜索、礼拜程序或控制按钮。

连接 Palco 后，会众可以跟随查看：

- 赞美诗和诗歌集的歌词；
- 圣经经文；
- 时钟、计时器和倒计时；
- 操作员启动的其他投射内容。

## 需要提前准备什么？

在安息日或活动之前，先准备好网络和设备。

1. 将三星电视连接到教会网络。
2. 使用本地配对时，将操作用的电脑或手机连接到同一网络。
3. 在另一台设备上打开[下载](/download)页面，确认是否有针对 **Samsung/Tizen** 的有效下载。
4. 如果有官方文件，请只使用该文件以及下载页面上的指引。
5. 如果没有文件，请打开电视的浏览器，或将兼容的接收器连接到 HDMI 接口。
6. 在电视开机且音量调好的状态下进行测试。

下载页面会显示 Samsung/Tizen 的卡片，但文件取决于接收器上是否有已发布的版本。本文档不提供任何特定的三星商店指引。

## 如何将电视浏览器作为替代方案使用？

仅在未安装接收器时，才将浏览器作为替代方案使用。导航和兼容性取决于电视型号。

1. 在遥控器上按 **Home** 键。
2. 打开电视上的 **Apps**、**Internet** 或可用的浏览器。
3. 输入 `app.pianolouvorja.com.br`。
4. 等待应用加载。
5. 进行一次阅读和导航测试。
6. 如果电视浏览器运行不佳，请使用连接到 HDMI 的电脑或装有 Palco 的电视盒。

不要尝试在三星电视上安装 Android APK：Tizen 不是 Android。

## 如何将电视与 PIANO 配对？

配对将电视上的接收器与控制礼拜程序的设备连接起来。

1. 在连接到电视的设备上打开 Palco 或网页版应用。
2. 在操作用的电脑或手机上打开 PIANO。
3. 进入 **Controle remoto e Palco**（遥控与舞台）区域。
4. 选择显示的配对方式：同一网络或通过服务器。
5. 在两台设备上确认显示的数据或代码。
6. 等待连接确认。
7. 投射一首测试用的赞美诗。
8. 前进到下一节，确认电视同步更新。

进行本地配对时，所有设备必须位于同一网络。如果教会对访客和设备使用不同的网络，请将操作员设备和接收器连接到设备所在的网络。

## 如何测试完整投射？

在会众到达之前进行测试。

1. 在 **Central de Mídia**（媒体中心）中，打开一首赞美诗并点击 **Projetar**（投射）。
2. 前进多节歌词和副歌。
3. 在 **Bíblia**（圣经）中，投射一段简短的经文。
4. 在 **Utilitários**（实用工具）中，测试时钟和倒计时。
5. 在 **Configurações**（设置）中，增大字体大小并根据需要调整对比度。
6. 确认电视不显示控制菜单。
7. 在操作设备上按 **ESC** 结束投射，确认电视画面已清除。

## 如何改善电视上的阅读效果？

调整是在操作设备上进行的，但会影响会众看到的内容。

1. 在 PIANO 中打开 **Configurações**（设置）。
2. 进入 **Projeção**（投射）。
3. 选择对比度高的背景和文字。
4. 增大字体大小以便远距离阅读。
5. 在浅色图像上启用文字底框。
6. 调整水平和垂直对齐。
7. 在会堂最远的位置重新进行测试。

## 如果电视没有出现在配对列表中怎么办？

1. 确认电视/接收器和操作设备在同一网络上。
2. 关闭并重新打开 Palco 或电视浏览器。
3. 检查电视是否处于隔离的访客网络中。
4. 仅重启接收器或电视，然后再次尝试配对。
5. 如果仍无法解决，请暂时使用 HDMI 线缆进行投射，不要中断崇拜。

## 如何在操作设备上组织礼拜程序？

电视只接收投射内容；准备工作应在团队使用的电脑、手机或平板上进行。

1. 在操作设备上打开 **Liturgia**（礼拜程序）。
2. 为崇拜的各个环节创建分类。
3. 添加音乐、经文、文件和备注。
4. 重新排列各项顺序，以反映实际流程。
5. 提前下载所需的赞美诗和内容。
6. 保存并与负责主持程序的人一起进行一次检查。
7. 在配对电视之前，先准备好第一个项目。

## 如何避免三星电视上的中断？

1. 保持电视接通电源，不要仅处于待机模式。
2. 如有启用，请关闭自动关机定时器。
3. 在活动开始前确认 Wi-Fi 网络。
4. 确保遥控器电池电量充足。
5. 崇拜期间不要更改网络设置。
6. 避免在电视上打开额外的应用。
7. 准备一根 HDMI 线缆作为应急备用方案。

## 如何在 Palco 中使用时钟和计时器？

1. 在操作设备上，打开 **Utilitários**（实用工具）。
2. 选择 **Relógio**（时钟）、**Temporizador**（计时器）或 **Contagem regressiva**（倒计时）。
3. 根据需要调整时钟的颜色和格式。
4. 在设定的时刻启动计时器或倒计时。
5. 在电视上检查显示是否清晰。
6. 当团队需要记录时间节点时，在计时器上保存标记。
7. 切换到礼拜程序的下一个项目时，结束当前投射。

## 如何应对临时的变动？

1. 让操作员留在主设备上。
2. 使用 **Central de Mídia**（媒体中心）的搜索功能查找所需的赞美诗。
3. 正常投射和翻页；电视会接收更新。
4. 在礼拜程序备注中记录重要变动。
5. 如果投射仍在正常运行，请避免重启电视。
6. 如果接收器出现故障，暂时切换到 HDMI。
7. 崇拜结束后，从容地重新进行配对。

## 崇拜前的最终检查清单

1. 确认 PIANO 能在所选设备上打开。
2. 确认赞美诗和资料均可用。
3. 确认礼拜程序顺序正确。
4. 确认教会屏幕能接收测试投射。
5. 在会堂后方确认字体大小和背景对比度。
6. 确认网络、电源和所需线缆。
7. 安排专人负责操作。
