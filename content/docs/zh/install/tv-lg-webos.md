# 在 LG webOS 电视上使用 PIANO LouvorJA

LG webOS 电视应通过 **Palco** 接收投影，而崇拜则由电脑或手机控制。请查看下载页面，确认是否已发布官方 webOS 文件；如果没有，可以使用电视自带的浏览器作为替代方案，或通过 HDMI 连接兼容的 receiver。

## Palco 在 LG 电视上是如何工作的？

Palco 将电视变成会众的显示屏。操作员在另一台设备上准备并推进节目单，LG 电视只显示投影的内容。

这样可以同步显示：

- 基督复临安息日会赞美诗（Hinário Adventista）的歌词、专辑与合集；
- 在圣经中选定的经文；
- 用于崇拜开始和进行的时钟与计时器；
- 从 PIANO 任何模块启动的投影内容。

## 配对前需要准备什么？

1. 打开 LG 电视，并将其连接到教会网络。
2. 将操作用的电脑或手机连接到同一网络，以便进行本地配对。
3. 在另一台设备上打开 [下载](/download) 页面。
4. 查看电视分区和 **LG/webOS** 卡片。
5. 只有当下载按钮可用时，才使用官方文件。
6. 如果没有发布文件，请准备 webOS 浏览器或通过 HDMI 连接外部 receiver。
7. 在节目开始前测试电视的网络连接。

当 receiver 发布了资源时，下载页面会识别 webOS 渠道。所查阅的资料中，没有关于 LG Content Store 目前已发布该应用的确认。

## 如何使用 webOS 浏览器作为替代方案？

当没有可用的 receiver 应用时，浏览器可能会派上用场。名称可能因 webOS 版本而有所不同。

1. 按遥控器上的 **Home** 键。
2. 打开 **网络浏览器**、**Browser** 或类似选项。
3. 输入 `app.pianolouvorja.com.br`。
4. 等待页面加载。
5. 进行打开和阅读测试。
6. 如果出现卡顿或操作困难，请改用通过 HDMI 连接的外部设备上的 Palco。

浏览器只是一种替代方案；进行专用投影的推荐流程，仍然是把控制端放在另一台设备上，电视作为 Palco 的显示屏。

## 如何将 Palco 与操作设备配对？

1. 在连接到电视的 receiver 上打开 Palco，或在电视上打开准备好的 Web 应用。
2. 在控制崇拜的电脑、手机或平板上打开 PIANO。
3. 进入 **遥控器与 Palco**。
4. 根据可用界面，选择同一网络配对或通过服务器配对。
5. 确认代码或所要求的信息。
6. 等待连接状态显示。
7. 打开一首赞美诗并点击 **投影**。
8. 前进一节歌词，确认电视上的更新。

如果选择本地模式，请确保两台设备使用同一网络。访客网络可能会阻止它们互相发现。

## 如何进行崇拜测试？

1. 投影一首赞美诗，逐行前进歌词。
2. 测试一段 **圣经** 经文。
3. 打开 **实用工具** 并投影时钟。
4. 如果计时器和倒计时会用于礼仪流程，请进行测试。
5. 打开已规划的礼仪流程，检查媒体项目。
6. 有音频时，检查电视音量。
7. 结束一次投影，确认电视反应正常。

请提前准备好媒体文件和赞美诗。PIANO 会将下载内容、进度和设置保存在控制节目单的设备上。

## 如何调整字体、背景和对比度？

1. 在操作设备上，打开 **设置**。
2. 进入 **投影**。
3. 设置背景颜色和文字颜色。
4. 根据大厅的距离增大字号。
5. 在浅色背景上启用文字底框。
6. 调整对齐方式和背景图片。
7. 请人在教会后方检查可读性。

## 如果 LG 电视无法连接怎么办？

1. 确认电视和操作设备的 Wi-Fi 或网线连接。
2. 关闭并重新打开电视的浏览器或 receiver。
3. 检查操作设备是否未处于访客网络。
4. 如果 PIANO 中有通过服务器配对的选项，请尝试重新配对。
5. 如果情况紧急，可通过 HDMI 将电脑连接到电视，继续崇拜。

## 如何在操作设备上安排崇拜？

1. 在控制电视的电脑、手机或平板上打开 **礼仪流程**。
2. 为节目单的每个环节创建分类。
3. 添加音乐、媒体文件、链接和团队备注。
4. 拖动项目以调整顺序。
5. 提前下载所需的赞美诗和材料。
6. 保存节目单。
7. 开始前将第一个项目保持打开状态。

## 如何在 LG 电视上使用圣经和实用工具？

1. 在操作设备上，打开 **圣经**。
2. 选择版本、书卷、章节和经文。
3. 点击 **投影**，并在电视上检查经文内容。
4. 打开 **实用工具** 以显示时钟或计时器。
5. 调整颜色，以便与电视上的显示效果相匹配。
6. 启动计时器或倒计时。
7. 在崇拜前测试结束投影的功能。

## 如何在节目开始前避免问题？

1. 提前打开电视。
2. 检查互联网或本地网络。
3. 将遥控器放在附近。
4. 进行教会大屏幕显示测试。
5. 如果使用外部 receiver，请检查 HDMI 线缆。
6. 不要在崇拜开始前几分钟更新电视。
7. 准备好 HDMI 备用方案，以应对可能的网络故障。

## 如何应对节目单的临时变动？

1. 操作员在 **媒体中心** 中查找新的赞美诗。
2. 直接在电视上投影该项目。
3. 如果团队需要记录变动，则更新礼仪流程。
4. 使用备注来指导节目中的下一位人员。
5. 让电视保持在 Palco 界面，不要尝试用电视遥控器控制崇拜。
6. 在请会众开始唱之前，目视确认歌词。
7. 变动结束后，恢复正常的顺序。

## 崇拜前的最终检查清单

1. 确认 PIANO 能在所选设备上打开。
2. 确认赞美诗和材料已就绪。
3. 确认礼仪流程顺序正确。
4. 确认教会大屏幕能接收测试投影。
5. 在大厅后方确认字号和对比度。
6. 确认网络、电源和所需线缆。
7. 指定一名负责操作的人员。
