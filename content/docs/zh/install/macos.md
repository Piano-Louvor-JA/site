# 在 macOS 上安装 PIANO LouvorJA

下载与您的 Mac 相对应的 DMG 文件，将 PIANO 拖到**应用程序**文件夹并打开。搭载 M1 或更新芯片的 Mac 使用 ARM64；Intel Mac 使用 X64。如果 macOS 阻止首次打开，请通过右键菜单打开。

## 如何判断 Mac 是 Apple Silicon 还是 Intel？

芯片类型决定了应下载哪个文件。

1. 点击左上角的 **Apple** 菜单。
2. 选择**关于本机**。
3. 查找**芯片**或**处理器**一行。
4. 如果显示 **Apple M1**、**M2**、**M3**、**M4** 或其他 Apple 芯片，请选择 **ARM64**。
5. 如果显示 **Intel**，请选择 **X64**。

如有疑问，不要同时下载两个文件。继续之前请再次查看**关于本机**屏幕。

## 在哪里下载正确的文件？

官方文件以 DMG 格式发布在 PIANO LouvorJA 的 macOS 版本中。

1. 打开 [下载页面](/download)。
2. 选择 **macOS**。
3. Apple Silicon 选择 **DMG ARM64**，Intel 选择 **DMG X64**。
4. 等待下载完成。
5. 打开**下载**文件夹。

请始终通过官方页面下载。第三方发送的名称相似的文件可能不是正确的版本。

## 如何安装 DMG？

DMG 会打开为一个小窗口，其中包含应用程序和“应用程序”文件夹。

1. 双击下载的 DMG 文件。
2. 等待安装窗口出现。
3. 将 **PIANO LouvorJA** 拖到窗口中显示的**应用程序**文件夹。
4. 等待复制完成。
5. 打开**访达（Finder）**。
6. 进入**应用程序**。
7. 双击 **PIANO LouvorJA**。
8. 确认打开后，通过访达推出安装磁盘。

不要让应用程序只在 DMG 内运行。将其复制到**应用程序**可避免它依赖于下载的文件。

## macOS 阻止了首次打开，怎么办？

从互联网下载的应用程序可能会出现这种情况。请通过右键菜单打开一次。

1. 打开**访达（Finder）**并进入**应用程序**。
2. 找到 **PIANO LouvorJA**。
3. 右键点击图标，或按住 Control 键点击。
4. 选择**打开**。
5. 在确认消息中，再次点击**打开**。
6. 之后即可通过启动台、Dock 或应用程序正常打开。

请勿在没有必要时更改 Mac 的安全设置。此操作仅允许打开您选择的应用程序。

## 首次打开时需要做什么？

PIANO 会准备曲库，并将您的信息保存在本机。

1. 在**应用程序**中打开 PIANO LouvorJA。
2. 首次准备时请保持联网。
3. 如有需要，通过顶部的 **−** 和 **＋** 按钮调整屏幕大小。
4. 在**媒体中心**搜索《基督复临安息日会圣诗》（Hinário Adventista）中的赞美诗。
5. 下载聚会中要使用的赞美诗和诗歌合集。
6. 在**礼仪（Liturgia）**中创建节目单。
7. 打开**设置**，调整颜色、背景和投影大小。

下载可以在之后继续进行。如果应用关闭，已保存的进度会在您返回时仍然可用。

## 如何在聚会前进行测试？

简单的测试可以避免敬拜或讲道时出现意外。

1. 在**媒体中心**打开一首赞美诗。
2. 点击**投影**。
3. 在诗节和副歌之间切换。
4. 打开**圣经**，选择一节经文并进行投影。
5. 在**实用工具**中测试时钟、计时器或倒计时。
6. 如果文字看起来太小，可在**设置**中增大字体。

要使用电视、投影仪或其他屏幕，请先连接设备，并与团队一起完成完整测试。PIANO 将操作屏幕与会众看到的屏幕分开。

## 如何保持 PIANO 整洁有序？

准备好的电脑让安息日的工作更加顺利。

1. 仅在需要重新安装时保留 DMG；应用通过**应用程序**文件夹运行。
2. 提前下载赞美诗、诗歌合集和礼仪内容。
3. 在礼仪中使用分类，例如**安息日学**、**敬拜赞美**、**奉献**和**讲道**。
4. 更换电脑前，请在**设置**中进行备份。
5. 在节目开始前测试媒体文件。

## 如何在编排节目之前组织礼仪？

礼仪将聚会的各项内容按顺序整理好，团队无需在节目进行中查找内容。

1. 打开**礼仪（Liturgia）**并创建新的节目单。
2. 创建分类，例如**迎宾**、**敬拜赞美**、**讲道**和**结束**。
3. 添加歌曲、经文、视频、图片、PDF 或演示文稿。
4. 为团队编写备注；这些备注不会显示在教会屏幕上。
5. 拖动项目以调整顺序。
6. 保存并重新打开以核对。
7. 聚会期间，逐项推进并跟踪已完成的内容。

## 如何准备离线使用的内容？

已下载到 PIANO 的内容在 Mac 上仍然可用，即使连接中断也不受影响。

1. 在一周内连接互联网。
2. 打开将要使用的赞美诗。
3. 点击所需项目上的 **download**。
4. 等待进度条完成。
5. 同时确认礼仪中的视频、PDF 和本地演示文稿文件。
6. 在不依赖新搜索的情况下进行一次测试。
7. 如果关闭应用，下载进度会被保留。

## 如何在电视上使用舞台（Palco）模式？

当连接到网络的电视作为会众屏幕时，请使用舞台模式。

1. 将电视或功放连接到教会网络。
2. 在连接电视的设备上打开舞台模式。
3. 在 Mac 上，打开**远程控制与舞台**区域。
4. 根据屏幕显示，选择本地配对或通过服务器配对。
5. 确认显示的代码或数据。
6. 投影一首赞美诗并切换到下一诗节。
7. 确认电视只显示投影内容。

## 聚会前的最终检查清单

1. 确认 PIANO 能在所选设备上打开。
2. 确认赞美诗和资料可用。
3. 确认礼仪顺序正确。
4. 确认教会屏幕能收到测试投影。
5. 根据会场背景确认字体大小和对比度。
6. 确认网络、电源和所需线缆。
7. 指定一名负责人进行操作。
