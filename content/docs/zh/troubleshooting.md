# 常见问题与解决方法

请从症状入手，在崇拜前先测试解决方法，并为投影准备好备用方案。已下载的内容、您的礼拜程序和本地设置都会保存在设备上，不会丢失。

## 求助之前应先检查什么？

在发送求助消息之前，请先完成以下检查。这能解决最常见的问题，并在问题仍然存在时为团队提供必要的信息。

1. 关闭并重新打开应用程序，或刷新页面。
2. 确认电脑、投影仪、电视和音频输出设备均已开机。
3. 检查视频线是否已连接，电视是否选择了正确的输入源。
4. 如果您正在尝试下载内容或使用网页版，请检查网络连接。
5. 打开一个已下载的诗歌，以区分是网络问题还是应用本身的问题。
6. 用一首诗歌和一节经文测试投影。
7. 记下操作系统、浏览器或应用版本、受影响的模块以及显示的错误信息。
8. 截取屏幕截图，但不要包含密码、个人数据或教会信息。

## 应用程序无法打开或无法加载，怎么办？

请先刷新。在网页版中，首次访问需要联网；在应用程序中，**重试**选项可以恢复临时故障。

1. 刷新页面。
2. 如果使用浏览器，请按 `Ctrl+F5` 更新缓存。
3. 在其他网站上确认网络是否正常。
4. 使用无痕窗口测试，以判断是否有浏览器扩展程序在干扰。
5. 在浏览器设置中清除该网站的数据，然后重新打开。
6. 如果出现错误页面，请点击**重试**。
7. 如果应用提示浏览器模式下缺少 bridge，请继续使用可用的本地数据，或使用适合您设备的应用版本。

如果问题仍然存在，请将检查清单中的信息发送给我们，并说明错误出现的时间点。

## 诗歌目录无法加载，怎么办？

请检查网络连接。应用程序会按顺序尝试多个目录来源；即使连接失败，已下载的项目仍可离线使用。

1. 检查网络连接。
2. 重新加载应用程序。
3. 如有必要，打开一首已下载的诗歌，以便继续排练或崇拜。
4. 在聚会期间请勿清除本地数据。
5. 网络恢复后，再尝试搜索。

## 诗歌无法下载，怎么办？

请关注进度条并保持网络连接。关闭应用程序不应清除进度：进度会保存下来以便稍后继续。

1. 确认网络连接稳定。
2. 开始下载并稍等片刻。
3. 如果进度停止，请重新加载或重新打开应用程序。
4. 再次搜索同一首诗歌，确认下载是否已恢复。
5. 崇拜时，请只使用您事先确认已下载完成的诗歌。

## 音频无法播放，怎么办？

请先检查电脑的音量和声音输出。PIANO 在您浏览其他板块时仍会继续播放音频，因此问题可能出在所选的输出设备或音频文件本身。

1. 确认播放器处于播放状态，而非暂停。
2. 调高 PIANO 和电脑的音量。
3. 确认已选择并连接正确的调音台、音箱或耳机。
4. 测试另一首有音频的诗歌。
5. 如果问题出在桌面版的外部视频或音频，请打开**设置**并检查**外部播放器**。
6. 选择**跟随系统**以使用默认播放器，或选择其他已检测到的播放器。
7. 在开始崇拜前再次测试。

## 视频、PDF 或演示文稿在错误的程序中打开，怎么办？

在桌面版中，PIANO 可以使用系统关联的播放器或其他已检测/配置的播放器。

1. 打开**设置**。
2. 进入**外部播放器**。
3. 选择**跟随系统**以使用电脑的默认程序。
4. 如有必要，可选择已检测到的播放器（如 VLC），或通过文件选择器添加其他可执行文件。
5. 重新打开该项目进行测试。
6. 如需还原，请移除自定义播放器，恢复使用系统关联的播放器。

## 投影画面没有显示，怎么办？

请确认线缆、电视/投影仪的输入源，以及是否已激活正确模块的投影。教会大屏与操作员的屏幕是相互独立的。

1. 打开投影仪或电视。
2. 在电视或投影仪上选择正确的输入源。
3. 检查电脑端和屏幕端的视频线。
4. 在**媒体中心**中打开一首诗歌。
5. 点击**投影**。
6. 前进一张幻灯片，测试画面是否更新。
7. 如果没有显示，请在正确的模块（如**媒体**或**圣经**）中重新打开投影窗口。
8. 用其他内容测试，例如一节经文或时钟。

## 无法检测到第二屏幕，怎么办？

对额外屏幕的识别取决于电脑、线缆和操作系统。请先确认物理连接和电脑本身的屏幕设置。

1. 关闭再重新打开电视或投影仪。
2. 拔下并重新连接线缆。
3. 如有条件，测试另一根线缆或另一个输入端口。
4. 打开电脑的屏幕设置，确认第二屏幕已显示。
5. 选择适合您电脑的双屏模式。
6. 系统识别屏幕后，返回 PIANO 并测试**投影**。

在 Windows 上，快捷键 `Win+P` 可在“复制”和“扩展”屏幕之间切换。在 macOS 上，打开系统设置 → 显示器，并将屏幕拖动到正确的物理位置。在 Linux 上，显示器设置位于 设置 → 显示（名称因发行版而异）。

## 歌词错位或难以阅读，怎么办？

请调整投影设置。歌词和圣经在应用程序中各有独立的显示选项。

1. 打开**设置**。
2. 在**投影**中，调整背景颜色、文字颜色、字体大小和字重。
3. 调整水平和垂直对齐方式。
4. 开启文本框，如果背景影响阅读，可调整透明度/描边。
5. 如有需要，更换或调整背景图片。
6. 对于圣经，也请检查圣经样式的专属设置。
7. 从远处、在会众观看屏幕的位置进行测试。

## 电视或舞台模式无法连接，怎么办？

请确认网络和配对状态。手册中说明了可通过同一网络的 P2P 连接，或通过服务器连接，两者位于不同的标签页。

1. 确认电视/舞台接收端和控制设备均已开机。
2. 对于 P2P，请将两者连接到同一局域网。
3. 避免使用会将已连接设备隔离的访客 Wi‑Fi。
4. 在控制端和接收端重新打开配对页面。
5. 重新连接，并测试一首诗歌和一节经文。
6. 如果崇拜期间连接失败，在可用的情况下，可改用有线第二屏幕作为替代方案。

如果重新连接后电视显示旧内容或画面冻结，请先在电视上关闭并重新打开舞台接收端（在浏览器中则刷新页面），然后再从 PIANO 端尝试重新连接。电视可能会在内存中保留已结束的上一次连接的画面。

## 更新似乎没有生效，怎么办？

在网页版中，更新会在刷新页面时应用。请在崇拜之前更新，不要在开始前几分钟才操作。

1. 刷新页面。
2. 如需更新缓存，请使用 `Ctrl+F5`。
3. 如果使用的是安装版，请关闭并重新打开应用程序。
4. 确认核心功能仍然正常：搜索、已下载的诗歌、音频、礼拜程序和投影。
5. 如果某项更改导致无法使用，请记录版本号、浏览器和症状，以便反馈给支持团队。

## 我的礼拜程序、下载内容或设置会丢失吗？

关闭应用程序、重启电脑或断网不应清除已保存的本地数据。即便如此，在更换电脑或对系统进行维护之前，请务必备份。

1. 打开**设置**。
2. 使用**备份**导出数据和设置。
3. 将备份副本保存在将要更改的电脑之外。
4. 在崇拜前依赖另一台电脑之前，先测试导入是否正常。
5. 在没有备份副本的情况下，请勿删除应用程序的文件或数据。
