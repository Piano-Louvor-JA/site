# 键盘快捷键

快捷键能帮助您主持崇拜时无需寻找按钮。请在聚会前先在教会的电脑上测试所有快捷键，并且仅当焦点不在搜索框或备注输入框时使用它们。

## 如何安全地使用快捷键？

请使用连接到操作员电脑的键盘。首先将诗歌、崇拜程序或圣经内容准备好；然后在投影过程中使用快捷键快速响应。

1. 在控制崇拜的电脑上打开 PIANO。
2. 在开始之前准备好诗歌和投影画面。
3. 使用方向键、空格键或快捷键字母之前，先点击文本输入框以外的地方。
4. 与团队进行一次简短的排练。
5. 保留屏幕按钮作为备选方案，以防某个快捷键没有响应。

## 哪些快捷键控制播放器？

在跟随诗歌或音频时使用这些快捷键。它们可以避免仅仅为了暂停、切换曲目或调节音量而切换界面。

| 操作      | 快捷键 | 使用时机                                       |
| --------- | ------ | ---------------------------------------------- |
| 播放/暂停 | `空格` | 在排练、入场或敬拜期间开始或暂停诗歌音频。     |
| 下一曲目  | `→`    | 当聚会安排或测试需要时，切换到下一曲目。       |
| 上一曲目  | `←`    | 当团队需要重复播放或更正选择时，返回上一曲目。 |
| 增大音量  | `↑`    | 确认音频输出正确后，提高播放器音量。           |
| 减小音量  | `↓`    | 在不打断音乐的情况下降低播放器音量。           |
| 全屏模式  | `F`    | 在会议或伴奏期间使用全屏播放器。               |

在搜索框中输入文字或编辑备注时，请避免使用方向键。否则，方向键可能会移动光标而不是控制播放器。

## 哪些快捷键控制投影？

在崇拜期间使用这些命令来显示、结束投影，或在控制界面与投影之间快速切换。

| 操作                        | 快捷键       | 使用时机                                                         |
| --------------------------- | ------------ | ---------------------------------------------------------------- |
| 切换投影                    | `P`          | 开启或关闭当前内容的投影，无需在屏幕上寻找按钮。                 |
| 结束投影                    | `ESC`        | 在一首诗歌、一节经文或某项功能结束后关闭投影；应用会要求确认。   |
| 在桌面版中切换操作员 ↔ 投影 | `Ctrl+Alt+P` | 在桌面应用中需要在操作员窗口和投影之间切换以核对两个画面时使用。 |

在使用 `ESC` 之前，请提前告知讲台上或唱诗的人员。该命令会结束投影，并且需要确认，正是为了减少误操作导致的意外中断。

## 如何在不离开当前流程的情况下查找诗歌？

当崇拜程序在聚会开始前不久发生变动时，快速搜索功能可以方便地查找《基督复临安息日会圣诗》（Hinário Adventista）、圣乐选集或其他内容。

| 操作     | 快捷键   | 使用时机                                                         |
| -------- | -------- | ---------------------------------------------------------------- |
| 快速搜索 | `Ctrl+K` | 打开搜索框，直接输入诗歌编号、标题或歌词片段，无需在菜单中导航。 |

1. 按下 `Ctrl+K`。
2. 输入诗歌编号、标题或部分歌词。
3. 选择正确的结果。
4. 在依赖无网络使用之前，确认该诗歌已下载。
5. 到了聚会环节时打开并投影。

## 如何与团队一起练习快捷键？

不要依赖第一次实际使用。请按照与崇拜时相同的顺序进行一次简短演练。

1. 打开一首已下载的诗歌。
2. 使用 `空格` 开始和暂停播放。
3. 使用 `↑` 和 `↓` 调节音量。
4. 点击**投影**并测试 `P`。
5. 使用 `ESC`，确认结束，然后再次打开投影。
6. 按下 `Ctrl+K` 并搜索下一首诗歌。
